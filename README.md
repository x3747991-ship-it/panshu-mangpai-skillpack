# 盘叔盲派 · 盲派命理四派融会技能包

> **体用做功 · 断事应期。** 把段建业盲派体系（《命理珍宝》《命理真宝》《命理瑰宝》《盲派中级命理学》《2010 高级面授笔记》《函授教材》等）与夏仲奇铁口直断、苏国圣金口诀、高德臣金口诀四大流派，蒸馏融合为一个统一体系：**ps-zonglun 唯一入口 + 四派分层路由 + 跨包仲裁兜底**。段派体用做功定层次，夏派铁口直断补应期，苏派口诀串宫压运，高派神煞佐证取象，各安其位，主从裁决。

## 一、核心定位

- **输入**：四柱（年 / 月 / 日 / 时柱干支）+ 性别；时辰存疑走夏派「兄弟数倒推」校时。
- **输出**：命局层次（功量层级 + 行业方向）→ 分域断语（事业 / 财运 / 婚姻 / 健康 / 六亲 / 牢狱 / 寿元）→ 命例佐证（匹配原型盘）→ 应期推算，两大块缺一不可。
- **不用神口径**：不论旺衰取用，按「宾主 → 体用 → 做功 → 功量」断吉凶朝向；正局按做功论层次，反局另立朝向。
- **四派统一**：段派体用（主断）＞苏派口诀 ＞ 高派神煞（佐证）；夏派铁口与段派并列为铁口层。
- **可追溯**：每条断语带规则编号 / 出处块号 / 置信度；跨包冲突按《跨包冲突仲裁表》12 项已定裁决 + 总原则兜底，不伪造唯一答案。
- **交互流程层**：另设 `ps-zonglun-guide` 使用指引 —— 先锁四柱、再锁背景、出初校命书、实证校准、出终版命书、引导细推后运（断法仍归 ps-zonglun 及各子技能）。

## 三、使用方法

1. 将整个 `盘叔盲派/` 目录作为技能包挂载到 TRAE / 你的 AI 助手中。
2. 用户报出「四柱 + 性别」（或可定四柱的出生信息），从总控 `SKILL.md` 入手，按七层流程调度；**完整论命建议先加载 `ps-zonglun-guide` 使用指引**，按其六步流程逐步引导（规避排盘出错、支持实证校准）。
3. 只问单一领域（如只看婚姻）时，直接路由对应子技能，不做全流程重算。

## 四、方法共识

- 本包为**盲派**体系（宾主体用、做功断层次、不用神），与子平法（日干立极、月令取格）是两套体系，不混用。
- 神煞只作佐证，不独立成断。
- 流年只管应期、不断吉凶；凶象须多作用重复方可定重，孤证作倾向。
- 干支形近字（巳/己、戌/戍、午/牛）按仲裁表校正后再引用。
