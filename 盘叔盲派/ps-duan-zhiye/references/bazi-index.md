# 四柱八字模型索引画布（本书专属）

> 本文件是本书蒸馏的规则挂载画布。
> L1-L3 为所有命理书共享的不可变底层（四柱、十神、五行）。
> L4-L8 由第 2 步骨架根据本书实际结构生成，追加在本文件末尾。
>
> 模型路径写法：`L1四柱 > 日柱 > 地支 > L2十神 > 正官 > L8断事 > 职业`

## L1 · 四柱 [不可变底层]

每柱的标准展开维度：

```
年柱 / 月柱 / 日柱 / 时柱
  ├── 天干  [五行] [阴阳] [ <- L2十神 ]
  ├── 地支  [五行] [阴阳] [ <- L2十神 ]
  ├── 藏干  [主气/中气/余气] [五行] [ <- L2十神 ] [透出与否]
  ├── 纳音  [纳音五行]
  ├── 空亡  [旬空] [空亡对十神的影响]
  └── 十二长生  [该柱天干在地支的十二长生状态]
```

### 十神属性卡（提取时须标注命中了哪些维度）

```
比肩：六亲=兄弟/朋友/同辈；心性=独立固执竞争；事业=自我奋斗合伙；财运=分财破财
劫财：六亲=损友/姐妹；心性=冲动挥霍；事业=投机冒险；财运=破财借贷；婚姻=男命克妻、女命第三者
食神：六亲=子女晚辈；心性=温和口福才艺；事业=技术艺术餐饮教育；财运=技艺生财；组合=制杀/见枭夺食
伤官：六亲=子女祖母；心性=聪明骄傲叛逆口才；事业=创意设计表演自由职业；财运=才华致富；组合=见官/生财/配印/制杀

## L3 · 五行体系 [不可变底层]

### 五行生克

```
生：木 → 火 → 土 → 金 → 水 → 木（循环）
克：木 → 土 → 水 → 火 → 金 → 木（循环）
```

### 旺衰判断维度

```
旺衰判断维度
├── 得令（月支是否生扶日干）
├── 得地（日干在地支的通根情况）
├── 得生（天干中有无印星生扶）
├── 得助（天干中有无比劫帮扶）
└── 综合：身强 / 身弱 / 中和
```

### 冲合刑害表

```
天干五合：甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火
天干四冲：甲庚冲、乙辛冲、丙壬冲、丁癸冲
地支六合：子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合火土
地支三合：申子辰合水、亥卯未合木、寅午戌合火、巳酉丑合金
地支三会：寅卯辰会木、巳午未会火、申酉戌会金、亥子丑会水
地支六冲：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
地支六害（穿）：子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害
地支相刑：子卯无礼、寅巳申恃势、丑戌未无恩、辰午酉亥自刑
```

### 干支相互作用

```
盖头：天干克地支
截脚：地支克天干
通根：天干在地支藏干中有同五行 → 天干有力
透干：地支藏干在天干出现 → 藏干发挥作用
拱：两干两支夹拱某字（如辰拱申、巳拱丑）
```

## L4 · 本书技法体系（盲派做功·职业取象）

```
盲派做功体系（段建业派）🔥🔥🔥
├── 做功总纲 🔥🔥🔥
│   ├── 制：制印/制官杀/制财/制比劫/制食伤
│   ├── 冲穿合刑拱：冲=动/穿=矛盾不合/合=得到或绑住/刑=开库做功/拱=暗动
│   ├── 库墓：刑冲开则为库（做功大）、不刑冲开则为墓（东西不是自己的）
│   ├── 宾主：年月宾/日时主；主位财入宾墓=帮人管财；合到主位=自己的
│   ├── 制者被制则不制
│   └── 用之字不可坏（用食伤不喜穿；独阴独阳不可坏/制）
├── 军官/军人断法 🔥🔥🔥
│   ├── 七杀配羊刃或羊刃库做工
│   ├── 伤官制杀或杀库做工
│   ├── 官杀配比劫或比劫库做工
│   ├── 火金组合、金水见火组合
│   ├── 戌土火库（火药/刀枪库）做工
│   └── 升迁应期（制印/制官杀到位之年）
├── 会计断法 🔥🔥🔥
│   ├── 亥水/子水被冲穿做工（数字之象）
│   ├── 亥子水为印星或财星与食伤组合做工
│   ├── 主位财入宾位墓（帮人管财）
│   └── 非见亥子水即是会计（须做功+象配合，防误区）
├── 老师断法 🔥🔥🔥
│   ├── 木火通明组合、木火做工（文类之象）
│   ├── 食神伤官做工或在门户做工（口才）
│   ├── 木火印星、金水伤官、印库做工
│   ├── 印星在月令为用、财虚透门户合印
│   └── 火土财星做工
├── 医生断法 🔥🔥🔥
│   ├── 食神伤官做工（官杀当病人、伤官当药）
│   ├── 金羊刃带库、火金组合（手术刀）
│   ├── 食神合印、土金食伤带印
│   ├── 库之取象（辰=药罐/化学；未=食神库；丑=金库/手术）
│   └── 分科取象（妇产：食神在门户+丑未冲；牙医：制酉金；药物：辰土化学；中医：卯木花草之象/木火药草类象）
└── 业务销售断法 🔥🔥🔥
    ├── 食伤落门户或年上生财临驿马
    ├── 财星虚透带驿马在年时
    ├── 天干食伤高透合虚印见财星
    ├── 门户+驿马=到处跑
    └── 行业取象（化妆品/电子产品/酒水/机械等）
```

## L5 · 本书用神体系

```
盲派不讲传统用神，讲"做功的主体字"🔥🔥🔥
├── 做功之字：谁在制谁、制得是否到位
├── 制到位（虚透被制/有根被制）→ 职业/财富成立
├── 制不了（无制、合到宾位、被反制）→ 该领域不成
└── 原局制不了靠大运见为吉（如伤官制官原局远，大运见到为吉）
```

## L6 · 本书神煞体系

```
神煞为取象辅佐，不作独立断法 🔥🔥
├── 驿马：到处跑、动工作、当兵应期（冲年上临驿马当兵）
├── 桃花：感情外遇、异性缘（庚为桃花、丁坐禄为桃花等）
├── 羊刃：军权、手术刀、身体损伤（羊刃做工掌军权）
└── 禄：身体/辛苦（用禄做功主辛苦劳碌）
```

## L7 · 本书大运流年体系

```
应期与岁运互动 🔥🔥🔥
├── 应期法则：合处逢冲、冲处逢合、原局有合流年应冲
├── 升迁/换职应期：制印之年、制官杀之年、官杀到位之年
├── 大运与原局互动：大运合八字合处逢冲为应期
├── 大运吉凶：杀带财三合印局=升官运；伤官合杀=提升；印化杀=提升
└── 流年断事：流年冲穿宫位星→离婚/分手/破财/生病之应
```

## L8 · 本书断事维度

```
职业断法（主维度）🔥🔥🔥
├── 军官/会计/老师/医生/业务销售（五大职业判定）
├── 职业稳定性（食伤在门户、印=单位、杀库=权力）
└── 行业取象（具体行业从象推出）
