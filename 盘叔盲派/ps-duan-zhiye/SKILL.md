# 职业断法（段建业派盲派·做功与取象）

## 什么时候用它

用户拿八字问职业时使用："帮我看做什么工作合适""我这八字是不是当官的命""适不适合当兵/考公""像不像会计/老师/医生/销售""这八字做什么生意"。

本技能不关注身强身弱、不取传统用神——断职业只看做功结构（谁制谁、制什么）+ 五行地支取象（是什么行业）。问婚姻、财运、健康、学业（非职业关联）时不用它，命例中的兼断内容只作辅助参考。

## 涉及的模型节点

- L4本书技法 > 盲派做功体系 > 做功总纲（制/冲穿合刑拱/库墓/宾主/制者被制则不制/用之字不可坏）
- L4本书技法 > 军官/军人断法
- L4本书技法 > 会计断法
- L4本书技法 > 老师断法
- L4本书技法 > 医生断法
- L4本书技法 > 业务销售断法
- L5用神 > 做功的主体字（制到位/制不了）
- L6神煞 > 驿马/桃花/羊刃/禄（只作取象辅佐）
- L7大运流年 > 应期法则（合处逢冲、冲处逢合、原局有合流年应冲）
- L8断事 > 职业（主维度）/婚姻/财运/健康/学业/六亲（兼断）

## 核心判断

看职业先看做功——八字里谁在制谁（制印/制官杀/制财/制比劫/制食伤），再加上五行取象定行业（亥子水=数字、戌土=火药刀枪、辰土=药罐化学、木火=文类、火金=军警手术）。职业从"做什么功 + 什么象"里定出来，不看身强身弱。

## 断法步骤

1. 先定做功结构：找出八字里谁制谁、用什么制、制得是否到位 [L4做功总纲 > 制/冲穿合刑拱]。做功的主体字是核心，制到位（虚透被制/有根被制）则该领域成立；制不了（无制、合到宾位、被反制）则该领域不成。
2. 再查库与宾主：日主坐库是否刑冲开（开为库能做功、不开为墓东西不是自己的）；主位财入宾位墓是帮人管财，合到主位才是自己的 [L4做功总纲 > 库墓/宾主]。
3. 然后取象定职业：看做功对象的五行地支类象——戌=火药刀枪库（军官）、亥子水=数字（会计）、木火=文类/印库=单位（老师）、辰=药罐/辛金=针头/丑=金库手术（医生）、门户+驿马+食伤=口才跑动（销售） [L4五类职业断法 + L1地支取象]。
4. 用大运流年验证与收敛：升迁/换职应期看"制印之年、制官杀之年、官杀到位之年、做功主体字出现之年"；应期法则"合处逢冲、冲处逢合、原局有合流年应冲" [L7应期法则]。同配置并列结论（如老师/医生、老师/媒体）用学历、大运、流年进一步收敛。
5. 兼断辅助：命例中职业断常与婚姻（无官看财为夫）、财运（官杀当财看）、健康（卯酉冲=关节痛）同断，可作交叉验证 [L8断事]。

## 判断标准

断对了会看到：命例原书反馈的职业与实际一致（如"08年财制印又提升了"）；职业判定与五行取象一一对应（亥子水→数字类、戌火库→军警类、辰药罐→医疗类、木火→文教类）；大运流年应期（制印/制官杀/做功主体字到位之年）兑现升迁换职。

断错了会看到：只看单因子下结论（如仅见亥子水就断会计、仅见食神就断老师）；把职业维度的"官杀当病人"与财运维度的"官杀当财看"混用；忽略库开/库闭（不开则东西不是自己的）与宾主（合到宾位=不是自己的）；不验证做功是否制到位（制不了则该领域不成）。

## 什么时候不该用它

1. 本套断法只回答"从做功与取象看像什么职业"，对同配置多种职业（老师/媒体/文职、老师/医生）只给倾向不给唯一答案——需要学历、大运、流年等外部信息进一步收敛。
2. 命例全部为军/警/医/教的体制内职业，对自由职业、创业型、艺术型职业覆盖不足；销售篇全是"打工式业务"，自营、合伙、股权类求财模式未展开。
3. 职业取象有明显时代局限：戌=火药刀枪、亥子水=珠算数字等是军旅/会计时代的类象，现代互联网、金融衍生、直播电商等新职业覆盖不到。
4. 健康、六亲、学业只在命例中顺带兼断（卯酉冲=关节痛、印为母、伤官合印=考学），没有独立成章系统规则，不可单独当作这些维度的断命工具使用。
5. 本技能与旺衰格局派立场相反：盲派不看身强身弱、不取传统用神，直接用旺衰派的强弱喜忌去套会得出相反结论。

## 出处

来自段建业派盲派职业断法讲义五篇：《如何看军官》《会计》《老师》《医生》《口才求财》（讲义成稿于 2000-2010 年代，网络教学+郝师亲传）。

原文："八字当中一般七杀配羊刃或羊刃库做工的、伤官制杀或杀库做工的、官杀配比劫或比劫库做工的、八字里火金组合或金水见火组合的、八字里带戌土火库做工的大部分都是当兵的或是军官。"

## 附：术语速查

| 术语 | 含义 |
|------|------|
| 做功 | 八字中一个字对另一个字的制、冲、穿、合、刑，产生"工作/作用"的结构 |
| 宾主 | 年月为宾位、日时为主位；东西在宾位被制/合到主位才是"自己的" |
| 库/墓 | 日主坐库要刑冲，开则为库（能做功），不开则为墓（东西不是自己的） |
| 穿（六害） | 矛盾、不合、暗中破坏；"被穿做工""穿倒" |
| 象法 | 干支类象直接定行业：亥子水=数字、戌=火药刀枪、辰=药罐化学、木火=文类、火金=军警手术、申=金融银行、酉=骨骼牙齿 |
| 官杀当财看 | 八字无财时，制住的官杀当财看（主发财而非当官） |
| 无官财当夫看 | 女命无官星，以财为丈夫 |
| 禄做功主辛苦 | 用禄（比劫）做工求财，主劳碌辛苦 |
| 财入宾墓=帮人管财 | 主位财入宾位墓 → 钱不是自己的，替单位管（会计断法核心） |
