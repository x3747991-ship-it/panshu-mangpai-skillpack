# 段建业（卜文）派 · 命理真诀断法（口诀断句）

> 流派来源：**段建业（笔名卜文）** · 编者导读本《命理真诀导读》，书中正文为宋英成等诸家命例，解评部分（「卜文解评」）为段建业本人。
> 本技能是《命理真诀导读》的**断法内核**，只保留「某八字配置 → 某人生结论」的可操作系统。
> 凡本书解评与原解冲突处，一律以**段建业链为主链**（原解标【原解】、段评标【段】）。

## 一、入口判定

**应该触发本技能**：用户给出（或口述）一个四柱八字，并想断具体人生领域——性格脾气、贫富贵贱／有没有钱、事业工作、学历、父母祖上兄弟子女、婚姻早晚与配偶、伤病灾寿、官讼牢狱、阴宅搬迁，或拿一个现成命例求逐条推。

**断前先做两件核对**：

1. **性别与时辰是否可信**。全书断法以"乾造／坤造"分男女星（女命看官杀、男命看财），并以四柱宫位（年祖辈／月父母／日夫妻／时子女）取象；时辰存疑或缺失时，仅断粗盘、不下六亲与寿元铁口。
2. **是否已定"日主强弱 + 喜忌"**。本书以**病药**为纲：先定日主强弱与病神（忌神）、再取用神。**用神管行运好坏，寿元星管生死**，二者不可混。

**不该触发本技能**（命中即转交或拒答）：只想排盘／只问"什么是伤官"等基础概念；问紫微斗数、六爻、梅花、奇门、手面相、实地风水；要求按子平格局（正官格、从格、化格）成破取用（本书无格局专章）；要把命理书蒸馏成技能包。

## 二、断法步骤

段氏断法总纲是「算命三步曲」（R001–R018），遇任何问题都按这个顺序走：

1. **一看日主强弱与病药**：定日主（L1日柱天干）→ 看月令、十神气势 → 取最强之病神（忌神）→ 依病取药取用神。 [L2十神 / L3五行 / L5用神]
2. **二看用神与运的好坏**：用神只判**行运吉凶**（"用神只管行运好坏，不管生死"）；对某配置先定喜忌，再看大运流年是扶是抑。 [L5用神>喜忌]
3. **三看寿元星与生死**：**生死单独一轨**——取寿元星（印／食／禄／病神），看其原神、墓库、空亡、死绝、被冲被合。 [L5用神>寿元星 / L7险运]
4. **四看应期（大运流年）**：以合冲墓穿为应期法；原局有合以冲为应、有冲以合为应；上五年重干、下五年重支。 [L7岁运>应期]

## 五、判断标准

断对了会看到：给出的结论能落到用户已知的**具体年份／事件**（某年结婚、某年离婚、某年丧夫、某年破财、某年入狱），且该年份能由"合冲墓穿应期"或"寿元星死绝"独立推出来；对原解冲突处，能说出段氏链为何更自洽。

断错了会看到：只堆断语却给不出应期；把"用神好坏"当"生死"（未用寿元星）；单看神煞（桃花／孤辰）就下结论；照搬"逢墓忌邀""冬至换年"等本书已驳伪诀。

## 六、什么时候不该用它

1. **时辰不可信时，六亲与寿元全盘失准**。宫位取象（年祖辈／月父母／日夫妻／时子女）与寿元星、应期都依赖四柱齐备；时辰存疑只作粗断。
2. **本书无格局专章**。不以正官格／七杀格／化格的成破取用；遇到须以子平格局定夺的场景，本技能覆盖不到（只用"从格／正格"判能否弃命）。
3. **流派口径不兼容**。段氏主张"用神自由心证、只求五行流畅""寿元星独立于用神"，与子平"月令定旺衰、以格局取用"常对同一八字给出相反结论；用户若已按子平体系排定，先声明口径差异、勿混用。
4. **神煞派／斗数派结论可能相反**。本书为**取舍派**、明确驳斥多项神煞伪诀；若用户坚持神煞定吉凶（如"孤辰带差错"），以本书立场先作说明。
5. **"克""妨"类断语不得输出**。书中反复要求"杜绝使用克、妨之类字句"；对婚姻、六亲不利的断语须以"信息同步""险运"表述，不得制造恐惧。
6. **近似性边界**。作者自承命理"只能作近似推断、没有绝对论断"（同八字者未必同断；许天愚七条断语中三条不符）。面向用户应说明这是流派断法、非确定事实。
7. **异本未随包提供**。任务卡提示的"风火集／电集／雷集"本次未提供，无法比对；涉及异本的断法不在本技能内。
