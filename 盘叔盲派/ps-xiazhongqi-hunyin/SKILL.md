# 夏仲奇断婚姻

> **缺口补充册见「夏仲奇断事补法」**：第三者的**转正应期**（等几年才转正、"合＝第三者／冲＝转正"机制）与**应期到月**（到某年子月／丑月）本册未收，见该册第四、五步。

## 什么时候用它

用户报出一个八字，问：什么时候能结婚、一生会结几次婚、会不会离婚、离几次、老公（老婆）怎么样、会不会克夫克妻、能不能结成婚、有没有第三者桃花、是不是晚婚不婚、嫁得远不远、对方年纪大不大——凡是"婚姻"这一格的问题，都用本技能。

**通用前置见「夏仲奇看命总纲」。** 宫位体系（L3）、十神六亲星定位（L4）、干支作用关系六件套（L5）、应期机制（L7）都在那里，本技能不重写；本技能只补"婚姻"这一类事专有的取法与断法。

## 核心判断

盲派断婚姻的第一动作，不是看日主强弱，而是**先给配偶星定准位**：男以财为妻，女以官为夫；女命局中无官杀，则以财看夫（年支之财为夫，主远方）。定准星之后，**夫宫（日支）与配偶星同参**——夫宫是"位"、配偶星是"人"，两者的合、冲、刑、穿、墓决定这段婚姻成不成、稳不稳、几时断（宫位与星位同参，通用见 L3、L4；作用关系见 L5；落到流年见 L7）。

所以同一张八字上，"能不能结婚"看的是配偶星有没有被库锁住（入墓不开婚），"稳不稳"看的是夫宫有没有被冲穿（穿夫宫主克夫），"几时结"看的是官星所管的年限里哪一年走财走官、或流年合去冲夫宫的那一方。**不看旺衰、不取用神、不定格局**；书中【邢解】偶用"忌神受冲"解释婚期，那是记录者本人的解释习惯、非夏仲奇原法，不得与主口径混用（见下 C01）。

## 怎么做

### 一、定配偶星（所有断法的第一步，通用前置见 L3、L4）

1. **男以财为妻**：数局中财星的数目与所落柱位，一位代表一任妻子。
2. **女以官为夫**：同样按官星落柱计数（月支之官为第一任夫、时上之官为第二任夫）。
3. **无官则以财看夫**：女命局中不见官杀，取年支之财为夫星，**年上主远方**，故此类命多主远嫁；再看所取之夫星（财）是否入墓库——**财入墓库则不开婚**、终身难成，应期取冲开墓库之运／年。【原文】"有财没官，以财看夫，财入丑库，因此无法结婚。"【邢解】"此造成为老姑娘的原因是因财宫都入库了，只有到六十三岁行入未运，冲开库，才能找到对象。"
4. **副夫宫法**：若某字与夫宫（日支）不见直接生克关系，但①它坐于夫宫之墓，或②它与夫宫合局——两居其一，该支即"副夫宫"，其上之干必当夫看。【段解】"甲木与午本无直接关系，但它坐戌，戌为夫宫之墓，又与夫宫合局，戌为副夫宫，故甲木必当夫看。"
5. **正副两夫宫时的第二夫取法**：夫宫出现正、副两宫时，以第二个夫宫论第二任丈夫，第二夫星围绕该宫取。该星与局中相穿则婚事来得晚；待运中该星得生、又冲去阻隔之支即成婚（本造以酉为第二夫星，酉戌穿故晚，戊辰运辛酉得生、冲去戌土而成婚）。
6. **一星两用**：一个字可同时代表两件事／两个人（酉金同时代表夫与子），则两事同到——再嫁即得继子；若该柱是命局所喜之处，此二人待命主好（子女那半边另见「夏仲奇断六亲」）。

### 二、断婚次（男以财数妻、女以官落柱计数）

1. 计配偶星之数：男计财星、女计官星，一星一任。
2. 逐位看该星是否受克、入墓、被刑：受克者主该任早亡（"前两个都得死"）；命中尚欠者，断其必再娶／再嫁，并给晚年再婚应期。
3. **日主甲坐申＋天干官杀混局主妻多**：【原文】"你这个人，甲木坐申，天干庚辛混局，妻多之命，我断你有五个老婆。"
4. **⚠「五妻之谜」未定（冲突 C02），三层照录**：
   - 【原文】说：甲木坐申、天干庚辛混局 → 妻多（"你这个人，甲木坐申，天干庚辛混局，妻多之命"）。
   - 【邢解】用妻宫多透计数："此造五妻之命是因**妻宫多透**，天干两庚一辛，再加妻宫申中暗藏庚金明暗共五个之故。"（同篇）
   - 【段解】明言"待以后再议"："此造如何正确得解，实属不易。**关于五妻的命理原因，待以后再议。**"（同篇）
   - 处置：**采【原文】口径**（甲木坐申、天干庚辛混局→妻多）；邢解的"计数法"标注为**存疑的解读**；数目不得当可靠指标输出（见"什么时候不该用它"）。

### 三、断婚期

1. **官杀所管年限**：看官杀何字、藏于何柱，定它"管到"的岁数区间（"巳中有个庚金，庚金是七杀，七杀管到十六岁"）；在该区间内取"走财走官"的流年为婚姻发动之年。
2. **正财流年合日元主婚应**：流年逢局中正财应期、且该财中所藏之干与日主相合（甲己合），该年结婚（"他十八岁结婚，是因在戊辰流年，局中亥水的正财流年应期，亥水中甲木，甲己合日元之故"）。
3. **夫宫夫星相冲断晚婚**：宫星相冲主晚婚，须逢流年合住冲方之一（丙辛合，令"两子不冲一午"）方可成婚。
4. **行官运而成婚，官运走完婚即尽头**：局中无明官、夫妻宫又受穿之造，唯行官运方有婚姻；官运一尽，婚姻也就到头（【段解】"局中无明官，夫妻宫又受穿，这种结构的婚姻会很差。但运行官运，故有婚姻，到己丑运时，已走完官运了，所以婚姻也就到了头。"）。
5. **多婚之命婚姻转稳看大运**：多婚造要到某一步大运才稳（"依我看，你到三十九岁行至丁巳运才能将婚姻稳住，在这之前你是结多少次离多少次"）；不可跳过前面的婚配等那一运再结婚（夏以"吃第五个烧饼"喻之）。

### 四、断克夫克妻

1. **火旺克妻，离婚即替代应凶**：日主（比劫）火旺、命硬克妻——妻留不住、多婚；若不离婚，凶不以"离婚"形式出，而以"老婆得病在床或猛灾伤亡"替代应凶。**离婚本身即是化解方式**。【原文】"他火旺克妻，是一定要离五次婚的，如果不离婚，不是老婆得病在床就是猛灾伤亡。"
2. **夫星合夫宫而时支穿夫宫主克夫**：夫星（官杀）合夫宫，时支来穿夫宫 → 克夫；行"穿"之支的大运即死夫（【段解】"观丙子一造，子水杀星合夫宫，当她丈夫看，见时支未穿，克夫信息，行未运，死夫。"）。
3. **夫星绝、死、受克、入墓则夫早亡**：绝于某支、死于某支、受克、入墓运，四事叠加断夫早亡（【段解】"以甲木当第一个老公，甲绝于申而死于午，还受辛金之克，难延命，当死于辛未运，甲入墓。"）。
4. **"弱绝怕入墓为枪库"**：官星在局中坐绝地、大运流年又入墓，以墓为"枪库"，断夫死于枪毙。【原文】"是挨枪子死的吧。"【邢解】"26岁壬年丈夫死于枪毙，土官星在局中坐绝地大运流年入墓，弱绝怕入墓为枪库。"此为该派独有象取命名。
5. **官星被刑被伤断夫凶死**：夫位官星先天受刑（戌刑丑）又受伤官（乙木）克 → 丈夫凶死之象；应期落克夫之字之运。【邢解】"此女，壬水日元，月下丑土官星，月干乙木伤官克子，年支〔戌〕刑丑，丈夫凶死之象。"
6. **断夫猛灾伤亡与起寡年岁**：夫星受克与子女星受克各自独立取，可同一命并断，并给出起守寡的岁数。【原文】"你丈夫猛灾伤亡，从二十八、九岁起，你就开始守寡。"

### 五、断桃花／第三者／同居

1. **运合夫宫夫星＝婚外情**：大运与日主相合、又合动夫宫（丁壬合、卯戌合），该运中当第三者。【邢解】"她十五至二十四岁壬戌运当第三者，是因大运与日主丁壬合、卯戌合，夫宫夫星全合。"
2. **合夫宫与冲夫宫之别**：同一夫宫，合（卯戌合）与冲（卯酉冲）所主的角色／关系状态不同——合＝第三者阶段，冲＝角色转变（婚后发财）。【段解】"壬戌运，是卯戌合，辛酉运是卯酉冲，对夫宫的作用不同，角色也因此而转变。"
3. **官杀本一人、状态不同＝角色转变**：局中官杀两见而申子之合使官杀归一，断为同一对象的角色转变（偏房转正／男友变夫）。
4. **暗合断同居**：日支与流年（或它字）暗合 → 遇男友并同居（暗合主不明不离的男女关系）。【邢解】"30岁丙年遇上男朋友，丑暗合，故而同居。"
5. **行十年桃花运主婚姻不顺**：大运以十年为一段，某段判为桃花运，该十年婚姻不顺；桃花不止一方犯，可夫妻前后各犯一段。【原文】"你四十一岁至五十岁行桃花运，在这十年间婚姻不顺。""到二00一（辛巳）年你对象也有外遇，从你五十一岁那年，你妻子遇上的一个男朋友，时间十年。"
6. **流年与命局合局即又起一段桃花**：流年与命局成局（丁丑起金局）→ 该年又来一段桃花，但"也不长久"，须另配散期。
7. **散期**：①同类相见即散——【原文】"1997年流年丁丑，会起金局，你还会再碰上一个，但这一个也不长久，我算你们到2000庚辰，**两辰相见就又得散**。"（辰辰相见必散）②原局之字与流年之字相同（两字相见）亦散，所断"散"都给到年月。
8. **桃花以运界定终期，行到墓库之运桃花止**：【原文】"我告诉你一个截止的时间吧，到戌运也就是你五十六、七岁，就没桃花了。"
9. **偏房缘定应期，到某年关系自散**：【原文】"依我看两样都不是，他是个骗子，你女儿该有一劫，你们大人想怎么样都没用，时间长了自然会有个了结。""我看最晚到1995年，到时他们自动就散了。"
10. **一次婚姻下不来**：女命婚姻星／夫宫显示婚姻不止一次的，直断"从你的命相看，一次婚姻是下不来的"，并须报出下一段出现之年与对象特征（【原文】"你呀，到了1997年，会再遇上一个有妇之夫，而且到时候，你还会给人家生孩子。"）。
11. **女命伤官坐空亡（歌诀）**：【邢解】"书曰：'女命伤官坐空亡，婚姻易遭阻挠、波折或口舌，婚后难得公婆喜爱，且与子嗣不和、或损子、或短缺男儿之虑。'"
12. **合动伤官＋夫宫伏吟主离婚**：流年之干合动局中伤官、流年地支又与夫宫（日支）伏吟，两条同现即该年离婚。【邢解】"甲戌年离婚，是因甲木合动己土伤官，戌夫宫伏吟。"

### 六、断婚姻走势（终止、延续、名存实亡）

1. **关系终止三档**：先以流年定"关系有所变化"之年 → 再以换运定"仍存在但不密切"的十年 → 最后以一个确切年龄定"彻底结束"，并连带同岁断身体之病（肾病或心脏病）。【原文】"你跟你儿子的关系已快到头了。到甲戌年（1994），你们娘俩关系就会有所变化。""你们娘俩的关系，就到你五十四岁时彻底结束！"
2. **墓库余气断关系的延续与减弱**：某星随大运走入墓库时，查墓库中是否藏有该星之余气；有余气则关系在该运内仍延续，只是不如前（分"延续但减"与"彻底断"两档）。【原文】"因为未中还有丁火，也就是说丁火在此时有余气。""等到了你下一步己未大运的时候，你和你的儿子仍然会有那种关系，可是不会那么密切了。"
3. **名存实亡之婚的"拖期离婚"判法**：状态判断与时间判断分开给——先判"名存实亡"（双方各有来往），再判"要离婚还会拖很久"，最后给拖到的具体年份；离婚年份之前仍继续犯桃花。【原文】"你的婚姻已名存实亡，两个人是你找你的相好，我找我的情人，但你要离婚还会拖很久，我算你到2001年才能离，但在这之前你还得犯桃花。"

### 七、断嫁老夫／嫁远方

1. **女犯伤官嫁老头**：满盘伤官 → 嫁年龄远大于己之夫（近六十岁）。【邢解】"满盘伤官嫁老夫。"此是盲师口诀；本书明确否定通行"见印入夫宫嫁年长、见伤食嫁年少"的说法——【段解】"许多书中讲，女命见印星入夫宫是嫁年长的，见伤食星则会嫁年岁小自己的，其理由是'印'是长辈，'伤、食'是晚辈。**这显然是未经检验的想当然的说法。**"（冲突 C03）
2. **行伤官运断嫁老夫**：大运走伤官，应期之内嫁年龄大之夫。【邢解】"大运甲戌流年乙亥，嫁到台湾，因行伤官运，嫁年龄大20多岁的老头。"
3. **合冲门户断嫁远方**：大运**合**局中门户 → 嫁到外地／外国（"甲戌大运，合局中门户，所以嫁到台湾"）；大运**冲**门户 → 亦断嫁远方（"辛丑大运，辛未流年，嫁到香港，大运冲门户，故而嫁远方"）。合、冲门户皆主离乡外嫁。
4. **官星宫位定配偶远近**：官在年柱 → 对象在远处；官在月柱 → 在近处（同学同事）。大运起得早，第一个运内逢官之流年所找之对象即为远处。【原文】"那是因为她的官在年上，如果官在月上，她就找同学找同事，是近处的。"
5. **距离取数**：无官以年支财为夫，年支主远方，距离按该支河洛数取。【邢解】"此女八字不见官星，以年上寅木才星为夫，合夫宫，年上为远方，日支亥水，水主六，故六千里开外。"【原文】"离咱这里得六千里开外，差不多快到国边了。"
6. **女命比劫旺则配偶年龄偏差大**：比劫旺（争夫之象）→ 所找对象不是年龄大很多就是小很多，不取相当年龄（本例大十四岁、后又小十三岁）。【原文】"还有，女命如果比劫旺的话，不是找年龄大的，就是找年龄小的。"
7. **合嫁老夫断婚姻**：夫宫逢合（合于老夫之支）→ 嫁年龄大自己十几岁之夫，且夫妻感情好（与"伤官嫁老夫"互为不同的触发口）。

## 判断标准

做对了会看到：先定准配偶星（男财女官、无官取年支财、必要时取副夫宫），再让夫宫与配偶星同参，把合冲刑穿墓逐条落到"成／不成、稳／不稳、几时断"上；婚次、婚期、克夫、桃花各走各的取法，结论能具体到某个流年或某步大运，且与求测者已有的婚姻事实对得上。

做错了会看到：跳过"定星"直接谈旺衰喜忌，或把"夫宫受冲"一律读成晚婚、一律读成当年成婚（见 C05）；把【邢解】的"忌神受冲"当成本派原法（见 C01）；把"五妻""三个老婆"这类数目当硬指标输出（见 C02）；把"嫁远方"顺推成"嫁老夫"（两者是独立断法）。

## 什么时候不该用它

1. **看到女命日支（夫宫）受冲，不要直接下"晚婚"或"当年成婚"的结论（冲突 C05，待裁决）。** 本书两处【邢解】给出相反说法、且未给分线：
   - 一说（冲＝障碍，须合解方成婚）：【邢解】"宫星在时支，财在年支弱受克无力生官，**夫宫夫星子午冲，故晚婚**，行辛卯大运，丙子流年丙辛合二子不冲一午，所以结婚。"（十六、老姑娘／块16）
   - 二说（冲＝触发，冲动日支之年即成婚）：【邢解】"29岁甲寅年结婚，甲申日元**流年寅冲申忌神故而结婚**。"（块23、块24）
   - 本书未给区分两说的判据。须回到"所冲之字是命局喜用还是忌神"上分辨，而这一点本书没有可复算规则；不能凭"日支被冲"一条下结论。
2. **不要用衰旺／忌神口径复验本派婚期结论（冲突 C01）。** 本书主体口径是不用衰旺（【总纲·弃衰旺】"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……所以说，当前流行的命理学所讲的东西，基本上是无用的。"），而【邢解】多处用"忌神受冲"解释婚期；【段解】自设质问已点明"用旺衰理论是讲不通的"。两套口径不能混用；凡以"这个字是喜是忌"复验断语者，本派答不了。
3. **时辰未校正，整套取法失效。** 定配偶星、数婚次、定夫宫都以四柱为准，报的时辰不准是常态，须先用兄弟姊妹数、婚期、六亲经历倒推校时（L2）。时辰无从校正时，婚次／婚期／克夫一类结论不可信。
4. **婚次、妻数这类数字型结论建立在旧时代婚姻可反复的社会条件上。** 本书"五妻""三妻""六次婚"依赖一夫多妻与婚姻可反复的旧社会前提；且作者本人就失过手——夏仲奇自述早年遇不断结婚离婚之造："我看出她婚姻多成多败，不断结不断离，但十八次还是没算出来，人家亲口告诉我的，后来细想，还是那时技艺不精呀。"故数目只能作"妻多、多婚、留不住"这一层，不得当可验证的硬指标。
5. **不要在"无官星"上只取一说当定论。** 老姑娘一例，【原文】说"有财没官，以财看夫，财入丑库，因此无法结婚"，【段解】却改口"一个无婚姻的女命不是八字中没有官杀星，而是有并占据其位置，但不能用"。两说并存，不可只取一说。
6. **凡以"官星到／合入夫宫"单条推结婚应期者，不采信。** 邢铭芬以己掌握的"正官星到又合入夫宫即有婚应"为任萍介绍不下十个对象，无一成；夏仲奇以"财官入库、冲库才开婚"论，两者结论可直接相反。
7. **"嫁远方"不得顺推"嫁老夫"。** 两者是独立断法；易麟所举嫁台湾之女命，男方与她年龄相当——远嫁的实际距离还受籍贯干扰，不能只由八字定。
8. **死法粒度只到"畜类"。** 十二生肖类化断死因只粗到"牛驴同类，皆是畜也，无需细分"，凡具体物种、具体死法（驴踢死／牛抵死）不列入可承诺范围；这是本派被当事人当场指出过的断错处。
9. **法所不能处须明说。** 本书多处对"某人为什么会有这样的婚姻"只留题不作解（如刘老太"有兴趣的读者可以分析一下"，小郭2000年冬所交男友"此造之解，暂作保留"）；遇此类追问，本技能不给死结论。
