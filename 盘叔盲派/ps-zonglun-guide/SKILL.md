# 盘叔盲派 · 使用指引（ps-zonglun-guide）v1.0

> 本指引是**交互流程层**，不替代断法。
> **断法一律交给 `ps-zonglun`（唯一入口）及其 28 个子技能**；本指引只规定：
> **什么时候问用户什么、按什么顺序问、每步给用户看什么、什么条件下才能往下走。**
>
> 核心目的有三个：
> 1. **规避排盘出错**——坚持「先要四柱、不要公历生日」；
> 2. **规避断错**——先出初校命书，再用**实证回溯校准**，最后才出终版；
> 3. **闭环交付**——终版命书之后，主动引导用户「细推后运」。

---

## 〇、一句话总纲

> **先锁盘，再锁人，后断命，终校准，再细推。**

| 步 | 名称 | 谁先说话 | 产出 |
| --- | --- | --- | --- |
| **第 1 步** | 锁四柱 | 系统请用户输入 | 四柱 ＋ 性别 ＋ 时辰（确认可用） |
| **第 2 步** | 锁背景 | 系统请用户输入 | 已发生的大事件 ＋ 六亲（父/母/夫/妻/子女）生老病死信息 |
| **第 3 步** | 出初校命书 | 系统 | **初校版命书**（明标「未经实证校准」） |
| **第 4 步** | 实证校准 | 系统比对 ＋ 请用户补漏 | **校准记录**（合／不合／推翻，逐条列明） |
| **第 5 步** | 出终版命书 | 系统 | **终版命书**（含附卷校准总表、错因记录） |
| **第 6 步** | 引导细推后运 | 系统主动提示 | 用户点选某步大运 → **该运专项详批** |

**铁律三条**：
1. **第 1 步没锁死，绝不进第 2 步。** 四柱错一位，后面全废。
2. **第 4 步的校准必须「重判机制」，不是「换措辞」。**（详见第 4 步「假修正禁忌」）
3. **第 5 步之后必须主动给第 6 步的引导。** 不给，用户以为交付完了。

## 一、第 1 步 · 锁四柱（本指引最重要的一步）

### 1.1 为什么必须先要四柱，不要公历生日

> **★ 一条硬规矩：优先向用户索取「四柱八字」，不要先要「公历生日」。**

理由（务必理解，不是形式）：

| 问题 | 要生日会怎样 | 要四柱会怎样 |
| --- | --- | --- |
| **节气换月** | 生日落在节气交界（如立冬前后、大雪前后），谁排都可能排错月柱 | 用户从万年历/排盘软件抄，**月柱是既成事实，无需再推** |
| **真太阳时** | 生日＋钟表时刻还需算经度修正、均时差，多一道出错环节 | 用户输入的时支**已是修正后的结果** |
| **跨年换柱** | 生日在立春前后，年柱易错（是否按农历年、是否按立春） | 年柱直接给，**无歧义** |
| **日柱** | 日柱需查万年历，手算极易错 | 日柱直接给 |
| **责任归属** | **排盘错了，责任在系统**——系统背锅，用户的命书全废 | **排盘责任在用户**——系统只管断，出错可追溯 |

> **一句话：排盘是「一次性、可验证、用户手上有现成答案」的动作，不该由系统承担。**
> **系统把精力全部留给断法，这才是本技能包的强项。**

### 1.2 向用户要什么（照抄这段问法）

第一次开口，**只问这三样**，不要夹杂别的：

```
请先给我这三样，我才能开始：

1. 四柱八字（年月日时，四组干支）
   例：甲子 乙亥 庚戌 癸未
   ⚠ 请从万年历或排盘软件直接抄四柱，不要给我公历生日——
     生日还要过节气、真太阳时两道关，容易排错；
     直接给四柱，等于排盘这一步你自己已经核过了。

2. 性别（乾造／男，或坤造／女）

3. 出生的钟表时间（几点几分）＋出生地（省市）
   时间用于两件事：① 确认时支有没有跨时辰边界；
                   ② 后面断应期时看能否精确到月。
   ⚠ 若时间只记得大概（如「下午三四点」），也先给我，我会标注存疑。
```

### 1.3 拿到之后的处理顺序

| 情况 | 处理 |
| --- | --- |
| **四柱齐全 ＋ 有性别** | → 进 1.4「四柱自检」 |
| **四柱齐全 ＋ 无性别** | 请补性别；未补前只断与性别无关的维度（见 `ps-zonglun` 第六节） |
| **四柱不全** | 请补全。**不要试图从生日反推**——那就回到 1.1 的坑里了 |
| **只给生肖／只给生日** | **要求补四柱**（可提示：去万年历或任意排盘 App 查一下，30 秒的事） |
| **四柱写了但可能有 OCR 形近字** | 按 `references/仲裁摘要.md` 第六节校正（见 1.4） |

### 1.4 四柱自检（必做，系统自己查，不劳用户）

拿到四柱后，**系统内部先跑一遍自检**，有问题再回头问用户：

**① 形近字校正**（`仲裁摘要.md` §六，必执行）

| 形近字组 | 校正 |
| --- | --- |
| 巳 / 己 / 已 | 地支「巳」≠ 天干「己」；「已」常是「巳」的误写 |
| 戌 / 戍 | 八字只用「**戌**」 |
| 午 / 牛 | 高频混淆 |
| 未 / 末 | 「**未**」是地支 |
| 酉 / 西 | 「**酉**」是地支 |
| 卯 / 印 | 地支「卯」≠ 十神「印」 |

**② 干支合法性**：天干（甲乙丙丁戊己庚辛壬癸）× 地支（子丑寅卯辰巳午未申酉戌亥）；干支阴阳须同（阳干配阳支）。**不合法的组合 → 退回问用户**。

**③ 时辰边界复核**（**这一步是本指引的核心价值之一**）

> 只有「钟表时间 ＋ 出生地」都给齐了，才能做这一步。

算法（牢记，可复用）：

```
真太阳时 = 钟表时刻 + (出生地经度 − 120) × 4 分钟 + 均时差
```

- **经度修正**：(经度 − 120) × 4 分钟。**东经 120° 以东为负、以西为正**（如成都 104°E → −64 分钟）。
- **均时差**：按出生日期查（幅度约 ±16 分钟，11 月初约 +15~16 分，2 月中约 −14 分）。
- **判定口诀**：**先看用户给的时刻距「时辰边界」还剩多少分钟，再看「经度修正 ＋ 均时差」能不能吃掉这个余量。**
  - 修正后**仍在本时辰内** → 时支**确认可用**；
  - 修正后**跨到相邻时辰** → ⚠ **时支存疑**，须走 1.5。

**例（本技能包首个实战盘）**：1984-11-12 14:45 · 广东梅州
- 梅州约 **116.12°E** → (116.12 − 120) × 4 = **−15.5 分**
- 1984-11-12 均时差 ≈ **+15.3 分**
- → 14:45 − 15.5 + 15.3 = **14:44** → **未时（13–15 时）**，距上界 16 分钟 → **确认可用**
- （巧的是两项修正几乎抵消，但**不能因此就不算**——换个经度或换个日期，结果会完全不同。）

**④ 起运数复核**（`ps-tiwei-jichu` 口径）

- 阳年男／阴年女 → **顺排**；阴年男／阳年女 → **逆排**。
- 从生日数到**相邻的节令**，得天数 ÷ 3 = 起运年数；**余 1 舍掉、余 2 进 1**。
- ⚠ **夏派另有一套口径**：「X 岁扎根 X 岁运」（随命而定，非固定三岁起运）——**若主断走夏派，须另标**（`ps-xiazhongqi-tiekou`）。

**⑤ 旬空复核**（**两柱都要查**，不可只查日柱）

- 年柱定一旬、日柱定一旬，**两个旬空都要比对本盘四支**。
- 口诀（`ps-tiwei-zuogong`「空官判式」）：**「两柱都要查，只用日柱会漏掉年柱带来的旬空。」**
- ⚠ **易错**：年柱带来的旬空常被漏查，而它往往就是全盘第一决定项（本技能包首个实战盘里，年柱甲子旬空**戌亥** → 月支、日支双落空，是全盘地基）。

### 1.5 时支存疑时的处理（不许硬断）

| 情况 | 处理 |
| --- | --- |
| 时辰**确认可用**（自检通过） | 正常进第 2 步 |
| 时辰**存疑**（跨边界／时间只记得大概） | **第 0 层走 `ps-xiazhongqi-tiekou` 校时**（仲裁 #13）：用**兄弟姊妹数、婚期、六亲经历**倒推 |
| 校不出 | **声明只断原局、不断流年**（`ps-zonglun` 第 0 层口径）——**不许硬出流年铁口** |
| 用户**坚持不校** | 全部时柱相关断语标「条件式结论」，并在命书页首写明 |

> **★ 校时的最高效手段：拿实证反查。**（本技能包首个实战盘的经验）
> 「妻少十岁、生女、做晚辈位的内容业」三项全靠时柱——**若时辰错，这三项都解释不了**。
> → **已知的实证履历，是比「问兄弟几个」更硬的校时证据。**
> → 所以：**第 1 步若拿不到确定时辰，可以先进第 2 步拿背景，用背景反校时辰。这两步允许回环。**

## 二、第 2 步 · 锁背景（实证校准的弹药）

### 2.1 为什么必须先拿背景，再断

> 盲派断法**不看旺衰、只读取象与作用**——这决定了它有一个天然优势：
> **每一个断语都可以被「已发生的事」直接验真或验假。**
>
> 所以正确的做法不是「一口气出完整命书」，而是：
> **先出一份「初校」，再用用户的人生实况把它砸一遍，砸不动的才是真的。**

**这一步拿到的东西，就是砸初校书的锤子。** 拿得越多，命书越准。

### 2.2 向用户要什么（照抄这段问法）

```
四柱我记下了。开始之前，请再给我一份「人生已发生的事」——
越多越好，越具体越好，尤其是年份。这份东西是用来「校准」的：
我会先出一版初稿，然后拿你这些实况去对，对不上的地方我重判。

请按下面五类尽量说：

【一、人生轨迹大事件】（有时间点最好）
  · 上学/学历（哪年、什么学历）
  · 工作（哪年起、什么行业、受雇还是自己干、换过几次）
  · 创业/开业/关停（哪年）
  · 升迁/调动/失业（哪年）
  · 买房/搬家/移民（哪年）
  · 破财/负债/官司/是非（哪年）
  · 大起大落的具体年份（哪怕只记得「大概哪几年顺/哪几年背」）

【二、婚姻感情】
  · 是否已婚、结婚年份
  · 配偶年龄比你大还是小、差多少
  · 夫妻关系怎样（好/一般/常吵/异地/分居/离异）
  · 有没有二婚、复婚、第三者

【三、子女】
  · 几个孩子、男还是女、大致出生年份
  · 顺产还是不顺、有没有夭折/流产/抱养

【四、六亲（最重要的校准弹药）】
  · 父母：健在否？若已故，哪一年、什么原因？
  · 父母关系、是否离异/再婚
  · 兄弟姐妹几个、排行、有无早逝
  · 子女/配偶有无病、灾、夭折

【五、疾病与健康】
  · 本人有无慢性病、大病、手术、意外（哪年）
  · 家里有没有遗传病、精神类疾病

⚠ 两点说明：
  ① 记不清年份就说「大概」，我按大概处理；
  ② 觉得不方便说的可以跳过——但六亲的生老病死信息越全，
     命书校准得越准（这是本派断法最能兑现的部分）。
```

### 2.3 拿到之后的处理

1. **建档**：把用户给的每一条，整理成「**年份 ＋ 事件**」的清单，作为**校准弹药库**。
2. **不要在这一步就下断语**——先收着，等第 3 步初校书出来再逐条对。
3. **若用户只给了一点点**（如「想算算婚姻」）：**不阻断**，照常出初校书，但在命书里**标明「未获实证校准」**，并在第 4 步再次邀请补充。
4. **若用户拒绝给背景**：同样不阻断——**但终版命书必须写明「本版未经实证校准，置信度整体下调」**。

## 三、第 3 步 · 出初校命书

### 3.1 走法

**交回 `ps-zonglun` 七层调度**（本指引不替代断法）：

```
第 0 层  定盘与前置（四柱已锁；含 ps-minglizhenbao 五张前置卡）
第 1 层  定层次（ps-tiwei-zuogong 体用做功 ＋ ps-tiwei-geju 层数锚）
         ＋ ps-duan-zhongji 定正局/反局方向
第 2 层  按领域路由（见 references/路由表.md）
第 3 层  互证（口诀 E5 两说并出 ＋ 神煞佐证 ＋ 命例 U-####）
第 4 层  象法定实物（ps-duan-xiangfa）
第 5 层  边界与仲裁（references/仲裁摘要.md）
```

### 3.2 初校书的格式要求

用 `ps-zonglun` 的统一报告格式，**外加一个页首声明**：

```
⚠ 本版为「初校版」——未经实证校准。
  断语依据结构推演，待用命主人生实况逐条核对后方可采信。
```

内容至少含：
- 序 · 怎么看这份命书（含体系声明：不看旺衰、不取用神）
- 上卷 · 盘面与结构（四柱表、藏干、起运、旬空、**时辰校验**）
- 中卷 · 七层推演（含分域细断）
- 下卷 · 运程与应期
- **附卷 · 待校准项清单**（★ 关键：把每一条可被验证的断语列出来，方便第 4 步逐条打钩）

### 3.3 附卷「待校准项清单」的写法（本指引的独创要求）

**把命书里所有「能被实况验证」的断语，抽成一张清单**，格式：

| # | 断语 | 该断语的结构依据 | 待命主确认 |
| --- | --- | --- | --- |
| 1 | 事业属「技术＋传播」复合业态 | 取象四门（干支/十神/宫位/神煞） | ☐ |
| 2 | 婚姻：某处偏薄／或某处偏旺 | 配偶宫状态（空亡/刑冲穿合） | ☐ |
| 3 | 子女数／性别倾向 | 子女星阴阳 ＋ 宫位 | ☐ |
| 4 | 父母：早逝或同住倾向 | 财临墓地 / 印星落宫 | ☐ |
| … | … | … | ☐ |

> **这张清单是第 4 步的作业本。** 没有它，校准就会漏项。

## 四、第 4 步 · 实证校准（本流程的灵魂）

### 4.1 校准的三种结果

拿第 2 步的弹药库，**逐条打钩**，每条只能落三档：

| 档 | 含义 | 处理 |
| --- | --- | --- |
| **✅ 合** | 断语与实况一致 | 保留，**置信度提升**，标注「已验」 |
| **⚠ 不合** | 断语与实况相悖 | ★ **进入 4.2「机制重判」** |
| **◻ 未验** | 用户未提供该维度实况 | 保留断语，**置信度不变**，列入存疑 |

### 4.2 「不合」时的处理：机制重判，不是改措辞

> **★★★ 本指引最要紧的一条规矩（血的教训）：**
>
> **当实证与断语相悖时，把断语「换个说法」不是修正，是掩盖。**
> **必须回去重判底层机制。**

**反面教材（真实发生过，务必记住）**：

| 轮次 | 做法 | 结果 |
| --- | --- | --- |
| 初稿 | 判「配偶宫空亡 → 婚姻不圆满、有耗」 | ❌ 实证否定（夫妻极好） |
| 「修正」 | 改成「纽带偏精神性、不靠物质维系」 | ❌ **假修正**——只换措辞，底层仍在解释「空亡导致了什么」 |
| 真修正 | **重判机制**：空亡＝「初始为虚」非永久失效；本盘该字有根有生、被合、被刑动 → **已被填实** → **在本盘不产生该现象** | ✅ 与实证一致 |

### 4.3 四条可复用的重判路径（按序排查）

**当某条断语被实证推翻，依次怀疑这四样**：

| 序 | 排查项 | 问法 |
| --- | --- | --- |
| ① | **时辰** | 该断语是否依赖时柱？若依赖 → **先怀疑时柱**（回去反校） |
| ② | **宫位落点** | 该六亲/该事的宫位认定对不对？宫为位、星为辅 —— **位定错，断语必错** |
| ③ | **引用条件** | 引用的条文，**触发条件是否逐项成立**？ |
| ④ | **机制层面** | 前三条都排除后 → **重判该字的机制**（见 4.4） |

**③ 的典型错例**（真实发生过）：
> 引用了「时空 → 子女迟育或损伤」这条，但**该条的触发条件是「时支落空亡」**，而本盘**时支并不空**（空的是日支、月支）。
> → **引用条件不符，这条本不该用。** ★ 教训：**引用任何规则前，先核触发条件逐项打钩。**

### 4.4 四条「以象代验」的禁忌（每一张盘都要守）

> 本派讲「**象优先于理**」，但这**不等于「象可以代替条件核对」**。
> **象定的是方向与性质；档位、层数、吉凶轻重，仍须回到条文逐条验。**

| 禁 | 错在哪 | 正解 |
| --- | --- | --- |
| **见空亡即断坏** | 空亡 ≠ 破坏 | **先问「有没有被填实的条件」**（有根有生？被合？被刑动？）——有 ⇒ 已被填实，**不产生该现象**；无 ⇒ 才按「务虚/减等/有名无实」读 |
| **见刑即断坏** | 「刑」≠ 伤害 | 本派明定：**刑＝开、动、取用**（「丑未、辰戌冲库与丑戌刑库效率最高」——刑是最高效制法之一） |
| **见冲即断坏** | 「冲」≠ 破坏 | 本派明定：**冲＝得到、互有、交换，一般不具破坏性**；且**墓逢冲则开**（喜冲） |
| **见虚即套低档** | 档位须回条文核 | 如「合财三档」：**先核「所合之财虚不虚」＋「坐支得不得旺」**，再落档 |

### 4.5 校准的产物：校准记录

**逐条写明**，格式：

| # | 断语（初校） | 实证 | 结果 | 处理 |
| --- | --- | --- | --- | --- |
| 1 | 事业为「技术＋传播」复合 | 会计→电商→知识付费→AI命理自媒体 | ✅ 合 | 保留，提置信 |
| 2 | 配偶宫空亡→婚姻有耗 | 夫妻极好、常年在同住、无异地 | ⚠ 不合 | **机制重判**：该字已被填实 → 不产生现象 |
| 3 | 子女宫临刑→事多牵连 | 三女皆顺产、无波折 | ⚠ 不合 | **机制重判**：刑＝开动非伤害；且「时空」条引用条件不符，撤回 |
| 4 | 合财落第三档 | — | ⚠ 不合 | **条件核对**：所合之财不虚（坐长生、有根）＋坐支得旺 → 落**第一档** |

> **★ 校准记录必须公开给用户看，不得藏在内部。**
> 用户看到「哪条被推翻、为什么推翻」，才对命书有信心——**这比「全对」的假象可信得多。**

## 六、第 6 步 · 引导细推后运（不许漏）

### 6.1 终版命书交付后，必须主动给出这段引导

```
命书到这里是完整的。接下来还能往下做一件事——

【细推后运】
命书下卷里，每一步大运我都只给了一段总批。
如果你想把某一步单独拆开细推（干支逐支作用、库中之物、做功方式怎么变、
逐流年引动点、分域详断），我可以另起一篇专门做。

建议优先推这两步：
  · 当前所在的运（最实用——未来几年的事都在这步里）
  · 下一步交运的运（最重要——换运前后结构会变，值得提前看清）

你要推哪一步？给我大运干支（或虚岁区间）就行。
也可以按「年份」问，我帮你换算到对应的大运。
```

### 6.2 单运专项详批的标准结构（可复用）

| 节 | 内容 |
| --- | --- |
| **卷首** | 为什么这一步要单独推（它动到了本盘的哪个关键结构） |
| **上篇 · 整体结构** | ① 定位（虚岁/公历/实岁/宫位段）② 运干（十神 + 伏吟/透干）③ **运支逐支全查**（对年月日时四支逐个过）④ 核心作用定性 ⑤ **做功方式怎么变** ⑥ 净定性表 |
| **中篇 · 逐流年** | 逐年：干支 + 与局中作用 + 与运支作用 + 引动等级。**只定应期，不断吉凶** |
| **下篇 · 分域详断** | 事业 / 财 / 婚姻 / 子女 / 健康 / 六亲，逐域给结构依据 + 断语 + 置信度 |
| **收卷** | 统一报告（含仲裁与边界、存疑声明） |
| **附** | 一句话总纲（这步运的准确定性） |

### 6.3 单运详批的四条硬规矩

1. **运支必须「逐支全查」**——对年、月、日、时四支逐个过一遍，不可只看一处。
   （本技能包实战发现：一个运支常同时牵动三四支，漏查一支就会漏掉整个结构。）
2. **先判「冲的是实库还是空壳」**——冲库之运，**若被冲之字已填实 → 按「冲动其库中之物」读（走开库支）**；若是真空壳 → 大幅减等。
3. **必须问「这一步把原来的做功方式改成了什么」**——**改方式 ≠ 断方式**。
   （本技能包实战：某步运把「制财」改成了「生财」，对本盘反而是更顺势的一步。）
4. **流年只定应期，不断吉凶**；且**冲库之运中，「出库年」与「显形年」通常不同，须分开标**（实战：冲库年后的一到两年才见官星/印星透干＝名分落定）。

## 八、失效场景（本指引什么时候不该用）

| 场景 | 处理 |
| --- | --- |
| 用户要**排盘教学** | 让位；本指引明确「不要生日要四柱」，是**取巧**不是教学 |
| 用户**只给生日、坚决不给四柱** | 可以帮查（用万年历口径）——**但必须标注「此四柱由系统代排，未经用户核验，出错风险由排盘环节承担」**，并优先请用户复核 |

| 用户**只要一两个字的解释**（「什么是空亡」） | 概念查询，不进本流程 |
| 用户**要求断死期/断牢狱/断重病** | 概率化措辞＋免责边界（不作医疗/法律/投资依据），不出确定结论 |
