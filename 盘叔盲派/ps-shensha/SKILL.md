# 盘叔盲派·神煞取象断法

## 什么时候用它

- 已经把四柱八字（年、月、日、时）和胎元/命宫/身宫排好，想系统查清命局**带了哪些神煞**、各神煞**取法对不对、吉凶轻重、落在哪个人生领域**。
- 具体问题如："我有没有天乙贵人""空亡怎么查、坐空亡是不是不好""女命带劫煞羊刃凶不凶""童子煞/将军箭怎么化解""命宫坐什么神煞代表什么"。
- 本技能是**断法辅助**：它回答"某个神煞配置 → 人生某个领域应吉应凶"，但神煞**只取象、不独立定命**，最终贫富贵贱须合参五行旺衰（见「什么时候不该用它」）。
- 全程须按**盲派师传起法**（命宫太阳过宫、四大空亡以日柱查、天乙贵人按《御定六壬直指》"甲戊庚牛羊"），与书房派/江湖派起法不同时以盲派为准——这是本技能与普通子平神煞技能的本质区别。

## 涉及的模型节点

- L1 四柱（年/月/日/时）、L2 十神、L3 五行（冲合刑害）——神煞落宫与应事维度的底座
- L4 神煞体系（本书技法）：
  - 基础盘模型：胎元 / 命宫 🔥🔥🔥 / 身宫 / 三垣（暗八字，命宫为核心）
  - 吉神类：天乙贵人 / 天月二德 / 文昌·学堂词馆 / 三奇 / 魁星·天罡 / 德秀 / 太极贵人 / 华盖 / 禄神·驿马
  - 凶煞类：劫煞 / 亡神 / 羊刃 / 空亡（旬空·互换空亡·截路空亡）/ 四大空亡 / 天煞孤星 / 冲天煞·戟锋 / 童子煞 / 将军箭 / 马倒禄斜 / 小限流年凶星
  - 长生十二宫（长生沐冠临旺等，桃花＝沐浴＝咸池）
- L7 大运流年（流年神煞断诀、岁运并临、凶煞逢冲有合解化）
- L8 断事维度：婚姻 / 健康·灾祸 / 事业财运 / 学业 / 性格 / 六亲·子女 / 化解趋吉

## 核心判断

1. **神煞只取象、不作独立断命**——每条神煞断法必须落到它佐证哪类断事（财/婚/业/健康/灾祸），不能凭"带某煞"直接下贫富贵贱铁口。这是作者立场，也是本技能的纪律。
2. **盲派起法有秘传**：命宫须用太阳过宫精确法；四大空亡**以日柱为主**查；天乙贵人否定"甲戊兼牛羊"。起法错了，断语全错。
3. **神煞吉凶随配置而变**：同一神煞坐吉神/坐凶位、逢冲合空破时吉凶相反。断语须带"触发条件 + 失效条件"，不许一成不变。
4. **凶煞可化解**：化太岁、送替身、挡箭碑、合冲解刑等化解法属于民俗手段，可作趋避参考，但绝不作医疗/法律/投资替代建议，涉及高风险的断语一律概率化措辞。

## 断法步骤

1. **先排定盘**：排出四柱 + 胎元 + 命宫 + 身宫（三垣），再按盲派起法逐类查神煞。命宫以太阳过宫法定位，是全书核心——命宫所临神煞决定一生重点吉凶。 [L4神煞体系>基础盘模型>命宫]
2. **按类别盘**：先吉后凶，逐类排查——基础盘神煞（胎/命/身宫所临）→ 吉神（贵/德/文/华盖）→ 凶煞（劫/亡/羊/空/四大空亡/孤星/童/箭/马倒禄斜）→ 长生十二宫 → 小限流年凶星。每查出一项，记"取用依据 + 落宫/所临十神 + 是否被冲合空破"。 [L4神煞体系>吉神类>凶煞类]
3. **判吉凶方向**：把每个神煞的吉凶，代入它坐的宫位与所临十神、以及是否坐贵/逢冲/空破，判定是"得势应吉"还是"失势应凶"。凡同一神煞吉凶互悖者，按本技能「冲突仲裁」裁决，不并列下断。 [L4→L3五行冲合刑害]
4. **落到断事维度**：把神煞吉凶归到婚姻 / 事业财运 / 健康灾祸 / 学业 / 性格 / 六亲子女之一（或多项），点明"待大运流年引动方发"。 [L8断事维度]
5. **补化解与免责**：逢凶煞给化解法（化太岁/送替身/挡箭碑等），并明确这些属民俗手段，不作替代性建议。 [L4神煞体系>凶灾化解]

### 冲突仲裁（吉凶互悖时一律适用）

- **裁决根本**：神煞只取象佐证，最终以五行旺衰与格局为本定贫富贵贱，神煞只作加减，不得单独定案。
- **冲突① 天月二德**："主贵/贵人之妻" vs "只锦上添花不决富贵"→**以"不决富贵"为作者真主张**，传统表述降级为扶助判据（第9块）。
- **冲突② 三垣空亡**："吉凶反论（总则）" vs "身宫财不聚（单体）"→**反论为总则优先**，身宫财不聚为默认断，须先过反论复核。
- **软性张力③ 岁运冲命宫**："主凶灾" vs "主迁居换房"→非冲突，前者断吉凶、后者断应事，凶年常兼迁动。
- **非冲突登记（防误标）**：劫煞凶 vs 配官贵→武贵；空亡凶 vs 财库我宫空→反发财；四大空亡短寿 vs 叠深则夭；羊刃凶 vs 带官印→吉论；华盖孤 vs 坐墓→享清闲福。均以"触发条件+失效条件"保留，不得删除。

## 判断标准

- **起法正确**：命宫太阳过宫、四大空亡以日柱查、天乙"甲戊庚牛羊"——起法对，断语才站得住。
- **坐宫清楚**：每个神煞都标明落三垣哪一宫、落哪柱、所临十神、是否被冲合空破。
- **落到断事**：每条断语都能说"它佐证婚姻/事业/健康/学业/性格/六亲/趋避哪一项"。
- **带失效条件**：吉凶神煞同见时给"触发+失效"双条件，不铁口；凡死亡/手术/坐牢/夭折等高风险断语一律概率化措辞并附免责。
- **断错会看到**：跳过五行旺衰直接以神煞定生死富贵、遇神煞互悖仍并列下断、把民俗化解说成必然应验——这些都不符合本技能纪律。

## 什么时候不该用它

- **须先排好盘**：本技能是"排查神煞配置与吉凶"的辅助技能，直接给四柱问"这人贫富贵贱"、且要求以五行旺衰格局定论时，不单独用本技能定案——那须配格局/旺衰技能，本技能只作佐证。
- **纯问排盘起算**：问"怎么起大运/怎么算胎元命宫/怎么算神煞公式"这类排盘操作，不涉断法，不触发。
- **跨流派起法冲突**：用户用的是书房派/渊海子平起法（四大空亡以年柱、天乙"甲戊兼牛羊"）时，本技能断语与其前提不同，须先说明所依盲派口径，防起法错判全盘错。
- **儿童健康高风险**：将军箭、小儿关煞、四大空亡等用于真实幼儿/涉夭折，须特别标注"仅作命理参考，医疗保健以医生为准"，不得制造恐慌。
- **替代性建议**：化太岁、送替身、挡箭碑等属民间习俗，不替代医疗、法律、投资建议；涉及死亡、手术等断语须伴随概率化措辞与免责声明。
