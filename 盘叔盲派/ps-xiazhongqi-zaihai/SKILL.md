# 夏仲奇断官非灾祸

> **缺口补充册**：①疾病的**脏腑对应／断寿两档死期／死因取象**见「夏仲奇断健康疾病」（本册健康层只到禄／火／羊刃）；②**"不入公门"的反面判法**与**穿刑的动态力量对比**（受克方得生反强）见「夏仲奇断事补法」。

## 什么时候用它

用户报一个八字，问下面这类问题：

- "这命会不会坐牢？判几年？哪一年出事？"
- "他会不会有灾？会不会出凶事？因什么事？" / "为什么发了财反而出事？"
- "我身体哪里会出问题？会不会受伤、会不会残？"
- "这命能有寿吗？能活多久？什么时候是关口？"
- "这案子能不能破？凶手抓得到吗？"
- 也可反向识别身份：这人是走黑道的、是当官的、是小偷、还是持刀的劫贼？

**通用前置见「夏仲奇看命总纲」**——本技能只写官非、牢狱、伤灾、凶死、寿元、破案这一门。看命总则（L1 不取用神、不衰旺）、定盘与时辰校正（L2）、宫位体系（L3，年为祖上父母、月为父母兄弟、日为自身配偶、时为子女，宫位与星位同参）、干支作用关系六件套（L5 合冲刑穿墓空）、理五行与象五行取象法（L6）、应期机制（L7 合动／库到／伏冲）都在总纲里，不在这里重写。

问六亲存亡的见「夏仲奇断六亲」，问配偶与凶死的夫星那一层见「夏仲奇断婚姻」，问财路与官贵的见「夏仲奇断财禄事业」。

## 核心判断

盲派断灾祸的第一判据是**"有生无制"**，不是看日主旺不旺：**凶的结构有没有被制住**，才是出凶与否的分水岭。凶神（伤官、劫财、七杀、羊刃之类）得力而全无制衡，一到生扶它的运就出凶；凶神被合、被制则凶解；大运未过（晦运未过）则次年再犯（L5）。

断死另立一条**"根"**论：日主唯一之根被刑坏（L5 刑），或寿元星（食神）落空亡、又被大运天干地支合绊而不能生（L5 空亡＋合），皆主损寿；凶死则以原局某一凶支为根，运使它得强根、与原局凶支成冲战，即成凶死（L5 冲战）。

应期不在"忌神到位"，而在"合动／库到／伏吟"把该字牵动的那一年（L7）；宫位（L3）与象（L6）用来定"何人、何处、何物"。三者缺一，结论就落不到具体年份与具体事上。

## 怎么做

### 一、断牢狱

1. **看官星有没有被穿**（L5 穿）。官星被穿＝违反法律；穿官的那一支即"违法星"。核心是找穿官之支，不是找日主旺衰。
2. **看穿官之支里藏的伤官有没有透干**。伤官透于运，即犯法得财之应期——这是"支转干应法"，与断克父应期同一机制（L7）。
   - 【邢解】"为何是非法之财，是因局中戌土与酉官相穿，意为违反法律，戌中含伤官丁火，在运中透出，是为应期，丁生己故是非法之财。"（三、牢狱命定）
   - 【段解】"此命之核心是看戌土，戌为违法星。"
3. **认犯罪组合**：劫财、伤官、又穿官，三者齐备即"犯罪组合"，主牢狱之灾；但有组合不等于立刻发案——须看有无"有生无制"。
   - 【段解】"同第三篇讲的道理一样，劫财伤官又穿官，是一种犯罪组合。"（三、牢狱命定）
4. **判明犯还是暗犯**：伤官隐而不现（不透干）＝非明火执仗，只是偷偷摸摸干坏事；伤官透出＝明犯。
   - 【段解】"此命伤官隐而不现，故不是那种明火执仗式的违法，只是偷偷摸摸干点坏事。"
5. **落应期**：原局金火对抗不明显时平日无事，一到**甲乙俱生丁、丁有生无制**的那步运便出凶。
   - 【段解】"原局中金旺火弱，两者形不成明显的对抗，故而一般情况是无牢狱之忧的。但到丁运，甲乙俱生丁，丁有生无制，便要出凶。"
6. **看晦运过没过**：凶运中逢流年天干与凶神相合（如丁壬合）＝当年出来（凶解）；但大运未过，第二年仍会再入狱。
   - 【段解】"在这五年牢狱中，逢壬申年丁壬合，合制丁，命主此年出来，但因晦运未过，第二年又入狱了。"
7. **给原由**：以所涉之星／宫定坐牢的原因——因财、因子女是两条可复用的原由判据（L3/L4）。原书给出的时长（如"坐十个月""三个月"）是**断语记录**，不是本派能算出的月数，不得据以承诺刑期（见"什么时候不该用它"）。
   - 【原文】"42岁这年有牢狱之灾，42岁到51岁十年不顺，54岁这年因孩子的事坐牢。"（二十五、苦水泡大苦命人）
   - 【叙事】"42岁因财务问题下台，并且坐了十个月的牢，今年因孩子的事我又坐了三个月的牢。"
8. **财路不正者**：先判财之来路，再往下推祸事之年与刑期——来路判先于财运判。
   - 【原文】"这个人将来是一定会发大财的，但是他的财路不正，他是要靠诈骗别人手里的钱财，才能够发达。"（三十一、求财当有道）
   - 【原文】"他发大财后的三年之内，就会被抓到监狱里去，而且进去了以后，就永远也不会放出来。"（同篇；对照【段解】所举黑社会头目造"壬子运的壬运大发数千万，子运辛巳年被捕，没收其资产，判无期"）

### 二、断犯法的主从与性质

1. **看伤食的来源与归属定主犯／从犯**：伤官食神由劫财生起、不围绕日主转的＝从犯；伤食都围绕日主转、日主亲自策划控财的＝黑道头目（主犯）。
   - 【段解】"只不过他的伤食神俱是劫财生起来的，所以他是个从犯。壬辰一造就不同了，伤官食神都围绕着日主转，所以是个黑道的头。"（七、黑道头目）
2. **看局中有没有印**：同是伤官穿官之结构，局中有印能制伤官，则不作黑道，伤官之才转为正规机构服务，主为官；穿官只应夫妻不和，不作罪犯。
   - 【段解】"此造与壬辰造有些相似的地方，但她却是个官员，为何？因局中有印之故，因印能制伤官，伤官之心性转成为正规之机构服务的才能……穿官之意也懂是与丈夫不和，而不是与法律相抗。"（七、黑道头目）
3. **认"劫财伤官与官不和"**：局中劫财、伤官俱现、官星与伤食不和＝行为必然与法律规范冲突，是犯罪分子（走黑道）。
   - 【原文】"这个人的命甲辰戊辰月，癸巳日、乙卯时，劫财伤官，拉帮结派，不走正道走黑道。"（七、黑道头目）
4. **以"穿"直断对抗法律**：局中见寅巳相穿（寅＝食神／禄、巳＝七杀）＝本人与法律对抗，是其犯罪之因。
   - 【段解】"寅巳之穿，即表示他本人要与法律对抗，是他犯罪的原因。"（十四、少年犯）
5. **认作案形态**：劫在时上主"手"，用劫＝以手作案，成小偷（掏兜）；比劫多、大运又走劫财运＝结伙作案（团伙抢劫杀人）。
   - 【段解】"戌丑刑，用劫，劫在时上主手，故成小偷。"（九、小偷与盗贼）
   - 【邢解】"局中比劫多，大运行己巳劫财运，故为众人合伙做案。"（十四、少年犯）
6. **认凶手之人与凶器（象取，L6）**：流年出现的官星（酉）即来犯之男人，配"辛金主刀"＝男性持刀劫贼。
   - 【邢解】"酉官为男人为劫贼，流年出现，辛金又主刀。"（十三、劫后余生）
7. **定引爆之年**：七杀旺而当年不出事的，只等比肩（劫）出现方引爆——以比肩到位之年为正应流年；另一路为"庚甲冲」引动杀星之应。
   - 【段解】"这个八字中杀星是很强的，虎视眈眈，只等比肩出现，戊辰年是正应流年，而庚午年是庚甲冲，引动杀星之应。"（十四、少年犯）
8. **落官方打击之年**：流年合动命中官星，去冲命主"作案之字"（食伤）＝当年官方反击，命主被抓或伏法。
   - 【段解】"故逢癸酉年，合动辰土官星去冲卯木，是官方的反击，命主必然伏法。"（七、黑道头目）
   - 【段解】"壬申年巳申之合，即他的犯罪行为见了官，所以这一年因结伙抢劫而被抓。"

### 三、断伤灾与血光

1. **羊刃被冲／穿主血光杀身之祸**：时上见羊刃、大运冲开其墓库、流年又穿倒日支；或命局羊刃被冲又见动刀之象，皆主血光／死。
   - 【原文】"不好，出凶事了！你孩子是不是遇到了拦路抢劫？命中冲了羊刃，动了刀子，有杀身之祸啊！"（十三、劫后余生）
   - 【段解】"其也是壬水日主，只是他是时上见刃，行戌运冲破辰，见未年穿倒子，故死。"（十一、父亲的哀伤·孙志刚案旁证）
2. **禄主身体**（L3 宫位＋L6 取象）：年月为腿脚之位，年月之禄被冲破＝腿脚残疾；命局之禄逢墓绝＝身体不能动（瘫痪卧床）。
   - 【段解】"二儿子命：壬子，丙午，丁丑，甲辰，子水冲坏月上之禄，年月为腿脚，故是个拐子。""三儿子命：甲寅，丁丑，辛酉，庚寅，是因禄逢墓绝，禄主身体，故身体不能动弹。"（六、命克子女）
3. **火为伤官坏了局主神经／精神病**：火主神经，应期看行伤官之运及相应支的流年。
   - 【段解】"大儿子命：甲辰、丁丑、甲戌、丁卯，是伤官丁火坏了命局，火主神经，故是神经病。"（六、命克子女）
4. **以"肢体"定生死**：日主本气之根（如甲寅之木）为"肢体"，肢体未被伤及＝虽重伤亦不死。
   - 【段解】"为何未死，此因甲寅之肢体没有受伤，实际也是因没有伤及肢体而幸免于死难。"（十三、劫后余生）
   - 读法提醒：本门对"为何不死"的解释常靠"哪个字没伤"回填，属事后自洽，不可当可预判的因果规则使用。
5. **以象定伤处**：时上丁火主头脸，流年癸水冲克之，又见辛金主刀＝头面受伤（毁容）。
   - 【邢解】"辛金又主刀，癸又克丁，丁火在时上主头脸，故毁容。"（十三、劫后余生）

### 四、断凶死

1. **先找"凶死之根"**：原局有某一凶支（如戌），大运使忌神得强根并与该凶支成冲战＝忌神反局，主凶死；对照造局中无此凶支则无凶害，反证原局那一凶支即凶死之根。
   - 【段解】"戊辰运亥水得强根与戌土相冲战，是忌神反局，故凶。""上造的原局中的戌土，是他遭凶死的原因。"（四、汉奸的结局）
2. **"有生无制即出凶"**（承核心判断）：凶神得力、无制即应凶；有制（合制）则凶解。
3. **断死因取象——十二生肖类化**：取六亲星所在之地支，以十二生肖类化为同类动物，由此断死因与方式。
   - 【原文】"你丈夫是叫牛抵死的吧！儿子是叫狗咬死的吧？"（二十、招婿女命）
   - 【邢解】"其女对象八字中正官是丑，驴牛同类皆是畜也，无需细分。"
   - 读法提醒：此处夏仲奇把"驴踢死"断成"牛抵死"，被当事人当场纠正，属自承的断错；类化粒度只到"畜类"，具体物种／器物／死法一律不列入可承诺范围。

### 五、断寿元与寿关

1. **食神为寿元星**：命以食神为寿元星者，此星落空亡，又逢大运天干合、地支合将其合绊而不能生，即损寿，应凶之年随之落定（L5 空亡＋合、L7）。
   - 【段解】"寅木食神为八字寿元星，有寅便不会损寿，坏在寅木空亡，此是其一，而丁丑运子丑合丁壬合，便不能生寅，故应在甲戌年，甲木食神虚透而合己，意为去寅矣，故必死。"（十一、父亲的哀伤）
2. **日主唯一之根被刑坏应死**：日主系弱水、全赖某支（或支中藏干）为唯一之根，此根逢大运墓库相刑而被刑坏，即应死。
   - 【邢解】"甲戌年大运丑，壬水唯一之根--丑中的癸水被戌刑坏了，故中煤毒死。"（十一、父亲的哀伤）
3. **短寿断法与"潜词"**：命主将死而又不能明说时，改以"某年有关口／要得病"作断语，点出病之所属（如血液方面），再以"过了某年就好了"作宽解语——实指即该年病逝。见此类断语须**反向**理解生死。
   - 【原文】"我算孩子到九六年这一年，就不好了。""她会遇到一个关口，要得病。""应该是血液方面的病。""过了九七年，就好了。"（二十一、短寿女命）
   - 【邢解】"我知道这是夏老师的一句潜词。"
4. **断寿关·隐语**：本派断寿元等重凶时常用"潜词"，同一句话的字面吉凶与实指吉凶可以相反，取断时不得按字面读。

### 六、断破财与子女的连带

1. **为子女破大财**：日支（坐下）财星被劫财暗合，又与子女宫（时柱）相穿→为子女破费花大钱；可据以反向推出子女众多。
   - 【原文】"你看他坐下财星被劫财暗合，而又与子女宫穿，就是这个意思。如果不是凭这个看出他为女儿破费花大钱，现在计划生育，我断然不敢断他有六个女儿的。"（八、六个姑娘）
2. **重操旧业再发大财即再出事**：别无谋生本事又无钱者必重操旧业，其后"在男人身上发大财"即再出事——**大财出事、小财无妨**。
   - 【原文】"你一定要注意，如果你以后要是在男人的身上发了财，只要是大财，你就会再出事。""小财不会出事。"（三、牢狱命定）

### 七、断案件能否破（司法应用）

1. **官星入墓则案难破**（L5 墓库）。凶手藏匿不现、游串作案、无线索＝案破不了。
   - 【原文】"你孩子的这场劫案，我看是破不了，因为从命中看是游串作案，公安又找不到任何线索。"（十三、劫后余生）
   - 【邢解】"官星在墓中，故案破不了。"
   - 口径分层：原文给的理由是"作案形态（游串）"，邢解归以"官星在墓"；引用评注的"官星在墓"系后加解释，须与原文分层标注（见"口径分层"节）。
2. **对照：官星得制则能破**。官星逢刑制（如戌刑之）＝必能将凶手绳之以法。
   - 【段解】"但逢戌刑之，必能将凶手绳之以法；而戌午合财局，便表示他死后得到国家之赔偿。"（十一、父亲的哀伤·孙志刚案旁证）

## 口径分层：本书内部两套声音（不得静默择一）

**C01 断命到底用不用用神／衰旺**
- 主口径（本书总纲，采信）：【原文·弃衰旺】"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……当前流行的命理学所讲的东西，基本上是无用的。"（三十一、求财当有道／块25）
- 另一层（邢铭芬本人的解释习惯，非夏仲奇原法，保留标注）：【邢解·用旺衰忌神断应事】"29岁甲寅年结婚，甲申日元流年寅冲申忌神故而结婚。""33岁戊午年调工作商业，戊土偏财主商业，午岁克申金忌神，主得比较理想的工作。"（二十五、苦水泡大苦命人）
- 本书内证：段解（整理者兼主评）自设质问——"为什么此人行壬寅大运财官两旺，行癸卯大运不顺，用旺衰理论是讲不通的，道理何在？"故本技能一律以"不取用神"为准；凡见邢解以忌神立论处，不得当本派口径采用。

**C04 断吉凶看"十神名目"还是看"运中实际作用"**
- 通行名目说（本书引述并质疑）："有的人可能不解，印化了杀，应该是好才对呀，为什么就是穿小鞋而不是提职位呢？"（三十二、杀人之命）
- 本书实况说（采信）："这就涉及到象了，走壬辰运，原来地支的生，发生了变化，变成了壬丙直接冲，所以是坏事而不是好事。"（同篇）
- 结论：断吉凶须看运中**实际作用**（生／冲）有没有变，不看十神名目。凡按"某组合必吉"的定式预期推断，本技能不沿用。

**附注（断案理由的分层）**：同一"案子破不了"的结论，【原文】依"游串作案"，【邢解】归"官星在墓"——两说并存，不得混成一说。

## 判断标准

**做对了会看到：**

- 有一个明确被点名的"凶的结构"（穿官的支、无制的丁、被冲的羊刃、被刑坏的根、入墓漂流的官星），而且这个结构能在盘上指出来。
- 应期落在一个被"合动／库到／伏吟／到位"的**具体流年**上，而不是"某段时间运气差"。
- 同一盘在"原由"上说得通：因财、因子女、因结伙、因受雇，与所涉之星／宫对得上。
- 断"能破"与断"破不了"有对照口径：官星得制／逢刑可破，官星入墓则难破。
- 看到"潜词"型断语时，能反向读成"过不去该年"，而不是当成好话。

**做错了会看到：**

- 用日主旺衰、用神喜忌去反推本派结论——那样会陷进"从弱还是身弱""何者为阴、制与不制"的争议里，越推越乱，本派原法里没有这条路。
- 把"应验"当成已证事实：本书无对照、无失败记录，取样本身就是筛选过的（见下节）。
- 遇到三刑就直断凶死／寿短——本派要先判木之死活（局中无明水生又被冲刑者作"死木"看，金冲反为劈木利生火，不作寿短）。
- 把"牛抵死""驴踢死""住院十个月"这类具体物种／器物／月数的断语，当成可承诺的输出。
- 拿评注（邢解以忌神立论处）当本派口径依据——那是换了体系。

## 什么时候不该用它

1. **断死期类结论一旦失手后果不可逆，且本书全部证据都是事后叙述的应验轶事：无对照、无失败记录，取样本身就是筛选过的**——夏仲奇的记录者自述"记录了几百例完整情节与命例"，意味着被记下来的多是应验的；作者自己也曾断错（把"驴踢死"断成"牛抵死"）且自承早年断不出十八次婚姻。**不得把"应验"当已证事实，更不得据此对活人下寿元、凶死的断言。**
2. **时辰未校正不可用。** 夏仲奇自己的做法是先用兄弟姊妹数校正时辰，说明他承认这是前提条件；时辰无从校正时（或如孙志刚案那样靠"可能为"倒推的八字），结论不可靠，须标为不确定。
3. **"牢狱几年""住院几个月"这类数字型结论，验证阶段已按"无规则（只给结论不给算法）"淘汰了相当一批。** 本技能只能给出已保留下来的、确实带判据的那些条目（如"因财／因子女"的原由判据、"发大财后三年之内"的界限），**不得承诺能量出刑期或住院的月数**；"十年不顺""二十年"之类年限曾被现实推翻（判二十年实坐十年余，作者自承未解）。
4. **不要用在本人的健康诊断、法律诉讼、投资决策上**——本书的判据不能替代医学诊断、律师意见或任何专业判断。凡用户带着"我是不是得了病""我这官司能不能赢""这笔钱能不能投"来问，须先说明本技能只是命理口径的取象，不能作为决策依据。
5. **本书大量断语依赖现场对话逐步收窄**（补记自述盲师靠"在求问者的反馈中，不断修正调整"），只给八字、无任何背景信息时可靠性大幅下降；"铁口直断"的独立性无法与"冷读＋反馈"区分开。
6. **与主流子平法"看忌神到位即应灾"的说法不同**，本书的应期靠"合动／库到／伏吟／到位"，两套不能混用；凡提问落在"请定用神／忌神""看身强身弱"上的，本技能不按此路取象。要看主流子平法那套请用「渊海子平」「子平真诠评注」，要看年柱纳音那套请用「五行精纪注释」。
7. **本派自我定位是"能断不能改"**：夏仲奇明确说"命也是无法更改的"、"我算到的凶灾，告诉本人也没一次起过作用的"，避灾法在本传承中已失传；凡用户指望靠本派断命去化解已定凶灾的，本派不承诺有效。（本书内部另有一层声音——记录者称"恶念转善则恶因随之化解"，与夏师"命不可改"相反，两说并存且互斥，不得只取其一当定说。）
8. **本派并非总能断出具体死法**。断凶死时出现"看不清"是它本来就有的状态（如"像也沾水也沾火死的，具体看不清"），不可因为断不出具体死因而判为断错，也不可用事后类象强行补圆。
