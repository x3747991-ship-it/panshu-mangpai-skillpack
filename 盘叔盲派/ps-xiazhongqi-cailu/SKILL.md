# 夏仲奇断财禄事业

> **缺口补充册见「夏仲奇断事补法」**：**职业取象的行业方向**（房地产酒店／服装布匹刺绣／地下矿井／掏兜等）本册只到五行类别，细分见该册第二步（含多处"判据层原文未见"的如实标注）。

## 什么时候用它

用户问"我什么时候能发财""能发多大财""干什么行业合适""能不能当官""会不会破财""这笔钱来路正不正"的时候用它。

**通用前置见「夏仲奇看命总纲」。** 本技能只写与财禄、职业、官贵有关的那一层断法；宫位与十神怎么定位（L3、L4）、干支作用关系六件套怎么用（合／冲／刑／穿／墓库／空亡，L5）、取象法（L6）、应期怎么引动（L7）、看命总则（L1）都在总纲里。总纲没读完，本技能的步骤会失去底子。

时辰尚未校正的（L2），先做校正，否则整套断法不成立。

## 核心判断

盲派断财，**不问日主旺衰够不够担财，只问财在哪儿、能不能被引到"主位"（日柱／日时）上来**。以禄（或日主）为我，**禄（或日主）所生者才是财，须合入主位方成本人之财**；不合入的不是自己的，**被劫财合去的，就是替别人挣**。

这是本书与子平法最不同的一处：子平在"我担不担得起财"上打转，盲派在"财能不能被合到我身上"上落点。判断链落在 L5（合／冲／刑／穿／墓）与 L7（流年合动、库到为应期）上，取象按 L6，六亲星位定义见 L4。

## 怎么做

### 一、断发财应期

1. **财星被合动，即为开始赚钱之应期。** 大运、流年之干把局中财星合动（含年干财、时支财），财星全动，命主自此开始赚钱。例：行丙子运、甲子年，年干己被甲合、时支丑被合动，断"从十六岁开始赚钱"。（L7；片2 R17）
   原文：【邢解】"说她从十六岁开始赚钱，是因大运行丙子，流年甲子合动时支丑土财星，而年干己土财也被甲合，财星全动了开始赚钱。"（三、牢狱命定／block_03）
2. **财须逢合到之运方发；合不到位的运只主打工。** 局中之财若不能转为日主之用则不发；运中之合若被**劫财**取得，只是替人打工（酉运辛劫合巳＝为别人打工）；须待财与主位真正合到之运（巳申合）方能发财。合到位后，**再逢流年干合去劫财的次年**即起财（申运，丙子年丙辛合把劫财合去，丁丑年开始发财）。（L5／L7；片3 R04）
   原文：【段解】"在亥、戌、酉等诸运中，俱不能将巳之财转为日主之用，酉运虽合巳，却是辛劫财获得了，只可能是为别人打工而已。只有等到申运，巳申合到，才能发财。""丁丑年正是申运的第二年，因丙子年丙辛合，财他合去了，故在丁丑年开始发财。"（五、五妻之命／block_05）
3. **断财运旺年（财年分级）。** 先给一段"财运不错的年龄段"（并由此连带断其"不是读书的料、已经下海经商"），再给**发大财的具体年份**，另给一个**次大之财**的年份，明确两笔轻重，把等待期说出来。（片1 R28）
   原文：【原文】"我从你的八字上看出，你从十八岁到二十三岁这段时间的财运很不错。你今年刚刚十七……现在就会下海经商了。""我预测你26岁（1997年）能发大财；另外，到你二十四岁的时候，你也能发，只是不如26岁那笔大，你就好好等个七八年吧。"（三十一、求财当有道，失道必遭灾／块25）
4. **财官临库，不冲不开不发。** 财星（或官星）落入墓库时，**库须有刑冲打开才能起用、主大富**；库不开只作普通收入，不作大富断。（L5 墓库／刑开；片2 R06）
   原文：【段解】"书曰：'财官临库，不冲不发'，墓库中物不逢刑冲是没法用的。故此造贵在丑财库被刑冲。"（一、豆腐佬的传奇／block_01）

   **主命例（"财官临库，不冲不发"）：乾造 乙未 己卯 丁丑 庚戌**（豆腐佬，1955年生）。断"你呀，将来会成为亿万富翁！""你从1991年开始发财，一年比一年有钱。"丑为财库，原局被戌刑开，故发。
   三个对照例（同篇段解）：
   - 乾造 庚戌 丙戌 丁卯 辛丑——"财库丑被戌刑开，行丑运，聘任为一家大企业的老总"；
   - 乾造 甲申 辛未 丁丑 壬子——"坐支财库被冲开，资产几千万。如财库不冲，则不能富"；
   - 乾造 丙午 庚寅 丁巳 辛丑——"丑之财库原局不逢刑冲，现在所行之运也不刑冲，故是个普通职员，只是收入较高而已"。
   **同为财库，发不发还看透干合财的是谁**：【段解】"财库丑被戌刑开，行丑运，聘任为一家大企业的老总。为何不主他本人有钱，此因丙旺于丁，丙透合辛财，主他为别人创造财富。"（同篇）

### 二、断财的方向与来路

1. **财星坐支定财之方位与来源。** 合财应期已定后，看所合财星**所坐之地支**定方位。例：己坐巳火上，断"己巳年从南方发大财"。（L6 取象；片2 R18）
   原文：【邢解】"己巳年从南方发大财，是因甲己合财之应期，己坐巳火上，故是南方的财。"（三、牢狱命定／block_03）
2. **丑中藏偏财为"暗财"，主取暗财。** 日支丑中藏癸水偏财，且有字冲动它，此人即为**取暗财者**（偷盗）；暗财被冲动，应于动财之年。例：乾造 辛亥 丙申 己丑 甲戌——丑中癸水偏财主暗财，十七岁行乙未运，未冲日支丑中癸水，暗财动了，故掏兜。（片3 R16）
   原文：【邢解】"年支亥水财星藏甲木官星合日支丑中己土，丑中癸水偏财主暗财，为取暗财者。"【段解】"邢老师所说丑为暗财，正是此造之核心。"（九、小偷与盗贼／block_09）
3. **财坐病地，断以医术发病人的财。** **先看合，合先于其他作用**；日主与年干之财相合，而该财星自坐病地（病地主病），所发之财来自病人 → 断此人为医生，发病人的财。（片2 R01／片4 R44）
   原文：【段解】"这个八字，日主坐长生之地，是相当旺的，丙辛有合，先看合，年上的辛金是财坐病地，所以夏老师断他毕业后是当医生，发病人的财。"（三十二、杀人之命／block_26）

### 三、断财的数额

**五行主数定财之数目**：按取财之五行定数，土财主五、十之数 → 此造十万元。（片2 R24）
原文：【邢解】"土财主五、十之数，故是十万元。"（三、牢狱命定／block_03）

**⚠ 这一项规则本身不完整。** 本书只给过**一两条**实例（"十万元"；另有一处只给结论"大概有三五十来万吧"），从"哪一笔财对应哪个五行"到"五、十是五万、十万还是五十万"，书中**没有可复算的换算规则**。验证阶段已按"**只能事后解释**"淘汰（淘汰记录 K04：晚年发财之数额可断（三五十万）——数额断验虽准，但取数规则本书未给）。**本技能把"五行—数目"这一层对应关系列出备查，但不承诺能算出数额。**

### 四、断职业取象

1. **合先定十神、坐支取象断职业。** 天干见五合 → 提出该合所牵涉的那个十神 → 查该十神**所坐地支**的状态 → 由"十神＋坐支"反推职业物象（辛金为财、坐病地 → 从病人身上得财 → 医生）。（片2 R01）
2. **阴阳类象断职业。** 辨干支阴阳——**木火为阳、金水为阴**；阳主光明、阴主隐蔽；**以阳制阴＝以正义战邪恶＝公安刑警；以阴坏阳＝黑道**。再落到具体柱去制服局中某字定职业性质。例：坤造 癸卯 丙辰 己丑 丙寅，以丙火与寅木制局中丑土，断"干公安的"，且"最适合干刑警"。（片1 R02）
   原文：【原文】"因为她的八字当中有两个丙火占阳，她的八字喜阳火，所以是公安。如果占两丁火，那这个人就是盗贼了。"【段解】"木火为阳，金水为阴……以阳制阴是以正义战邪恶，就是公安刑警之象，反之以阴坏阳，便是黑道象。"（十七、女公安／块16）
   ⚠ 原文层用了"**喜**阳火"这种取用神式表述，段解已把它改判为阴阳取象。**引用"喜某五行"式断语时，不得同时声称本派不用衰旺**（反例三）。

### 五、断官贵

1. **伤官暗合七杀主当官，印制伤官则有权。** 局中伤官与七杀暗合（杀旺伤官弱），又用印去制伤官——**伤官在这里当权力看，制得住则有权（当官），制不住则失权**。例：乾造 戊戌 壬戌 辛亥 甲午，亥水伤官暗合午火七杀，戊土克壬＝用印制伤官，故断"这个命是个当官的"（县长一级）。（片2 R26）
   原文：【段解】"此造之所以能当官，是因亥水伤官暗合午火七杀。杀旺伤官弱，又局中戊土克壬水，是用印制伤官，伤官在这里当权力看，制之则有权，反之则失权。"（四、汉奸的结局／block_04）
2. **食神合官主当官。** 日主能生出食神、食神得力，与官星相合，即为官命；行合绊忌神之运更升官。例：坤造 壬辰 癸卯 丙辰 戊子，"她命贵在食神"，大运戊戌戊癸合、卯戌合，合绊忌神，当县长十年。（片3 R21）
   原文：【邢解】"食神合官是当官的。大运行戊戌戊癸合，卯戌合，合绊忌神故而当县长十年。"【原文】"她命贵在食神。"（十、将门虎女／block_10）
3. **以食神制坐支官杀（弱制／平衡制）主显贵。** 用食神制坐下官杀，分两档：**弱制**（食神弱而制旺官）与**平衡制**（食神亦旺）；皆主显贵。行运扶起食神则官职连升，行至**穿食神之字反怕失职**。例：乾造 甲辰 丁卯 丙辰 戊子，戊旺属"平衡制法"，行午运扶起戊土官职连升；辛未运未穿子，反怕失职。（片3 R22）
   原文：【段解】"他也是用戊土来制坐支子水，只是此造局中戊旺，不是弱制，是一种平衡制法。行午运扶起戊土，官职连升：辛未运就很难再升了，未穿子反怕失职。"（十、将门虎女／block_10）
4. **运刑动制神、成局时掌权（当官应期）。** 已具前条"官格"结构，**大运刑动局中制伤官之支**始掌权（乙丑运丑刑动戌、戌制亥，开始掌权）；再逢**三合杀局、伤官得制之运**权力最大（丙寅运丙生戊，寅午戌三合杀局）。（片2 R27）
   原文：【段解】"乙丑运丑刑动戌，戌制亥故开始掌权；丙寅运丙生戊，寅午戌三合杀局，伤官得制，权力最大。"（四、汉奸的结局／block_04）
5. **合而保护制神则失权、招祸。** 运干与制神或制支相合，使其不能再制凶神——**合即"保护"了所制之凶神** → 失权、遭缉捕。例：丁卯运丁壬合、卯戌合，使戊土不能制壬、戌土不能制亥，"此运便失权，遭辑捕"。（片2 R28）
   原文：【段解】"到丁卯运时，丁壬合卯戌合，便使戊土不能制壬(合而保护)，戌土不能制亥，此运便失权，遭辑捕。"（四、汉奸的结局／block_04）
6. **断掌权／失位，按 C04 看运中实际作用**（见「核心判断」分层）：名目上"印化了杀应该是好事"，只要运进来把原来的生变成冲，就是坏事。**掌权与失权各落在一段大运上**（L7：运定吉凶段），例中"二十八到四十七岁当官，四十八岁以后就不行了"。

### 六、断破财与财路不正

1. **断财路不正（来路判 → 祸事年 → 刑期）。** 先判财之来路：将来必发大财但"**财路不正**"、靠诈骗他人钱财发达（**来路之判先于财运之判**）；再由发财的年份向下推祸事之年（"你在结婚之后的第二年，就会有祸事发生""你到了2000年，会去坐牢"）；再定灾的持续时间与不可解（"他发大财后的三年之内，就会被抓到监狱里去，而且进去了以后，就永远也不会放出来"）。来人不信也不改断语。（片1 R29）
   主命例：乾造 壬子 癸丑 辛酉 乙未（命占壬癸辛三奇）。断18—23岁财运不错、17岁下海经商；26岁（1997）发大财、24岁亦能发（较小）；女友多、28岁（1999）结婚；结婚次年（2000）坐牢；财路不正为诈骗。后判**巨额诈骗罪，死缓**。
   原文：【原文】"这个人将来是一定会发大财的，但是他的财路不正，他是要靠诈骗别人手里的钱财，才能够发达。"【叙事】"巨额诈骗罪，死缓。估计这辈子出不来了。"（三十一、求财当有道，失道必遭灾／块25）
   **※ 刑期细节（几次、几年、何地、何月起、能否放出）指向「夏仲奇断官非灾祸」技能**；本技能只写到"财路不正 → 祸事年"这一层。本书对刑期"按几次、几年、何地、何月起"的取数规则**未公开**（淘汰记录 T17），不得承诺。
2. **重操旧业再发大财即再出事（大财出事、小财无妨）。** 命主别无谋生本事、又无钱，必重操旧业；此后只要**发大财就再出事，小财无妨**。（本条主线归「夏仲奇断官非灾祸」，此处只作"财的大小—事的大小"这一取象的交叉引用）
   原文：【原文】"你一定要注意，如果你以后要是在男人的身上发了财，只要是大财，你就会再出事。""小财不会出事。"（三、牢狱命定／block_03）
3. **劫财伤官一类的破财**属通用应期（"流年逢劫财伤官主破财"已按通用道理淘汰，见淘汰记录 K09），本技能不单列。

### 七、断为他人作嫁

**财被劫财合去，就是替别人挣。** 两种写法：
- **运中之合被劫财取得**：【段解】"酉运虽合巳，却是辛劫财获得了，只可能是为别人打工而已。"（五、五妻之命／block_05）
- **同五行旺者透干合财，主为别人创造财富**：【段解】"为何不主他本人有钱，此因丙旺于丁，丙透合辛财，主他为别人创造财富。"（一、豆腐佬的传奇／block_01）

## 判断标准

做对了会看到：

- 对着一个陌生八字，能先说出**财在哪一柱哪一支**、**这一支与主位有没有合／合的路径有没有被劫财占住**，再给出发财的那一步运、那一年。豆腐佬造能说出"丑财库被戌刑开所以发"，五妻造能说出"只有等到申运，巳申合到，才能发财"。
- 财路不正类能说出**"先发财、后出事"的顺序**（先定来路，再定祸事年），而不是笼统说"你财运不好"。
- 官贵类能说出**掌权与失权各在哪一段运**（乙丑运开始掌权、丙寅运权力最大、丁卯运失权），并给出为什么（制神被刑动／成局／被合保护）。
- 断语能落到**具体年**（1991、1997、2000），而不是只给吉凶方向（L7）。

做错了会看到：

- 用"日主弱担不起财""财多身弱"去解释发财，或反过来给发财的人扣"身强能担财"——这是子平口径，不是本书口径（C01）。
- 看到"印化了杀"就断升职、看到财库就断大富——**库不开的不断大富**，**名目好而运中作用变坏的按坏断**（C04）。
- 把"数额"当结论报出去（"你这辈子能挣三五十万"）——本书没有可复算的取数规则，报了就是编。
- 把职业取象断成唯一的实物（把"木火为阳制阴"直接说成"你就是警察"），忽略了同一组干支可以取多种象、还要落到具体柱才定得下来。

## 什么时候不该用它

1. **数额型结论不得承诺。** "三五十万""十万元"这类数额，本书**只给了结论、没给算法**（取数规则未公开），验证阶段已按"**只能事后解释**"淘汰（淘汰记录 K04）。**本技能不承诺能算出数额**，只能事后对照；给用户报数额一律视为越界。
2. **时辰未校正不可用。** 报时辰不准是常态（L2），夏仲奇本人先用兄弟姊妹数等校正时辰才开断。时辰无从校正时，财在何支、库开不开、合到不到位全都无从谈起，整套断法失效。
3. **职业取象弹性大，单靠八字无法唯一确定职业。** 同一个字可以取多种物象（寅既可为"衣物、鞋"，午既可为"手术刀"又可为"阳刃"），本书多篇以"自标存疑""暂作保留"收尾（反例六、反例七：把"驴踢死"断成"牛抵死"，当事人当场纠正）。断到"哪一类工作"可以，"哪一个具体岗位"不能承诺。
4. **财路不正／牢狱类结论一旦失手后果不可逆，且本书无法证明准确率。** 此类断语全部是事后叙述的应验轶事，无对照、无失败记录，取样本身经过筛选（骨架「盲点与边界」）。给出"你会坐牢""你财路不正"这类结论前必须说明这是本书体系内的推演、非已证事实；刑期细节更不在本技能范围，须走「夏仲奇断官非灾祸」。
5. **凡与"旺衰取用"两运吉凶矛盾、无法自洽的造，本派不承诺给出可用解释，属待解区。** 【邢解】"为什么此人行壬寅大运财官两旺，行癸卯大运不顺，用旺衰理论是讲不通的，道理何在？"（块23、块24；反例十三、十四）。邢解自己的解释里夹带"忌神"口径，与本派"不用衰旺"相抵，**凡邢解以忌神立论处，不可直接当本派口径采用**。
6. **无背景信息、全靠现场反馈修正的场景不适用。** 补记自述夏仲奇"在求测者的反馈中，不断修正调整"；且本书大量断语是在求测者已给出部分信息之后作出的。只有一张八字、什么都不知道时，本技能的成功率没有证据支撑。失效条件和门类边界见 L8。
7. **女命"无官星即以财看夫"一条须并陈段解口径。** 【原文】"有财没官，以财看夫，财入丑库，因此无法结婚。"（十六、老姑娘）／【段解】"一个无婚姻的女命不是八字中没有官杀星，而是有并占据其位置，但不能用。"（同篇）——两说并存，**不得只取"无官星故无婚姻"当定论**（反例二）。此条与财禄交叉，本技能沿用并标注。
