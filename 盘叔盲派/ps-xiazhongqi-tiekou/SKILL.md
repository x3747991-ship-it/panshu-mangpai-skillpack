# 夏仲奇看命总纲

> **本派缺口补充册（2026-10-01 补漏轮新增）**：①「夏仲奇断健康疾病」——五行配脏腑断病／断寿与两档死期／死因取象／疾病应期，本总纲无此门类；②「夏仲奇断事补法」——断性格·职业行业方向·父母宫再婚继亲·应期到月·反断他人·第三者转正·穿刑动态力量·不入公门·书末附录口径。

## 什么时候用它

- 用户给出一个四柱，问"这命怎么样""这人怎么样""从哪里看起""以后会怎样"。
- 要断六亲、婚姻、财禄事业、官非灾祸、取象、应期之前，先在这里定盘：立宫位、定星、读干支作用、定取象口径。本技能是全批技能的共同前置，其余各技能正文里的宫位（L3）、十神定位（L4）、干支作用（L5）、取象（L6）、应期（L7）一律引用本技能，不另写精简版。
- 用户拿来的是一个具体四柱（年月日时），并且能提供一点背景——哪怕只有"想算算婚姻"这一句，也算有背景。

（只问"哪天是黄道吉日""这个月哪天动土"一类择日问题，不要用本技能，那是另一套体系。）

## 核心判断

盲师夏仲奇断命，**不用衰旺、不找用神、不定格局**。日主强弱在这里不表示能力强弱，也不表示身体好坏；同一八字得出不同结论的根源，就出在"要不要先找用神"这一步上。

正确的做法：以日干为"我"，把八字里每个字当成一个**有具体作为的存在**，直接读它们之间的合、冲、刑、穿（相害）、墓库、空亡、伏吟，再叠上宫位（年为祖上父母、月为父母兄弟、日为自身配偶、时为子女）与星位（父＝财、母＝印、夫＝官、兄弟＝比劫）的取象，最后用流年的"引动"把结论落到具体年份。

为什么放弃用神反而断得更细：用神是一层中介，它只回答"吉不吉、旺不旺"；而合冲刑穿墓空是**动作**，直接对应"谁被谁带走、谁把谁穿倒、谁进了库"，于是配偶次数、子女性别、职业、死因这类细事才有落点。段解原话：**"没有用神，只有取象。"**

## 怎么做

### 第一步（L1）看命总则：先把"理"的框架放掉

1. 不要先算日主旺衰，不要先取用神，不要先定格局。本书立场（块25）：**"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……所以说，当前流行的命理学所讲的东西，基本上是无用的。"**
2. 判吉凶不看十神名目（如"化杀为贵"），只看**运中实际作用变了没有**——是生、是合、还是直接冲。（分歧 C04，见下"分层判读"。）
3. 出场问法：先算出"是什么"（性质、人物、地点），再答"能不能""成不成"。凡以揣摩人心为断者（"夸少、骂老、说中年"），不是命理。

### 第二步（L2）定盘与时辰校正

1. 默认报的时辰**不准**，先校正再断。
2. 校正手法：用**兄弟姊妹数、婚期、六亲经历**倒推。示例（块1）："按戌时推，你有一个哥哥，一个妹妹"——当事人点头，时辰才算定下；与命主实际不符就换时辰重排。
3. 起运口径用盲师说法"**X岁扎根X岁运**"：如一岁扎根一岁行运、七岁扎根七岁运、八岁扎根八岁运、四岁扎根行运。随命而定，不是固定的三岁起运。
   - 【原文】"你一岁扎根一岁行运，如果时辰没错的话，你没有兄弟，是家里的独生子。"（块5；"如果时辰没错"正是把起运与时辰绑在一起验的写法。）
4. 扎根落点可进一步取象定层次：【原文】"你七岁扎根七岁运，扎根扎在荷叶上，我算你十九岁考上学校，是中专学历。"（块16，R03）——"扎在荷叶上"＝根基不实，故学历只到中专。

### 第三步（L3）立宫位

1. 宫位总诀（块10原文）：**"年为祖上父母，月为父母兄弟，日为己身妻(夫)，时为子女。"**
2. 盲派窄口径的补充：**月令（月支）专作"兄弟宫"**（"月令为兄弟宫，临伤官必泄比肩"）；**日支**男作妻宫、女作夫宫；**时支**作子女宫／子孙宫。
3. **宫位与星位同参**：同一位六亲，既看其宫，也看其星，两者互相印证。
4. **宫位被穿／被冲＝该宫位破损**：【段解】"因母位在月令，原局酉戌穿倒母宫，故应在戌运之戌年"——宫被穿倒，凶应就落在"穿宫"的那个运年上。
5. 宫位另可断身体部位：**年月为腿脚、时上为头脸面**（"子水冲坏月上之禄，年月为腿脚，故是个拐子"）。

### 第四步（L4）定星：十神六亲星定位（盲派口径）

按书定星，**不得混用通行子平的取星法**：

| 六亲 | 本书取何星 | 书中依据（原句） |
| --- | --- | --- |
| 父 | **财** | "看父则以酉金财看" |
| 母 | **印** | "以月上乙木为正印为母亲" |
| 夫（女命） | **官／杀**；局中无官则**以财看夫** | "有财没官，以财看夫" |
| 妻（男命） | **财** | "甲木坐申，天干庚辛混局，妻多之命" |
| 兄弟／手足 | **比劫**（比肩为手足，劫财亦兄弟） | "己土比肩为手足" |
| 子女（男命） | **官星** | "他的女儿与儿子都不跟他说话（男命官星为子女）" |
| 子女（女命） | **伤官＝儿子、食神＝女儿** | "丁火就是伤官，就是她儿子"／"她的食神是姑娘" |

- ★ **男命官星为子女**一条，与通行子平法（男命子女看食伤）**不同**，须按书定；女命则以食伤分男女（伤官为子、食神为女）。
- 星有无根、是否被印制，决定该六亲的存亡。**星定错，后续一切刑冲结论作废**，故定星是断六亲的固定第一步。

### 第五步（L5）读干支作用关系：六件套＋伏吟

这是断细事的主工具，逐类对照书中给出的具体关系：

1. **合**
   - 六合：乙庚合、甲己合、丙辛合、丁壬合、巳申合、卯戌合、寅亥合。
   - 半合：如寅午半合。
   - 暗合（藏干相合）：午亥暗合、丑暗合——主暗中、不明之事。
   - 两向用法：**合动**（把该字激活、搬到某位，"合动乙，等于乙木印星临到戌"）与**合去／合则去**（合住即被带走、失效，"逢庚年合乙，合则去"）。
   - **合而保护**：合住制神，使其不能再制凶神，反主失权、招祸（"丁壬合卯戌合，便使戊土不能制壬（合而保护）"）。
2. **冲**
   - 冲开库则发：**"财官临库，不冲不发"**——墓库中物不逢刑冲不能用（"贵在丑财库被刑冲"）。
   - 冲伤／冲战致凶："戊辰运亥水得强根与戌土相冲战，是忌神反局，故凶。"
   - 具体：子午冲、寅申冲、卯酉冲、辰戌冲（"冲去戌土，当成婚"）。
3. **刑**
   - 三刑：丑未戌三刑（断六亲出问题、子女先天疾病）、寅巳相刑（断死闺女）、丑戌相刑（断死弟）。
   - **刑开库**：戌刑开丑库、丑刑动戌——库要刑开才能取用，是发财、当权的钥匙。
   - 自刑：同性相刑，用于"刑落何宫即应何亲"。
4. **穿**（＝通行之"害"；盲派把它提到与刑冲同级，权重远高于通行命理）
   - 具体：**酉戌相穿／穿倒**（穿倒母宫、穿倒父星）、卯辰穿、午丑相穿、未穿子、寅巳相穿。
   - 用法：宫位／星位被穿＝该宫位被破坏（早丧父母、婚姻差）；**穿官即为违法**（"局中戌土与酉官相穿，意为违反法律"）；穿亦可主**应事迟晚**："局中酉戌穿，来得晚"。
5. **墓库**
   - **入墓**：星入墓＝该字暂被收存、不能作用，甚则断其人事终结（"酉墓在丑，所以父亲死于癸丑年"；"甲绝于申而死于午……当死于辛未运，甲入墓"）。
   - **库到**：墓库之支在流年真正到来，即为应期（"到癸丑年正好库到，是谓之应期"）；**只是刑开库之年不应**（"戌年正好刑开丑库，故戌年是不会死父的"）。
   - **墓库余气**：入墓之运若库中尚藏该星之余气，则关系延续但不密切（"因为未中还有丁火，也就是说丁火在此时有余气"）。
6. **空亡**
   - 落星／落宫皆主该人事虚而不立：乙坐空亡、女命伤官坐空亡、子孙宫落空亡（"婚后不生孩子，是因子孙宫落空亡"）。
7. **伏吟**（另加）
   - 原局某支在大运／流年重复出现，即该宫位被叠加触发："甲戌年离婚，是因甲木合动己土伤官，戌夫宫伏吟。"
8. 取用次序：**先看合**（"丙辛有合，先看合"）；再看冲、刑、穿；最后看墓库、空亡。

### 第六步（L6）理五行与象五行：两套并行

1. **理五行**按生克正理推（"这个丁本身弱，很难克的"）；**象五行**按象推。**理上讲不通的，就从象上讲**："八字有理五行与象五行，从象上讲，丁能克酉。"（R12）
2. 取象可以极具体，且"合先于其他作用"：财坐病地→发病人的财→医生；寅为印为衣物、在地支为鞋→"领导给他穿小鞋"；午火为阳刃→手术刀；时柱为门户→出门；三合局成→有人邀他入局。
3. 同一支在不同关系里各取一面，拼成事件本质（杀人之命例：午＝阳刃＝凶器、午卯破＝方法、午亥暗合＝医生身份、三合火局＝利用手术刀）。

### 第七步（L7）定应期：靠"引动"

1. 总机制：断出之事要落到年，靠**流年与命局某字相合（合则去／合动）、相冲、库到、伏吟**来**牵动**该字所主的人事；被牵动的是谁，该年应的就是谁的事。示例（R48）："行辛运甲戌年，卯戌有合，等于是合动了辛卯这一柱，这一柱的辛在盲派里当人看。"
2. 三种常见应期口：
   - **支转干应法**：克星藏于支，其天干在运中透出且不受它神制，即为应期（R12："她局中克父之能量是戌，戌中含丁，丁现于大运……表示克父的东西出现了，实际是应期的原理"）。
   - **流年到字**：受克之字于流年再现即为应期（R39："到已巳运巳火合克申，申难存，壬申年申到为应期"）。
   - **库到／合动子孙宫／冲动子孙宫**：星入墓则取库到之年；生育则取冲动或合动子孙宫之年。
3. **大运与流年分工**：大运定"吉凶段"（某十年顺不顺、某段关系延续还是了断），流年定"应期点"（哪一年发生）。
4. **一字兼两星则两事同来**（R41）：一星两用，两事并应（"酉金同时代表儿子，儿子与夫同到，故得继子"）。

### 第八步（L8）按门类落断（详细边界见「夏仲奇断法边界」）

- 六亲：父＝财、母＝印……→ 看其宫与星的刑冲穿墓空 → 定存亡与应期。
- 婚姻：男以财数妻、女以官（或副夫宫）计婚次 → 看宫星合冲穿 → 定婚期与聚散。
- 财禄事业：看财官之库开不开、财能否合入主位 → 定发财与职业取象。
- 官非灾祸：看官星被穿／伤官透藏、禄与寿元星之存亡 → 定刑期与生死。
- 各门类的详细判据见对应技能；本步只管"从哪一门进、用哪几个字"。

## 分层判读（本书内部分歧，不得揉成一条）

**C01 · 断命到底用不用用神／衰旺**（全书最核心分歧）：

- 【总纲·弃衰旺】说：断命不取用神、不讲神煞，流行命理学的用神体系"基本上是无用的"——"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……所以说，当前流行的命理学所讲的东西，基本上是无用的。"（块25）
- 【邢解】说：另有一套以旺衰忌神断应事的讲法——"29岁甲寅年结婚，甲申日元流年寅冲申忌神故而结婚。""33岁戊午年调工作商业，戊土偏财主商业，午岁克申金忌神，主得比较理想的工作。"（块23）此系邢铭芬本人的解释习惯，**非夏仲奇原法**。
- 【段解】同案自设质问，明确说旺衰讲不通："为什么此人行壬寅大运财官两旺，行癸卯大运不顺，用旺衰理论是讲不通的，道理何在？"（块24）
- → 本技能**以【总纲·弃衰旺】为主口径**；引用邢解的"忌神"表述时，一律标注为邢解一层，不得当成本派法则。

**C04 · 断吉凶看"十神名目"还是看"运中实际作用"**：

- 【通行名目说（本书引述并质疑）】说："有的人可能不解，印化了杀，应该是好才对呀，为什么就是穿小鞋而不是提职位呢？"
- 【本书实况说】说："这就涉及到象了，走壬辰运，原来地支的生，发生了变化，变成了壬丙直接冲，所以是坏事而不是好事。"
- → 本技能**采本书实况说**：断吉凶须看运中实际作用（生／合／冲）变了没有，**不看十神名目**。

## 判断标准

**做对了会看到**

- 断语能落到具体的**字**与**具体年份**上（哪一年、因哪个字动、应的哪个人），不是"近年注意身体"这类笼统话。
- 同一张盘，"宫位—星位—作用关系—流年引动"能串成一条链，且链上每一环都在盘里指得出具体的字。
- 用流年"合／冲／库到／伏吟"核对应期时，能解释"为什么偏偏是这一年"，而不是撞出来的。

**做错了会看到**

- 开头先算旺衰、先找用神、先贴格局名——一旦走了这条路，细事（婚次、子女数、职业、死因）就落不下来，断语只能停在吉凶层面。
- 用十神名目直接贴结论（"印化杀所以是好事"），不去看运把原来的"生"改成了"冲"，结果与实况相反。
- 引用【邢解】的"忌神冲克"讲法，却当成夏派法则去推论——口径已经串了层。

## 什么时候不该用它

1. **时辰未校正时不能用。** 报时辰常不准，夏仲奇本人的做法是先推兄弟姊妹数校正时辰，说明这是他自认的前提条件；时辰无从校正时，整套取法失效。
2. **只有八字、没有任何背景信息时不能用。** 本书大量结论依赖求测者现场反馈修正（补记自述"在求测者的反馈中，不断修正调整"），"铁口直断"的独立性与"冷读＋反馈"难以区分；无背景信息时可靠性无从保证。
3. **数字型结论受时代条件限制，不能照搬。** "断出五个老婆""断出六个姑娘"建立在生育不受限、婚姻可反复的社会条件上；作者在第八篇已明说"由于计划生育的推行……推命中的孩子数没有了实际的意义"。今天照搬子女数一类数字结论会直接出错。
4. **断死期类结论本书无法证明准确率。** 此类结论一旦失手后果不可逆；书中"活不过1997年"恰好应验属幸存者记录，全书的有效性证据都是事后叙述的应验轶事，无对照、无失败记录，取样本身经过筛选。
5. **照【邢解】那套"取用神／看忌神冲克"用，会错在这里：** 邢解在块23、24明显用旺衰忌神解释应事（"流年寅冲申忌神故而结婚"），而段解在同案自设质问、明确说"用旺衰理论是讲不通的"，总纲亦明言夏不用用神神煞。若把邢解这部分当成本派法则去复算，等于用被本书自身否定（或至少未认可）的口径断命，遇到与总纲冲突的命例会得出相反结论且无法解释——凡此，只能作为邢铭芬一层的表述保留，不得当定论。
6. **同盘异命的判别，本书未回答。** 作者被直接问到"命主已经有克无生，何以不死"时，答"你须自辩而通"，等于承认未解决。

## 出处

来自《命术轶闻》（盲师夏仲奇断命遗例）**邢序**、**二十五篇（苦水泡大苦命人）／二十九篇（祸福灾咎全由命）**、**三十一篇（求财当有道，失道必遭灾）**、**二篇（悲惨的女人）**、**十篇（将门虎女）**、**三十二篇（杀人之命）**、**补记（为什么瞎子才算得准）**。

原文：

- 【总纲·弃衰旺】"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……所以说，当前流行的命理学所讲的东西，基本上是无用的。"（三十一、求财当有道／块25）
- 【段解】"没有用神，只有取象。"／"这就涉及到象了，走壬辰运，原来地支的生，发生了变化，变成了壬丙直接冲，所以是坏事而不是好事。"（三十二、杀人之命／块26）
- 【原文】"你的命是：乙未年，己卯月，丁丑日，庚戌时。按戌时推，你有一个哥哥，一个妹妹。"（一、豆腐佬的传奇／块1）
- 【原文】"你七岁扎根七岁运，扎根扎在荷叶上，我算你十九岁考上学校，是中专学历。"（十七、女公安／块16）
- 【原文】"年为祖上父母，月为父母兄弟，日为己身妻(夫)，时为子女。"（十、将门虎女／块10）
- 【段解】"因母位在月令，原局酉戌穿倒母宫，故应在戌运之戌年，不应在巳年与午年。"（二、悲惨的女人／块2）
- 【原文】"你看她的食神是姑娘，巳中丙与寅中丙都是姑娘。"／"丁火就是伤官，就是她儿子。"（二十七、孽情／块22）
- 【段解】"即酉金入墓于丑，而戌年正好刑开丑库，故戌年是不会死父的。到癸丑年正好库到，是谓之应期。"（二、悲惨的女人／块2）
- 【段解】"她局中克父之能量是戌，戌中含丁，丁现于大运，又不受制于它神，表示克父的东西出现了，实际是应期的原理。八字有理五行与象五行，从象上讲，丁能克酉。"（二、悲惨的女人／块2）
- 【段解】"行辛运甲戌年，卯戌有合，等于是合动了辛卯这一柱，这一柱的辛在盲派里当人看。"（三十二、杀人之命／块26）
- 【邢解】"甲戌年离婚，是因甲木合动己土伤官，戌夫宫伏吟。"（二、悲惨的女人／块2）
- 【邢解】"29岁甲寅年结婚，甲申日元流年寅冲申忌神故而结婚。"（二十五、苦水泡大苦命人／块23）
- 【段解】"为什么此人行壬寅大运财官两旺，行癸卯大运不顺，用旺衰理论是讲不通的，道理何在？"（三十、诸葛东方／块24）
