# 盲派实战断命·命理瑰宝（段建业）

## 什么时候用它

用户给出四柱八字（最好带性别），问以下任何一类盲派断事问题：

- **婚姻**：婚姻好坏、会不会离婚、几次婚姻、何时结婚、配偶怎样、有没有桃花外遇
- **财运**：有没有钱、会不会发财、破财年份、做什么能赚钱、富还是贫
- **官命/事业**：能不能当官、官职多大、适合什么工作、会不会下岗辞职、事业走向
- **大运流年**：某步大运吉凶、某年应什么事、流年吉凶应期
- **其他断事**：父母六亲生死、子女、性格人品、官司牢狱、健康灾祸、学业功名

本技能无需先定传统格局或用神——本派弃衰旺、不用传统用神，按"原局做功制化 + 宾主 + 虚实 + 干支取象"断命；先辨宾主虚实，再落到所问维度，最后看大运流年应期。规则出处中「珍宝」为姊妹篇《命理珍宝》内容混入txt，作为交叉参考。

## 核心判断

1. "八字看贵贱、大运看吉凶、流年看应期"——流年只管吉凶应期，不主喜忌：用神流年受制反凶、忌神流年受克反吉。
2. 断命核心是做功制化 + 宾主 + 虚实 + 干支取象，不看日主衰旺、不需传统用神；日主衰旺法取用有四大缺点，当弃。
3. 婚姻以配偶宫为主、配偶星为辅；官命看官杀印必须有根；财运看伤官当财、以禄当财、比劫去财三种特殊财法。

## 断法步骤

1. **排四柱大运，辨宾主层次**：日主/日柱/日时为主，他干支/年月为宾；八字为主、大运流年为宾。客只能作用主，反客为主即该神应期。［L4 世应（类六爻宾主）］
2. **看原局做功**：找制什么、化什么（做功对象），定喜忌与病神，识贼神捕神——忌神可被强用神制服则称贼神，制它的用神称捕神。［L4 贼神与捕神；L5 做功对象］
3. **辨虚实**：干透无根为虚干、有根为实干，地支皆实；宜用神实而忌神虚；忌神虚而受生主凶、忌神实而被制主吉。［L4 干支虚实应用；L5 虚实用神］
4. **断贵贱层次**：原局显象优先——得势而有病神主贵，有势无病反贱，势不足或病太重主平常。［L4 先天垂象；L4 命学六大要诀>看势］
5. **落到所问维度**：按问项查对应专辑（婚姻看配偶宫为主、配偶星为辅；财运看伤官当财/以禄当财/比劫去财；官命看官杀制化七配置；六亲活论、生死看原神）。［L8 断事维度］
6. **看大运定吉凶**：大运十年统看与上下五年分看，视流年刑冲合并而定；大运冲八字不主动，旺冲衰为破。［L7 大运吉凶］
7. **看流年定应期**：流年只管应期不主喜忌；应期四类型（受冲克出现/动而逢合/虚透通禄/地支受制逢透干），合者见冲、冲者见合、没有的出现时为应。［L7 应期类型］

## 判断标准

断对了会看到：按"配偶宫为主、配偶星为辅"断婚姻与原局结构吻合；按"伤官当财 / 以禄当财 / 比劫去财"断财运，与实际求财方式（投机、实业、渠道垄断）对应；流年应期（结婚年、破财年、升官年、六亲死年）与实际年份吻合；象法取职业（律师、军官、企业家、文职）与实际身份一致；大运吉凶与"流年只管应期不主喜忌"原则验证一致。

断错了会看到：拿"身强身弱、取用神"的框架来套本派断语（两套体系错位）；忽略先天垂象直接以大运流年断贵贱层次；把桃花/驿马/空亡等神煞当独立吉凶断（本书神煞仅作取象）；要求应期精确到某日（本派只能断到年、月层面）；平淡无做功结构的命局被强行套"伤官当财/官杀制化"断语。

## 什么时候不该用它

1. **问"日主身强身弱、取什么用神"**：本派弃衰旺、不用传统用神，不按此作答；这类问题应使用旺衰用神派技能。
2. **传统神煞专问**（天乙贵人、桃花、驿马、空亡、羊刃等神煞吉凶）：本书神煞仅作干支取象辅助，不作独立断命。
3. **非子平体系**：纯纳音问、铁板神数条文（需起数考刻，走 tieban 技能）、六爻/奇门/六壬等。
4. **出生时辰不确定、无法排盘**：应期与取象均依赖四柱完整。
5. **女命"贞操/淫贱/克夫"式道德定性**：本技能已按任务卡中性化处理，不作此类断语。
6. **应期精确到"某日"**：本派应期只能断到年、月层面。
7. **平淡命局无做功结构**（无制无化、无墓库刑冲、无从旺从弱之势）："看势+病神"法难以分出贵贱，应如实告知"原局平淡"，不强行套断语。
