# 高德臣盲派金口诀（直断口诀）

## 什么时候用它

用户给出一组四柱干支（最好带胎元/命宫/身宫三垣），问人生直断类问题：

- "看这个八字婚姻怎么样""什么时候结婚"
- "这八字是穷命还是富命""能不能当官"
- "帮我看父母寿命、兄弟姐妹几个、子女贤不贤"
- "这个八字哪年有灾""什么时候发财"
- "这八字性格怎样""适合做什么工作"
- "八字看阴宅、祖坟有没有迁过"

这是高德臣派（师承苏国圣"玄门苏记"）的盲派口诀直断体系，按口诀速查速断，不需要走子平格局推演。

## 核心判断

1. **财官印是否流向日主**是贫富贵贱的总开关：流通入日主为富为贵，流向它方为财来财去，被刑冲穿绝截断则平民布衣。
2. **三垣四柱是一统**：胎元/命宫/身宫与四柱不可有刑冲穿绝，三垣天干坐财官印且坐支生扶则直断富。
3. **串宫压运**是断流年应期的主法：以太岁起十二神配四柱三垣，看四季应期。
4. **神煞不可一查便说**：须配喜忌使用，被刑冲穿绝空亡则吉不吉、凶不凶。
5. **空亡能改诸神性**：空亡介入可改判吉凶；年空父母不利、月空兄弟不助、日空夫妻不合、时空子孙不顺。

## 断法步骤

按盲派"论命四步"执行：

1. **一看八字十神立**：列出四柱十神，定财官印食的位置与强弱 [L1四柱>四柱干支/L2十神]
2. **二看四柱与三垣**：查刑冲穿绝合（含三垣），判断五行流通路线是否指向日主 [L4>三垣论/L4>财官印断贫富>流通路线]
3. **三看大运对命局**：定大运干支与命局生克制化，按"最旺为病、去病为喜"断十年祸福 [L4>易海拾贝>病药观]
4. **四看流年应期**：串宫压运起太岁（流年/大运/日干三种起法），十二神配旺衰断当年吉凶与四季应期 [L4>串宫压运]

断事入口（按用户问题选路径）：

- **问贫富贵贱**：先断旺衰（两党比较法）→ 看财官印是否流入日主 → 查三垣坐支 → 按富/贵/平常/贫/贱/凶/无官七诀定级
- **问婚姻**：月令为婚宫、日支为配偶 → 查刑冲穿绝空亡 → 看日支十神 → 定早晚远近 → 查克夫克妻
- **问六亲**：先定太极点（测父偏财、母正印、兄弟比劫、子女食伤官杀）→ 查星旺衰+宫位生克 → 定寿夭/个数/贤愚
- **问流年吉凶**：串宫压运起太岁配十二神 → 查凶年之规（岁运并临/征太岁/冲克用神）→ 定应期
- **问性格**：日干直断 → 十神心性 → 五行旺衰 → 日柱纳音成象 → 生时性情（多路交叉）
- **问伤病寿**：伤灾/官灾/病灾/寿限四类标志逐项查 → 五行配宫位断病（年头月胸日腹时下肢）

## 判断标准

断对了会看到：
- 问婚姻能指出婚宫偶宫配置与应期年份
- 问贫富能指出流通路线与富/贫等级
- 问流年能按串宫压运排出十二神并给出应事方向

断错了会看到：
- 给的八字缺少三垣或不完整，直断类规则难以落位
- 特殊格局（从格/专旺格）下"流通入日主"等直断失效
- 时辰不准（尤其子时不分早晚）时串宫压运全盘错位

## 什么时候不该用它

1. **非八字问题**：紫微斗数、手相、六爻、奇门、风水（阴宅断法虽含"风水"字眼，但仍是八字看阴宅，不是罗盘风水）——不要抢其他术数领域的活。
2. **子平格局推演**：本书是盲派口诀直断，不走"正官格/财格"格局用神推演；问"这是什么格、用神是什么"用子平类技能。
3. **时辰缺失/双胞胎/时辰存疑**：串宫压运与日干起太岁必须以准确时柱为前提；书中有夜子时误排成贫命的实例警示（M6）。
4. **低置信民俗断语**：铁扫帚、属犯相、绊禄桃花、借子女看父母外情等民俗条目置信度低，供参考不供定论。
5. **从格/专旺格特殊配置**："财官印流向日主"总纲以常规命局为前提，旺极从格须先判从格再断（块18 月谈赋：木旺无金以从木）。
6. **断语时代局限**："女命干净""露财""克夫克妻"等断语含传统视角，现代社会须转化使用，不作绝对化结论。

## 出处

原文摘录：
> 盲派真谛秘决留，论命过程四步走。一看八字十神立，财官印食细追究。二看四柱与三垣，刑冲穿绝是主流。三看大运对命局，十年祸福定喜忧。四看流年应期到，串宫压运定数求。（第五章·论命四步）

> 财为养生之源，不可或缺，官为修身之本，不可太旺；印为护身之道，不可缺少。先看财官印是否有气，二看是否流向日主……财官相生入日主，命主肯定居富庄。（第四章·苏氏财官一口金）

> 盲派命学是真经，串宫压运显神功。四柱定格年为春，月夏日秋时为冬。依序排出十二神，诸神来管吉和凶。（第六章·串宫压运基础）

> 批命佐以神煞是为了提高准确程度，但神煞不可一查便说。首先要看神煞所临五行喜忌……其次要看神煞是否被刑冲穿绝临空亡？如是，吉则不吉，凶则不凶。（第二章·神煞运用补遗）
