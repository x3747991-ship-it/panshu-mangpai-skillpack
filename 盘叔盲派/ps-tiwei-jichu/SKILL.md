# 段氏理象学·基础表（查表册）

> 本册是《段氏理象学》（段建业 著）**底层基础表的补漏册**，与本库主册「段氏理象学」配套使用。
> 分工：主册走「**宾主 → 体用 → 做功 → 功量**」四步定层次；本册补它缺的**取体用底层表**——藏干、长生强弱、排盘三口诀、纳音交运、十干三列、十二支两列、十神四列等。
> 读它的正确方式：手上有个命要断，凡是卡在「这个字怎么起、这个字里藏着什么、这个字属什么、这个十神落哪儿」时，翻到对应那一组表去查；查完立刻回主册继续走那四步。**本册不单独出结论。**

## 什么时候用它

用户在跟着主册断命、卡在下面这些"查表"动作上时用它：

- 「月柱的天干怎么起」「时柱怎么定」「晚上 11 点半出生算哪一天、配什么时干」
- 「几岁起大运」「起运数是几天折一年」「什么时候交运、交运那天要注意什么」
- 「这个天干的人身体对应哪儿、性格什么样、长成什么形状」
- 「这个地支被冲了／被穿了，主什么病」
- 「他出生那一年的纳音是金木水火土的哪一个」
- 「某个十神对应什么场所、在什么单位做事」
- 「五行什么时候该生却不生、该克却不克、反倒被对方克」

**通用前置必是「段氏理象学」主册**——先由主册走完定宾主、分体用、找功、判功量，本册的表才用得上（藏干用来查根、纳音用来定交运、十干十支用来取象、十神四列用来落行业与场所）。本册是**查表册**，不替代主册。

## 核心判断

**表是"取体用"的底料，不是结论。** 同一个字，翻藏干才知道里头有没有根、通不通禄、能不能成党；翻纳音才知道这人哪一天交运；翻十神四列才知道这个词到底是"什么角色、在哪个场所做事"。没有主册那四步把这些表串起来，表查得再全，也断不出层次。

## 怎么做

四组表，按"先起盘、再取象、后判生克、末定角色"的顺序查。每组开头写明**什么时候查这组**。

### 第一步 排盘起局——查第一组表（六张）

**什么时候查这组**：手上只有出生年月日时（或已有四柱但要核月柱时柱、要排大运与交运）时，先过这一组。

**表 1-1 四柱排盘三口诀一特例**（年柱以**立春**分年、非正月初一；日柱直接查万年历）

年上起月口诀：

```
甲己之年丙作首，乙庚之岁戊为头；
丙辛之岁寻庚上，丁壬壬寅顺水流；
若问戊癸何处起，甲寅之上好追求。
```

（用法：「甲己之年丙作首」＝甲年、己年正月月干支为**丙寅**，二月丁卯，依次顺排十二月。）

日上起时口诀：

```
甲己还加甲，乙庚丙作初。
丙辛从戊起，丁壬庚子居。
戊癸何方发，壬子是真途。
```

夜子时／早子时之别：

| 时段 | 名称 | 起法 |
|---|---|---|
| 23:00–24:00 | 前一日的「夜子时」 | 以**当日**日上起时歌**推转一轮**，再纳天干（甲日之夜的子时＝**丙子**，非甲子） |
| 00:00–01:00 | 后一日的「早子时」 | 直接按日上起时歌诀推排 |

立四柱须**竖写**（年月日时竖排），男命记「乾造」、女命记「坤造」。
示例：2010 年 12 月 9 日凌晨 0 点 30 分生 → 庚寅／戊子／癸巳／壬子；同日 23 点 30 分生 → 庚寅／戊子／癸巳／**甲子**（夜子时，时干须推转一轮另定）。

**表 1-2 大运排法（四步）**

1. **定顺逆**：阳年生男、阴年生女**顺排**；阳年生女、阴年生男**逆排**。（阳年＝甲丙戊庚壬生年，阴年＝乙丁己辛癸生年）
2. **数天数**：从生日算起，按同样顺逆，数至**最近的一个节令**，看共几天。
3. **折年数**：天数**除以三**＝起运数；除不尽时**余一舍掉、余二进一**。
4. **定起运**：起运数应在 1–10 岁之间（一节气三十一天内，÷3 最大为 10、最小为 1）；当日交节、不足一天者，以**一岁**起运。

每运十年，**前五年走天干、后五年走地支**；起运岁数按**虚岁**定（出生当天算一岁，过一年加一岁）。

**表 1-3 盲派交运时间（按生年纳音定，本书特色）**

| 年命纳音 | 交运时间 |
|---|---|
| **火命** | 清明前三天 午时 |
| **土命** | 芒种后九天 辰时 |
| **金命** | 处暑当日 申时 |
| **木命** | 大寒当日 寅时 |
| **水命** | 冬至前三天 亥时 |

两点补充：① 上述"几天"均按**虚岁**的天数计；② 交运禁忌——**不要外出**（怕与自己属相不和之人相冲），**三日之内不参加红白宴事**。每**五年**交一次运（因大运前五年天干、后五年地支）。
用法示例：2005 年 3 月 15 日巳时生男（阴年生男，逆排大运），从生日逆数至最近的节令惊蛰（3 月 5 日）差 10 天，10÷3＝3 余 1（余一舍掉），故**3 虚岁起运**；其年命纳音为**水命**，所以此后凡逢交运之年，都是**冬至前三天亥时**交运。

### 第三步 判生克成不成、定五行行业——查第三组表（三张）

**什么时候查这组**：主册判"制局净不净、这一功成不成"时，碰到"明明该生的却没生、明明该克的却没克"，或要在还没走十神象前、先按日主／命局主导五行给一个行业大类时，翻这一组。

**表 3-1 三条生克细则＋旺喜克／弱忌克**

相生三条：

1. **母强喜泄**——强土喜金泄；强金喜水泄；强水喜木泄；强木喜火泄；强火喜土泄。
2. **子弱喜生**——弱金喜土生；弱土喜火生；弱火喜木生；弱木喜水生；弱水喜金生。
3. **母弱怕泄**——土弱金多则土易陷；金弱水多则金易沉；水弱木多则水易干；木弱火多则木易焚；火弱土多则火易熄。

相克两条：

1. **一方过旺，喜此方受克**——土旺得木方能疏通；木旺得金方成栋梁；金旺得火方成器皿；火旺得水方成相济；水旺得土方成池沼。
2. **一方过弱，忌此方受克**——土弱逢木必为倾陷；木弱逢金必为砍折；金弱遇火必见销熔；火弱遇水必为熄灭；水弱逢土必为淤塞。

**表 3-2 反生反克的边界条件**

相生反常：

| 该生而不生 | 边界条件 |
|---|---|
| **土不生金** | ① **燥土**——土中含火，性燥，不能生金反脆金；② **土多**——金被土埋，无法得生 |
| **金不生水** | ① **弱金**——金太弱，自顾不及，无法生水；② **冬金寒水冷**——冬季金寒水冷而不生 |
| **水不生木** | ① **水多木漂**——木无根见水易漂，不受水生；② **寒水**——冬水气寒，木冻难生，要有暖才可生 |
| **木不生火** | **湿木**——木被水湿，难以生火 |

相克反常：

| 该克而不克 | 边界条件 |
|---|---|
| **土不克水** | ① **水旺土弱**——土不能克水，反有水多土流之患；② **湿土**——土中含水，如泥巴一样；③ **金多或金介于其中**——土贪生金而忘克水 |
| **水不克火** | ① **火旺水弱**——水不能克火，反有击旺火性之忌；② **木多或木介于其中**——水贪生木而忘克火 |
| **火不克金** | **土多或土介于其中**——火贪生土而忘克金 |

## 判断标准

**做对了会看到**：月柱时柱能自己起出来（夜子时知道要推转一轮另定）；起运数能算出并知道余一舍、余二进；能按生年干支查到纳音、再落到"哪一个命、哪一个时辰交运"；碰到某字受伤时能立刻查到"应其病"；十神取象时**能说出这个词落在什么场所**（表格 4-3 的四列齐用）；碰到"该生没生、该克没克"时，能指出是燥土、土多、湿木，还是夹了一个贪生忘克的中神。

**做错了会看到**：
- 把本册的表当成结论直接报出去——只说出"这个字主文化、那个字主学校"，却说不清它在命里到底有没有做功、是几层功；
- 夜子时按当日直接排时干而**不推转一轮**（把甲日夜子时排成甲子而非丙子）；
- 起运数除不尽时**逢余就进位**（正确是余一舍、余二进一）；
- 交运时间按节气直接取、**不先查生年纳音**；
- 只查**年柱**旬空而不查日柱、或反过来（主册另有此条，本册表格同源）；
- 看主位之财时**只扫天干不翻表 1-5 藏干**，把"藏而不透之财"误断成"无财"；
- 十神取象只走六亲／人物／事物三列而**漏掉「场所」列**——行业只停在类别，落不到"在什么单位做"。

## 什么时候不该用它

1. **本册是查表册，不能单独拿来断命。** 没有主册的「定宾主 → 分体用 → 找功 → 判功量」四步，光有这些表断不出层次——藏干表查得出"有没有根"，但"这个根有没有参与做功"要回主册判；十神四列查得出"什么角色、什么场所"，但"这个角色是不是功神"也要回主册判。**凡是要下"富贵到什么层次""这命好坏"的结论，一律回主册。**
2. **表内的字不是断语。** 表 2-1、2-2、3-3、4-3、4-4 都是**取象库**，一个命里出现某字不等于该字所主之事必应；须先确认该字在局中的作用位置（主位／宾位、体／用、功神／废神）。
3. **主册已有的内容不在这里重出**：宾主体用、功神废神、贼神捕神、六种做功方式、制局通辨、制法明析、宫位类象（六亲／时序／空间／身体／物件）、神煞（禄刃墓马空）、干支物象（天干地支的物象与动物列）——这些请直接查主册「段氏理象学」与其 `references/干支类象.md`。本册只补它们**没有的那一份表**。
4. **五行宜业清单（表 3-3）只是粗分。** 它按"五行级"给行业，比十神级清单粗；主册要求取象四门（干支象＋十神象＋宫位象＋神煞象）齐走才能定到具体职业，只走本表会停在"五行类别"。
5. **本册继承主册的一切边界**：不看日主衰旺、废除用神、不认从格、基本不讲八正格、只用五个神煞；问婚姻、六亲、疾病、牢狱、应期的系统推断，本书未展开，本册同样不提供。问"能不能化解"——本派无化解法；问"佩戴／摆放某个字好不好"——本派无外物模块，一律不予编造。
6. **OCR 文本讹字须当心**：本册素材来自扫描 OCR，形近字（巳／己／已、戌／戍、癸／葵）易混。引用表格时若遇明显讹字，已按上下文订正并在文内注明（口诀中的「已」、纳音歌的「白腊金／金泊金／桑松木」）；**核不到的地方不补，直接写"原文未见"或照录原文并加注**。
