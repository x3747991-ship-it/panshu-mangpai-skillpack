### 作业 · 第1期（为何说此人是烧砖窑的／为何说此人是拉皮条的）

- 题目：本期为「第一期思考题答案」，含两问：①为何说此人是烧砖窑的；②为何说此人是拉皮条的。（题目见卷1/卷2·第1期，本卷未复现；题面条件由答案反推：命局含「戌」为火库、以燥土作财，行癸亥运；另一造以亥为用神、亥中甲木为劫、未土财为女人、亥未拱卯）
- 题目命例：无完整四柱列出（仅隐条件：一造「燥土作财，戌为火库」；一造「以亥为用神，亥中之甲木为劫，未土财表示女人」，本科未给干支）
- 答案：①此人是烧砖窑的；②此人是拉皮条的。
- 推理链：①燥土作财，戌为火库 → 类化为窑；行癸亥运助身取财 → 定为烧窑；庚辰年辰戌冲、乙庚合引动戌土 → 该年与人合伙烧窑（辰戍冲）。②亥未拱合禄神（命局本拱不成，大运入癸亥才给此机会，壬年始做此生意）；八字财多，未土财表示女人，亥欲合未、暗中拱卯，卯为日主自己 → 须经其暗中中介，亥未才能合成（中含甲己合）；其用神是亥水，靠亥赚取其他男人的钱 → 拉皮条；乙木根在未，女人都经过他的手。
- 涉及规则：干支意向·类化取象（戌为火库类化为窑）；禄与原身·亥未拱禄；以禄当财；六冲七法·冲出（辰戌冲引动火库）
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 干支意向 > 类化取象；L4 > 禄与原身；L4 > 六冲七法 > 冲出；L5 > 以禄当财
- 原文摘录：因燥士作财，戌为火库，类化为窑。行癸亥运助身取财
- 原文位置：卷3·第1期思考题答案

### 作业 · 第3期（此造为何在己酉运己卯年不吉）

- 题目：此造为何在己酉运己卯年不吉？（题目原文在本卷复现：**此造为何在已西运己卯年不吉？**；亦见卷1/卷2·第3期）
- 题目命例：乾造 丁未（原字：丁末） 壬子 丁巳（原字：丁已） 辛亥（天干行「丁壬丁辛」／地支行原字「末子已亥」）
- 答案：此年不吉——这一年跑了很多事，一事无成，没赚一分钱。
- 推理链：①己酉运 → 巳酉半合金局，为忌神合局；②己卯年 → 卯酉冲，酉动；③酉为中神 → 冲动局之中神会加强其合的力量，故不吉、空忙无财。
- 涉及规则：六冲七法·冲动（逢冲而动）；用神被冲合绊坏的应期（忌神合局逢冲反强）；三合半合（巳酉半合金局）
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 六冲七法 > 冲动；L5 > 用神被冲合绊坏的应期；L3 > 冲合刑害表 > 地支三合
- 原文摘录：己酉运巳酉半合金局，为忌神合局，己卯年卯酉冲，酉动

### 作业 · 第4期（诸造取用神与吉凶年份断验）

- 题目：（题目见卷1/卷2·第4期，本卷未复现；题面条件：给数造验其用神与各年吉凶——①乾造行乙卯运应大吉之应期；②乾造行癸丑运发财之应期；③以禄当财一造及似造之墓库开闭；④以禄当财之「禄怕劫财」例外）
- 题目命例：乾造癸卯 戊午 己酉 甲戌（天干「癸戊己甲」／地支「卯午酉戌」）｜乾造癸未（原字：癸末） 戊午 庚申 壬午｜乾造壬辰 丁未（原字：辰未） 庚辰 庚辰（天干「壬丁庚庚」／地支「辰未辰辰」）｜己酉 丁卯 庚辰 庚辰（天干「己丁庚庚」／地支「酉卯辰辰」）｜乾造壬寅 辛亥 甲寅 丙寅（天干「壬辛甲丙」／地支「寅亥寅寅」）
- 答案：①行乙卯运冲去忌神酉又合会忌神戌，主大吉；起步乙亥年、丙子年赚最多。②行癸丑运发财，95、96 年发大财，由穷光蛋成千万富翁。③以禄当财以禄为用；丑运墓库被冲穿打开不发入墓。④某造官星有用，喜用财官，不可用禄。
- 推理链：①乙卯运冲去忌神酉、又合会忌神戌 → 主大吉；丙子年子水财星为忌，八字先天结构去忌神癸水，财出现被去为应期 → 据「去忌神时得忌神」原理，该年发财最大；丁丑年生助酉金病神 → 官司赔钱；戊寅年戊土忌神透干不利。②以禄当财，火克金、救金需用水（水有抑火调候之功），乙亥年合用神临身；命中有午未，丑未冲、丑午穿，墓库被打开而不会墓金 → 丑运遇冲穿则发；丙子年合墓为应期，冲墓喜合 → 发最多。③第二期一造行丑运墓库不逢冲害，待辛未年冲墓而发，丙子年合墓而闭；庚辰年已行完丑运不再发。④辰未辰辰造以禄当财，时干庚金为「干禄」，用神土与金；壬子运十年不顺；乙亥年乙庚合、金衰被合去受重伤；丁丑年子丑合去忌神子。⑤己酉卯辰辰造：丁火官星有用，喜用财官，不可用禄。⑥壬寅寅亥寅寅造：官星极衰无用，本可用食神泄秀却逢丙辛合无法用食神 → 只能以禄当财；禄神太多则不贵；乙卯运己卯年禄临旺乡、甲己合动日主表示命主自己享到「禄」（命中原无劫财，行卯运非分禄）。
- 涉及规则：去忌得用·去忌神时得忌喜；以禄当财（禄作寿元星，忌劫财）；墓库·入墓/入库与冲开合闭；用神扶抑/调候；十干体象（官星有用与否决定能否以禄当财）
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 去忌得用 > 去忌神时得忌喜；L5 > 以禄当财；L4 > 墓库 > 入墓 / 入库；L5 > 用神扶抑 / 调候 / 病药 / 从势
- 原文摘录：此因命中有午末，丑未冲，丑午穿，墓库被打开而不会墓金
- 原文位置：卷3·第4期作业答案

### 作业 · 第5期（食神去官格之升职与旧事翻案／金水伤官之品行）

- 题目：（题目见卷1/卷2·第5期，本卷未复现；题面条件：①乾造行壬午运辛未年、辛巳运丙子年两度升职，并断文字转行政、96 提拔、庚辰翻旧帐；②乾造丙子运乙亥年为重大转折之应期与流年抉择）
- 题目命例：乾造乙酉 丙戌 甲戌 己巳（天干「乙丙甲己」／地支原字「酉戌戌已」，时支判正为巳）大运 8乙酉 18甲申 28癸未（原字：末） 38壬午 48辛巳（原字：已）｜乾造甲辰 癸酉 庚辰 壬午（天干「甲癸庚壬」／地支「辰酉辰午」）
- 答案：①行壬午运的辛未年升职，行辛巳运的丙子年升职；此前从事文字工作，90 或 91 年转行政，96 年提拔，庚辰年因别人之事牵涉、翻旧帐、与钱有关。②转折在丙子运的乙亥年——由医院保卫科科长调入某厅升为副处长（98—99 年在扶贫工作队任队长）。
- 推理链：①此造食神去官成格，用神是火（火主文字、写作或绘画）→ 八十年代中后期搞文秘；伏宫在八岁（辛酉）遇干之年升官，辛未年宫易正透、被丙火合去 → 主升；辛巳运它在大运透干 → 断被八岁合去或克去之流年升职，丙子年无疑；庚辰年七杀忌神被年劫财合入命中 → 事由别人引起；辰戌冲 → 旧事重提，冲财与财有关；立秋甲申月合杀被冲、杀星得禄 → 最厉害。②甲辰造金水伤官主聪明秀气；辰土混水 → 俗；吹牛说谎因伤食混杂又地支无根（食神主言语，混伤官则话语不着边际，水虚浮支无强根 → 言而无信）；食神下面落官星又暗合 → 会拍马屁奉迎上司；转折断乙亥年而非壬申/癸酉，因乙庚合、六岁之喜合入命主 → 喜事临身；大运入丁丑略差于丙子，庚辰年无八字所喜之水出现 → 平调不升。
- 涉及规则：去忌得用·伤官去官格（食神去官成格，伤官去官不论日主衰旺）；伏吟反吟；六合三用·合绊（合去忌神主升）；活论十神·食神言语与伤食混杂
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 去忌得用 > 伤官去官格；L4 > 伏吟反吟；L4 > 六合三用 > 合留；L4 > 活论十神
- 原文摘录：此造食神去官成格，用神是火，火主文字、写作或绘画

### 作业 · 第6期（辰土寿元星空亡，穿倒寿元星之应期）

- 题目：（题目见卷1/卷2·第6期，本卷未复现；题面条件：乾造从财，取何为用神兼寿元星，并断其死于何时何因）
- 题目命例：乾造壬辰 庚戌 丙申 壬辰（天干「壬庚丙壬」／地支「辰戌申辰」）大运 辛亥 壬子 癸丑 甲寅 乙卯（天干「辛壬癸甲乙」／地支「亥子丑寅卯」）
- 答案：此造命不长，死于乙卯运，庚辰年车祸身亡。寿元之星为时上一辰土，燥土戌不为寿星。
- 推理链：①八字从财 → 以土泄火生财作用神，也作寿之星；②看似土多，实际戌土为忌神不作寿星，年支辰太远又逢冲 → 年月辰戌之土可不看，只用时上一辰土（少而精，且处于「主」的地位）；③今辰土空亡 → 兆其寿不会长；④乙卯运卯辰穿 → 穿倒寿元星主死于此运（六合与六穿、六冲地位一样，不能说合可解穿，只能合穿兼论，故卯戌合不解卯辰穿）；⑤庚辰年为死亡之期：辰土出空出现 + 辰戌冲使卯戌无法合 → 一心一意穿辰；印主车，「穿」者撞之意 → 车祸身亡。
- 涉及规则：从格分辨（八字从财）；穿害·穿害断病灾 / 穿中带生克；禄与原身·寿元星（禄/印为寿元星，被穿倒则应凶）；空亡·出空应期；六冲七法·冲动
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 从格分辨；L4 > 穿害 > 穿害断病灾；L8 > 生死寿元；L4 > 空亡
- 原文摘录：乙卯运卯辰穿，穿倒寿元星主死于此运
- 原文位置：卷3·第6期作业答案

### 作业 · 第7期（一）（解释此造为私生子之理）

- 题目：解释此造私生子的理是……（题目描述在本卷复现：**解释此造私生子的理** ；亦见卷1/卷2·第7期）
- 题目命例：乾造己卯 壬申 丙午 辛卯（天干原字「己王丙辛」，月干判正为壬；地支「卯申午卯」）
- 答案：他一定是母亲与他人偷情的私生子——真父为情夫、名义之父为母亲正式丈夫；庚辰年偏财星透干，真父大白天下，父母离异。
- 推理链：①偏财申金秉令为生父，正印卯木为生母；②印星伏藏而财秉令 → 说明他是父亲的小老婆所生；③卯申暗合 → 为父母偷情之意；④正财辛金为名义之父，且坐在正印之上 → 是母亲的正式丈夫；⑤故定为母亲与他人偷情所生。事件：其母与有妇之夫同居，无法作正室便找个男人结婚作掩护，为情人生下此造，后被丈夫发现、对薄公堂。
- 涉及规则：活论六亲（偏财为生父、正财为名义之父、正印为生母）；干支意向·暗合（卯申暗合主偷情）；活论十神·财印伏藏
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）
- 模型路径：L4 > 活论六亲；L4 > 干支意向；L4 > 活论十神
- 原文摘录：偏财申金秉令为生父，正印卯木为生母，印绥伏藏财秉令，说明他是父亲的小老婆所生
- 原文位置：卷3·第7期作业答案

### 作业 · 第7期（二）（找用神：五造取用之正误）

- 题目：找用神（题目描述在本卷复现：**找用神：** 下列五造的用神判断，附易错点说明；亦见卷1/卷2·第7期）
- 题目命例：①乾造壬辰 癸卯 戊辰 丙辰（「壬癸戊丙／辰卯辰辰」）｜②乾造己卯 丁丑 庚戌 庚辰（「己丁庚庚／卯丑戌辰」）大运 丙子 乙亥 甲戌 癸酉 壬申 辛未（原字：末） 庚午｜③乾造庚戌 辛巳 丙辰 乙未（原字：末）（「庚辛丙乙／戌巳辰末」）；《命理指要》三造：辛丑 甲午 丙申 丁未、甲午 甲戌 丙辰 甲午、戊戌 己未 丙午 戊戌｜④乾造戊寅 甲寅 甲戌 甲子（「戊甲甲甲／寅寅戌子」）｜⑤庚子 庚辰 庚辰 戊寅（「庚庚庚戊／子辰辰寅」）
- 答案：①用火为正解（非土多身旺用财）；②从禄用湿土与金（非火调候）；③用神是木（非火，非金）；④用火（甲木参天，脱胎要火）；⑤水作用神、金为喜神，火土为忌。
- 推理链：①辰为湿土如泥巴无法帮身，且卯将辰穿坏 → 用火为正解；癸酉年由老板变穷光蛋（癸生寅木? 实为忌），戊寅年长生丙火赚钱；注：春生与秋生之戊土一般都用火，尤爱丙火。②丁火坐寒土、根被冲刑坏，卯木无法生过来，火无用 → 必从禄用湿土与金（与王立军命相似）；以仇甫全先生经历逐运验证：丙子运丙火、子水皆忌且子丑合绊用神丑 → 不吉；乙亥不损土金 → 平常；甲戌最差（甲生丁忌、戌冲去用神辰）；癸酉好转（癸去丁、酉去卯）；壬申最好（壬去丁、日主得禄）。③不管是燥土还是湿土都晦火 → 日主以弱论而且很弱，用神是木而非火（连带《命理指要》丑午申未、午戌辰午、戌未午戌三例都用木）。④身旺直流通，取火作用神（《滴天髓》曰「甲木参天，脱胎要火」）；取辛金正官没有半点道理；李后启将丙辰运庚子年 22 岁当小学校长释为「杀透干制比肩忌神」，实为杀为忌虚透干、被大运丙制而得官。⑤比较难找用神，实际水作用神、金为喜神、火土为忌；辛酉年结婚，癸亥—丁卯年发财，戊辰年赔光欠债，丙丁年好转，甲申运财运很好。
- 涉及规则：用神扶抑 / 调候 / 病药 / 从势；十干喜忌（甲生酉月喜水润、戊土春生秋生用丙火）；从格分辨（从禄用湿土与金）；六合三用·合绊（子丑合绊用神）
- 验证状态：教学验证（经讲师批改）
- 置信度：中（教学例，经讲师批改）

### 作业 · 第46期（乾造乙未造为何子水为忌神）

- 题目：请大家说说为何此造子水这忌神？（本块内题目齐全；另附主命例之直断与「如一例」附例）
- 题目命例：乾造 乙未 戊子 乙卯 壬午（原字：乙戊乙壬／未子卯午，无错字）。附例：乾造 辛丑 庚寅 戊子 壬子（原字：辛庚戊壬／丑寅子子，无错字）
- 答案：主命例直断——此造是银行行长，岳父是高官，他是沾岳父的光爬上去的：以印星子水为忌神，未财制之；命中用神是未，财星本作父看，但临「应」位，故为岳父。作业答——此造乙木冬生本应火为调候，但又见了（子水）不生卯反破卯，故作忌神；好在未穿之，去印得官，故为官。
  附例（辛丑造）——有人会认为初春气寒用火，那就大错了；寅中丙气弱，不生戊土，故当忌神看。从财，以印为病，去印得官，在丁亥运中大吉升职，到丙戌运反降职，诸事不顺。
- 推理链：

  4. 结果——未土穿子（去印）→ 去印得官 → 故为官。
  5. 附例同理——初春气寒本应用火，然寅中丙气弱不生戊土 → 寅当忌神；从财以印为病 → 去印得官；丁亥运大吉升职，丙戌运反降职。

### 作业 · 第48期（坤造庚戌造为何亥为忌神）

- 题目：说说此造为何亥为忌神？（本块内题目齐全；另附「又如」两例）
- 题目命例：坤造 庚戌 壬午 丁亥 乙巳（原字：庚壬丁乙／戌午亥已，判正：已→巳）。附例一：乾造 甲辰 癸酉 庚辰 甲申（原字：甲癸庚甲／辰酉辰申，无错字）。附例二：乾造 癸丑 辛酉 癸亥 丁巳，5岁行运 庚申 己未 戊午（原字：癸辛癸丁／丑酉亥巳；大运 庚己戊／申末午，判正：末→未）
- 答案：主命例——此造身强，有官则先论官；但若以官星为用，则官星被坏（亥被旺巳冲，又坏其原神，还虚透），故官不能作用；看八字日主占禄刃之旺，应从其强势，见亥可当病神看。（郝先生讲八字不要看衰旺，也不要看用神……此八字说亥水是用神，那是用神被坏；说亥水是忌神，那是忌神无法去又临身，怎么看都不好；只要见到这种组合极差，亥水是用神或忌神都无关紧要。）
  附例一（甲辰造）——身旺，甲木财星不论用神或忌神，组合都不好：作用神看根被坏、逢生不起；作忌神看有原神生而去不干净，故是差命。
  附例二（癸丑造）——此造身强，从强以财作忌神；贵在财无原神、原局中被制，行财运可发财，但最怕流年见时（柱）之原神，果，戊寅年赔钱。
- 推理链：
  1. 主命例——身强 → 有官先论官。
  2. 官不可用——官星亥被旺巳冲、坏其原神、又虚透 → 官不能作用。
  3. 从强取用——日主占禄刃之旺，从其强势 → 亥当病神看。
  4. 反诘（郝先生语）——此等极差组合，亥为用神则被坏、为忌神则无法去又临身，用忌之争无关紧要。
  5. 附例一——身旺，甲木财星作喜作忌皆不佳（作喜根坏逢生不起、作忌原神生而去不净）→ 差命。
  6. 附例二——身强从强，财为忌神；财无原神、原局被制 → 行财运发财；最怕流年见时柱之原神 → 戊寅年赔钱。
