# 盘叔盲派 · 命理珍宝 断法主干

> **本技能是「元规则断法主干」**——不做单单一件断事，而是给出**全书断法总纲 + 大运流年 + 取用神**，供所有断事类技能**前置调用**。
> 体系来源：段建业《命理珍宝》第1–50期（盲派郝金阳一脉），有效正文 61,935 字。
> 与子平类技能的分工：**子平类技能管"月令取格、三用神统一"；本技能管"宾主归属、吉凶与应期、去忌神得忌神、十神意向"。** 二者结论冲突时，按调用方技能的口径声明，不得混用。

## ⚠️ 零、铁律（先读，后断）

1. **宾主先行**：任何吉凶判定之前，先确定"谁作用谁"——同一字处"主"位代表命主自己、处"宾"位代表他人。**不判宾主就下断语，必错归属。**
2. **吉凶与应期分论**：**大运主吉凶、流年主应期**。流年本身无吉凶，只在与大运作用后形成吉凶。不得拿流年字面直接断吉凶。
3. **冲害合同论**：合**不能**解冲害，冲害也**不能**解合；四者同时出现时力量俱减。**只有"无冲害合"时才论三刑/三合/半合。**
4. **无出处不断**：每条断语带期号（珍宝·第N期）。凡属作者补述而非原文直推的口径，标「作者口径」。
5. **不造新术语**：本书术语（宾主/贼神/意向/患/关财门/绊禄桃花/内食神/天地合）已有专义，不得替换为通行义。
6. **时代口径降维**：女命"淫贱/卖身"、官贵本位"一品/罢官"等属旧语境，转译时须标注并降维表述。

## 一、入口判定

### 1.1 什么时候用它
| 触发场景 | 说明 |
|---|---|
| **起手断一命** | 用户报出四柱（+性别），问"这命怎么断/从哪入手" → 本技能给断法主干与六步流程 |
| **定大运流年吉凶** | 问"哪步运好/哪年应事/为什么这年会这样" → 走 L7 岁运体系 |
| **取用神** | 问"该取什么用神/为什么用这个字" → 走 L5 用神体系（禄财三路 + 贼神 + 虚实 + 调候） |
| **判吉凶归属** | 问"这事是在我身上还是在我亲人身上" → 走 L4.1 宾主 |
| **被前置调用** | 其他断事技能（婚姻/官命/财运/六亲/牢狱/寿元）在断吉凶与应期前，先取本技能的【通用断法前置】模块 |
| **辨正错误断法** | 用户引用"逢冲必凶/三刑凶/伏吟凶/缺什么补什么"，要判对错 → 走"失效场景"节反驳 |

### 1.2 什么时候不接（入口挡板）
- **无排盘**（缺四柱、只给生肖年份）→ 不接，先补盘。
- **缺时柱** → 时柱相关判断（门户取象、子女宫、归禄、时上财、伏吟门户）全部降级为"待定时辰复核"，其余照断。
- **纯排盘方法 / 基础概念（干支五行十神定义）/ 神煞表 / 纳音** → 本书不讲，转排盘类技能。
- **紫微斗数、六爻、手相、姓名学、风水布局** → 不接（第39期住宅取象仅作取象，不作断法）。
- **博彩预测（六合彩特码）** → 第36期整篇已剔除，不接。
- **无模型路径、无期号出处的推论** → 不作为本技能结论输出。

## 二、【通用断法前置】模块（★ 其他技能可直接调用）

> 这一节是本技能被其他技能前置调用的接口，**与格局属什么、断哪一件事无关，所有命都用**。

### P1 宾主卡（先填这张卡）
```
主 ── 日主 / 日柱 / 日时 / 贴日主者 / 八字 / 八字+大运 / 禄印比肩 / 食神财星 / 用神喜神
宾 ── 他干支 / 他柱 / 年月 / 远离者 / 大运流年 / 太岁 / 他神 / 杀刃劫 / 忌神仇神
```
**用途**：①定吉凶归属（自己 / 亲人）②定吉凶性质与轻重 ③定"同字异位"的解释（卯在日时＝自己，卯在月年＝别人）
**出处**：珍宝·第6期

### P2 岁运卡
```
大运 = 吉凶　　流年 = 应期
作用次序 = 先判宾主 → 流年先与大运作用 → 再作用于八字
应期三则 = 合者见冲为应 / 冲者见合为应 / 没有的出现时为应
太岁反客为主 = 太岁干支与八字某支见禄见比 → 该年必应此字之事
十年分合 = 流年与大运无刑冲合并 → 上下五年分看；有刑冲合并 → 十年统看
```
**出处**：珍宝·第21期、第6期、第30期

### P3 冲合刑害优先级
```
六合 > 三合局 > 三会局
先论冲合害 → 再看别的；冲害合同论（力量俱减）
无冲害合时 → 才论三刑 / 三合局 / 半合局
流年冲八字大运 = 动；冲墓库 = 开
大运冲八字不主动；旺冲衰 = 破；冲墓一般主破
```
**出处**：珍宝·第21期

### P4 忌神处理卡
```
① 先判忌神强弱
② 弱忌神 → 旺制（彻底制服，做"客贼神"）
   旺忌神 → 弱制（周旋平衡，最易生存）
   略偏旺 → 平衡制（用印化杀、化敌为友）
③ 旺用神怕弱制（同理：旺用神被弱制 → 小气、心胸窄、成不了大气）
④ 去忌神时得忌神：忌神被去的流年为应期，该年反而得到该神代表之物
⑤ 忌神不出现 → 该事物不需求、自然天成
```
**出处**：珍宝·第38期、第34期、第4期

### P5 虚实卡
```
干透无根 = 虚　　有根 = 实
虚忌神 / 实用神 → 吉　　实忌神 / 虚用神 → 凶
不宜：虚忌神受生、实用神被制
最宜：实忌神被制、虚用神受生扶
两例外：①调候用神虚也吉 ②泄神宜虚（秀气、清气）
```
**出处**：珍宝·第32期

### P6 十神意向卡（活论十神与六亲）
```
某神的含义随与其对应/相关的神出现与否而变
印 → 学术/荣誉/权力/地位/房车；正印=正统职业，偏印=非正统+鬼才
官杀 → 职务/权力/官匪/官司/疾病/桃色；天干杀=名声，地支杀=心劲
财 → 财富/欲望/色欲；财透干而虚=才华、会来事；偏财色欲尤显
食伤 → 食神温顺优良；伤官傲慢狡猾；二者皆主自由；伤食见金受制=军人
比劫禄刃 → 争夺；羊刃凶中之凶（兵刀/手术/灾祸）；禄=自尊/肉体/权力/财富/寿命
内外 → 内食神者被人吃，外食神者去吃人
```
**出处**：珍宝·第29期、第14期、第26期

## 三、断法步骤（六步）

```
第1步 排盘补齐 → 四柱+性别+大运；缺时不接；缺时柱降级
第2步 立宾主   → 填 P1 宾主卡，明确"谁作用谁"、同字异位归属
第3步 定势与病 → 五行能否平衡？不平衡则看"势"；有势须有病（病神是什么就能得到什么）；无病反为贱
第4步 取用神   → 三路递进：
                 ① 财 / 官杀 / 伤食 有可用者 → 用之
                 ② 三者俱不可用而命中有禄 → 以禄当财、以禄当官
                 ③ 都找不到 → 反找忌神（以忌神定局）
                 并叠加：虚实卡（P5）+ 忌神处理卡（P4）+ 调候（条件触发，见规则集 M/L 节）
第5步 定格局与断事 → 伤官去官 / 比劫去财 / 去印得权 / 禄格 / 内食神 / 从格族 / 官命七配
                 断事：官·财·婚·六亲·牢狱·职业性情·色性·骗子·寿元·下岗
第6步 行运收口   → 大运定吉凶、流年定应期；冲合刑害按 P3 排序；
                 圈高危：禄神复吟、入墓之应、反客为主、伏吟、破（卯破午）、穿倒寿元星/六亲星
```

**做对了会看到**：先出宾主卡 → 出"势与病" → 用神给三路结论（含"为何不用财/官/食伤"）→ 格局名带期号 → 断事分"原局"与"行运"两块 → 应期给到具体流年并说明是"合应冲/冲应合/出现为应"哪一则 → 每条带期号。
**做错了会看到**：不判宾主直接断 → 用旺衰强弱法取用神了事 → 拿流年字面断吉凶 → 见三刑/伏吟/冲旺就断凶 → 忌神被去就断吉（未分"对人吉、对该六亲凶"）→ 用神终身化 → 断语无出处。

## 六、失效场景（什么时候本技能不成立 / 该被反驳）

### 6.1 本技能失效的边界
1. **喜忌判错则全盘皆错**：本书格局判据是"能否去忌神"，是**动力型**判据；若"势与病"判错，格局、用神、应期全部连锁出错。**调用前必须独立校验喜忌。**
2. **命例即偏样本**：全书命例几乎全是"已知结局后反推"（名人、已故者、作者本人及友人），存在事后合理化与幸存者偏差。**不得据此宣称预测效力**；引命例佐证须声明此局限。
3. **师承口诀不可溯源**：标"郝先生讲/郝先生有诀"者（穿倒羊刃、穿倒正印归不了正、食冲者缺乳缺食、妻入墓喜冲、金见水沉为牢狱、十年统看vs五年分看）在本书记载之外无出版物可查，只能标 **「师承口传（本书转述）」**。
4. **两处作者未给答案**：第3期"丁未 壬子 丁巳 辛亥 造己卯年为何不吉"与第31期"丁酉 壬子 庚辰 戊寅 造子水为何为忌"未获完整解答，不得硬补。
5. **不覆盖基础层**：不系统讲排盘、节气、藏干、神煞表、纳音；**不覆盖**化气格、专旺五格（曲直炎上稼穑从革润下）、两神成象、暗冲暗合——此类判断须转子平类技能。
6. **OCR 错字**：原文干支有错（`乙己`应作乙巳、`寅庚`应作庚寅、`酉辛`应作辛酉、`李连英`应作李莲英、`撤切尔`应作撒切尔、`马莉莲·梦露`应作玛丽莲·梦露），引用干支须核对校正并标 `[OCR校正]`。
