## 四、神煞类象

**出处**：第一章·象法 第二节（P18–P22）

### 4.1 禄神

**查法**：甲禄在寅、乙禄在卯、丙戊禄在巳、丁己禄在午、庚禄在申、辛禄在酉、壬禄在亥、癸禄在子。

| 维度 | 内容 |
|------|------|
| 心性 | 亲为、独立、主张、自我意识、尊贵、独占、主宰、享受 |
| 物象 | 权力、封地、财富、供养 |
| 身体 | 身体、肢体、女人的肉体、寿命 |
| 说明 | 是日主的延伸，代表日主到地支行使权力。年月的禄不代表自己，可以被制；日时的禄代表自己，不能被制 |

### 4.2 羊刃

**查法**：甲刃在卯或乙、丙刃在午或丁、戊刃在未或巳、庚刃在酉或辛、壬刃在子或癸。**只有阳干有羊刃，阴干没有羊刃**。羊刃也可以看天干。

| 维度 | 内容 |
|------|------|
| 心性 | 胆大、勇敢、凶恶、狠毒、不计后果、不顾面子、占有欲、侵害、不利父妻 |
| 物象 | 刀、枪、剑、手术、兵器、武装、政法、执法 |
| 身体 | 四肢、身体 |
| 说明 | 虽是劫财之一种，但比劫财之心性更凶悍 |

### 4.3 墓库

**含义**：收藏、控制之意。库象由所墓之十神决定。

| 库类型 | 象 |
|--------|----|
| 羊刃库 | 军团、营地 |
| 伤官/食神库 | 寺庙、学校、工厂 |
| 财库 | 银行 |
| 官杀库 | 权力中心、组织部门 |

> 「凡是聚集众多的意思都是库的含义，大家可以举一反三。」

### 4.4 驿马

**查法（盲派，与常法略不同）**：申子辰马在寅午戌，寅午戌马在申子辰，巳酉丑马在亥卯未，亥卯未马在巳酉丑。以年柱和日柱为主查。

| 维度 | 内容 |
|------|------|
| 心性/事象 | 走动、外出、远行、游走、迁移、奔忙 |
| 物象 | 车、船、马 |
| 说明 | 驿马逢合，表示停留、不动之意 |

### 4.5 空亡

**六甲空亡**：

| 旬 | 空亡支 |
|----|--------|
| 甲子旬 | 戌、亥 |
| 甲戌旬 | 申、酉 |
| 甲申旬 | 午、未 |
| 甲午旬 | 辰、巳 |
| 甲辰旬 | 寅、卯 |
| 甲寅旬 | 子、丑 |

**查法**：以日主或年柱为主，观他支中见者为空亡。

| 维度 | 内容 |
|------|------|
| 类象 | 务虚、玄学、空物、减半、损失、不全、挂名、名义、有名无实、形式、气、象、影子 |
| 宫位义 | 年支空亡祖业空；月支空亡兄弟无靠或有伤损；日支空亡做事虎头蛇尾、少成多败、无归宿感、夫妻缘薄；时支空亡子女迟育或子女有损伤 |
| 吉凶 | 凶星空亡凶减半，吉神空亡福不全。命中所用之神旺相而空亡，主性格气度宽大、超凡脱俗，能成就于务虚事业（佛道、玄学、五术、气功、艺术） |
| 五行空 | 金空则鸣、火空则发、水空则流、木空则朽、土空则陷 |
| 说明 | 天干也可讲空亡（原局无、大运来亦算）；流年不讲空亡 |

### 4.6 亡神

**查法**：亥卯未之亡神在寅，寅午戌亡在巳，巳酉丑亡在申，申子辰亡在亥。年、日查。

| 维度 | 内容 |
|------|------|
| 心性 | 代表人的心性，含义与空亡之神相接近 |
| 类象 | 亡命之徒、胆大、你死我活、容易犯罪、做事做绝、致敌人于死地、无情无义、没有边际、有计谋、力量大 |

### 4.7 劫煞

**查法**：亥卯未劫煞在申，寅午戌劫煞在亥，巳酉丑劫煞在寅，申子辰劫煞在巳。劫煞处五行绝地。

| 维度 | 内容 |
|------|------|
| 心性 | 表示人的心性 |

### 4.8 华盖

**本书仅一处提及**：「辰为华盖，金水组合为肺，见辰土主湿。」（第十章·疾病 P83）

|-----------|------|

**断病入手方法（第二节）**：①从命局过弱之五行入手；②从命局过旺之五行入手（被克之五行、生多为克、盗泄太过）；③从被冲克之五行入手；④从被合化之五行入手；⑤从寒暖燥湿入手。

> 「生多为克」：土多金埋；金多水浊；水多木漂；木多火塞；火多土焦。
> 「盗泄太过」：火多木焚；木多水缩；水多金沉；金多土虚；土多火晦。
> 「合化」：某五行被合化掉，实质就是此五行受伤，改变了性质。

### 6.3 速度与车祸机制

| 机制 | 内容 |
|------|------|
| 火穿冲表速度快 | 酉戌穿、寅巳穿、丑午穿、丑未冲、寅申冲、子午冲、辰戌冲等 |
| 其他穿 | 除火穿外，其它穿也容易出现车祸 |
| 带火的穿 vs 带水的穿 | 带火的穿（酉戌、寅巳、丑午）速度比其它穿快得多；带水的穿（申亥、子未）速度慢 |
| 引动条件 | 由大运流年引动而发生车祸 |

**原文摘录**：
> 「辰、丑、申、酉、子，子有转动的轮子象，都可以表示车。有的车的象对称，象征两个轮子。火穿冲表示速度快，如酉戌穿、寅巳穿、丑午穿、丑未冲、寅申冲、子午冲、辰戌冲等，除了火穿外，其它穿也容易出现车祸。驿马也表示车象，除车象外，还有其他凶象，因大运流年引动而发生车祸。」
