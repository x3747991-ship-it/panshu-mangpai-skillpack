# 夏仲奇断事补法

## 什么时候用它

用户报一个八字，问的是下面这些"别的册子没收"的事：

- 这人的性子怎么看？（古怪易出偏、正派本份、口才好、是干公安还是当盗贼的料）
- 他以后干哪一行？（房地产、酒店、服装布匹、下矿井、刑警队长……）
- 我父母是不是再婚？我是不是随娘改嫁、有没有继父养父、会不会被过继、会不会一进门就当后娘？
- 这件事应到哪一年、哪个月？
- 从我的八字看，我将遇到的对象／我儿子会怎样？
- 我这个第三者要等几年才能转正？
- 某一方被克，但它得了生，会不会反过来去克对方？
- 什么命的"不入公门"（当不了官、进不了公职）？
- 婚姻应期里"定婚"和"结婚"是同一件事吗？

**通用前置见「夏仲奇看命总纲」**——先做定盘与时辰校正（L2）、立宫位（L3）、配六亲星（L4）、读合冲刑穿墓空（L5）、取象（L6）、定应期（L7）。本技能只写现有七册（看命总纲、断财禄事业、断官非灾祸、断婚姻、断六亲、断法边界、取象直断）**没有收**的那一层；凡与它们重叠的，只留一句"另见「XXX」"，不重复展开。

（书末附录《为什么瞎子才算得准》是**外来口径**，单列在正文之后，不与正文混用。）

## 核心判断

同一张八字、同一组干支，会因为**"是丙还是丁""有印还是无印""得生还是没得生""活木还是死木"**这几处分岔，走到完全相反的心性、职业、吉凶上去——本册补的就是这些"分水岭"判据，以及"事要应到几月""对方会怎样"这类落到细处的断法。断法仍守本派总则：不取用神、不论衰旺，只用宫位／星位＋合冲刑穿墓空＋流年引动（L1、L3、L4、L5、L7）。

★ **本册有一节是"外来口径"，必须单独看**：书末附录《为什么瞎子才算得准》用的是**用神／神煞／三奇／阳刃**，还带"万不可拘泥""你须自辩而通"这类说法，与夏仲奇"铁口直断"的体系**不完全一致**。该节把八条判法**单列**在正文之后（见「★ 附录口径」一节），全部标为【附录】层，**用前须知口径不同，不得与正文口径混写**。

## 怎么做

按"用户先问什么，就先查什么"的顺序走。每步开头写清：从哪儿问起 → 去哪几个字上找 → 落到什么结论。

### 第一步 查性格心性

1. 先看局里有没有"伤官坏局"，再看伤官是火还是别的。伤官坏局且为火，断"性情古怪、狂妄自高、易走极端、精神出偏"；应期落行伤官之运＋相应之支的流年。【段解】"大儿子命：甲辰、丁丑、甲戌、丁卯，是伤官丁火坏了命局，火主神经，故是神经病。"（block_06）
2. 看正财是否透干。正财在天干 → 断"这人正派、本份"；若财星又入墓（如辛见丑入墓），连带断"生官与产生情欲的能力已经没有了"，可推守份不婚。【原文】"你看她的八字，正财在天干，所以她很本份。"（block_16）（婚姻那半边另见「夏仲奇断婚姻」。）
3. 看食神是否高透。食神高透 → 断"口才好、会说话办事"；但**不能**因官杀偏重就断"犯桃花"，正派与否要看夫宫与官杀的实际作用。【邢解】"说她嘴会说是因戊土食神高透，食神主口会说话办事。"（block_10）
4. 看局中是"两丙"还是"两丁"。两丙占阳 → 光明正义，走公安；两丁占阴 → 隐蔽破坏，走盗贼。这是**心性方向**的取象：木火为阳、金水为阴，以阳制阴＝正义战邪恶，以阴坏阳＝黑道。【段解】"木火为阳，金水为阴；阳主光明、显耀，阴主隐蔽、潜藏，以阳制阴是以正义战邪恶，就是公安刑警之象，反之以阴坏阳，便是黑道象。"（block_16）
   - ⚠ 此条原文层用了"喜阳火"的喜用式表述，段解已改判为**阴阳取象**；引用时**不得同时声称本派不用衰旺**。
5. 看局中有没有"印"。同样是"伤官穿官"的结构，**有印制住伤官** → 伤官之心性转为"为正规机构服务的才能"（走正道、入公门）；无印制则堕为黑道。这是"同一组合、心性两分"的分岔口。【段解】"此造与壬辰造有些相似的地方，但她却是个官员，为何？因局中有印之故，因印能制伤官，伤官之心性转成为正规之机构服务的才能。"（block_07）
6. "生性风流""不是什么好人""命生得贱"这一类话，**本书是先出结论、后补旁证，未给可复算的判据链**，只能当结论级评断记存，**不得**当可独立推演的判据。（block_08／25／22）
7. ⚠ 稿中「火弱有水 → 这种人淫」一条，**已被「夏仲奇断法边界」列为性别歧视色彩、待隔离、不得当可迁移判据输出的原话**；本册只作缺口录存，**不要写成判据用**。（block_02）
8. 把"看人"与"看八字"分开："直性子、认死理""性情豪爽"这类是**现场观人／叙事**，原文未见对应的八字判据，不可倒推。（block_09／05）

### 第二步 查职业与行业方向

1. 先定发财结构，再取行业象，**不要一开口就报行业名**。以"财官临库、丑财库被戌刑开"定发财结构，行业方向才落到"房地产、酒店"这类大事业上；发财应期另给。【原文】"将来你刁；用再卖豆腐了，可以干大事业，最后你要搞房地产、酒店，成亿万巨富……你从1991年开始发财。"（block_01）
2. 断"从男人手中挣钱"这类职业（出卖色相）：落点是**日干合财星（意向取财）＋官与库支相穿（财来路不正、违法）＋伤官之库**。【邢解】"此造甲生戌月，伤官之库，年支酉金官星，与之相穿，又日干甲合己土财星，故她意向取财。"（block_03）
   - ★ 本条的**诚实记录必须原样保留**：【段解】"如用现在流行的日主衰旺原理解，不仅不可能看到如此程度……如果你认为官杀为忌，便不能理解她为何总从男人那里取财；若认为官杀为用，则难以解释她如何会犯牢狱。"——这是本书自认"**职业取象不能靠旺衰**"的正面论据。
3. 断"旺财去印 → 刑警队长"：用局中阳火制阴金、旺财去印，是"以阳制阴＝正义战邪恶"的具体落点（承第一步第 4 条）。【段解】"局中以巳中阳火制阴金，旺财去印，是某公安分局刑智队长。"（"刑智"系"刑警"之讹，照原文录）（block_16）
4. 断"当兵"：日干合流年正财之年应入伍（此条已收于「夏仲奇取象直断」，本册不重写）。（block_20／23）
5. ★ **只存行业方向、判据层原文未见**的几条，一律**不得编判据**：
   - **服装布匹／刺绣**——【原文】"你干的是服装布匹一类的工作""是的，我是做刺绣的"（block_16）。**原文未见给出此断的判据**，段解未补，「取象直断」亦无。**只存行业方向，判据层原文未见，不得编判据。**
   - **地下工作／煤矿下井**——【原文】"28岁转业，是在地下里的工作"（block_16／20／23／24）。**判据层原文未见**（同篇只给"29岁甲寅年结婚……寅冲申忌神故而结婚"等邢解，未解"地下工作"怎么得出）。**不得编判据。**
   - **掏兜（小偷）／酒店夜总会／服装小买卖**——均只见断语或叙事，**判据层原文未见**，只作行业方向录存，不得编判据。（block_09／13／25）
6. 职业（医生、公安等）与行业方向的其余取法，另见「夏仲奇取象直断」「夏仲奇断财禄事业」，本册不重复。

### 第三步 查父母宫再婚与继亲

⚠ 本组是**整组缺口**——「夏仲奇断六亲」只覆盖"父母早丧（弃养、穿倒母宫／父星）"，**不覆盖再婚、继亲、过继**。**夏仲奇原文层多只给断语、未给判据**；唯一成系统的判据在书末附录（属外来口径，见 5、6 条与附录节）。

1. 断"过继"：直接断在某岁（如"出生二岁该过继给别人"）。**注意"老大也可能过继"**——原叙述者本人就点出反常识处（"一般过继人的都是老小，老大怎么会过继？"），**不得拘于"过继的必是老小"**。【原文】"你是兄弟三个，排行老大，出生二岁该过继给别人。"（block_21）★ **判据层原文未见**（同篇只给"兄弟三个，排行老大"，邢／段未对"过继"单独作解）。**不得编判据。**
2. 断"随娘改嫁／一母二父／养父待己好"：按"岁数＋事件"给（如"四岁随娘改嫁"），并附"养父很疼你"。【原文】"你四岁随娘改嫁，你有一个母亲两个父亲。""你的养父很疼你，把你当作他的掌上明珠。"（block_22）★ 该造"随娘改嫁"的判据**夏仲奇本人在本篇未给**、段解未补；**系统推演在附录另一造（见附录节第 1 条），属附录口径**。
3. 断"进门就当后娘"：落点是**未结婚而子孙宫先动** → 婚后即有非亲生子女。先看第一步大运地支定第一个孩子属相，再看该运时"还没结婚、子孙宫却提前动了"。【原文】"你一进门就当上后娘，你是五男二女的命。""她的第一个大运走的是卯……走这个运的时候她还没结婚，可子孙宫却提前动了。"（block_22）（"子孙宫提前动主未婚先得子"的取星法另见「夏仲奇断六亲」，本册只补它接到"后娘"的这一环。）
4. 断"与生父缘薄 → 随娘改嫁 → 有继父"：断语链按此三步给。【原文】"从你的八字看，你命中与生父缘薄，你应是随娘改嫁的命，还有个继父。"（block_08）★ 判据层同篇未展开。
5. 上面 1–4 条**夏派原文侧多未给判据**。要成系统判据，只能走附录节第 1 条（父星入墓 → 母星逢合 → 先冲后合 → 后见之字为后父），**用前须认它是附录口径**。

### 第四步 查应期到月

1. 桃花遇人可给到**流年＋流月，并给两个候选月**（子月或丑月二择其一）。【原文】"你看着吧，到丙子(96)年的子(十一月)月或丑月(腊月)定能遇上。"（block_02）
2. 关系散期给到**季节／月**，并用月气说理由（"火临月、水到绝地"）。【原文】"依我看，到丁丑(1997)的夏，火临月，水到了绝地，两人关系就完了。"（block_02）
3. 牢狱入期给到**月**，出期给"几个月后"。【原文】"在明年(1993年)的四月。"（block_03）⚠ 出狱的"几个月"是**断语记录，不是本派能算出的月数**（「夏仲奇断官非灾祸」明言不得据以承诺刑期），只可照录、不可承诺。
4. 凶灾给到**阴历月**，并且★**交节时刻必须说清**——出事在"九月二十"，但按节令已进十月节，记录者因未交代交节而误了避灾窗口。【原文】"要看是1998年阴历十月最凶。"【叙事】"这年十月十九立冬，正是立冬的第二天，在节令上实际已经进了十月节。都怪我没将交节时间说清楚。"（block_11）（交节口径已由「夏仲奇断法边界」收录，此处只作月级应期实例。）
5. 多段桃花／偏房可**逐段给到月、季节、年**（六七月、八月中秋、某年底、次年春）。【原文】"2001年六七月分手一个，当年的八月中秋左右，你还能遇到一个桃花，这一个到2002年底散。""2003年春，你还要遇到一个。"（block_23）
6. 断某人之死可给到**流年＋流月**。【邢解】"死于辛未年甲午月。"（block_18）⚠ 此条属【邢解】层的月级记录，引用须标层，**不得**当夏派可复算规则（见"什么时候不该用它"第 1 条）。

### 第五步 查第三者转正应期

1. **先判"是第三者／角色会转变"**（此层另见「夏仲奇断婚姻」§五.2：合夫宫＝第三者阶段、冲夫宫＝角色转变），本册补它**没写的两件事**：要等几年、哪年离婚／结婚／生子。
2. **转正应期＝给到具体年**（不是"迟早会转正"）。【原文】"恐怕你要等很长的时间……得六年，待到九五年，你们俩才能成。"（block_15）
3. **转正三步时间线**：男方某年离婚 → 次年结婚 → 再次年生子（并附"生子带财"）。【原文】"你这个老板有一个女孩……但他也要到乙亥年(1995)才能离婚……他应是九五年离婚，九六年你们结婚，九七年你生下个男孩。""你生的这个孩子会给你带来财运。"（block_15）
4. **判据（角色转变的机制）**：官杀本一人，因**合（卯戌合）与冲（卯酉冲）**两种作用不同而角色转变——**合＝第三者阶段、冲＝转正**。【段解】"偏房转正，八字中一定有象。原局子水杀星为夫；然又有卯申合，申中官也是夫，因申子之合，官杀星原为一人……壬戌运，是卯戌合，辛酉运是卯酉冲，对夫宫的作用不同，角色也因此而转变。"（block_15）
5. **对照（同型字，一为转正、一为散）**：偏房缘也可给"最晚到某年自动散"。【原文】"我看最晚到1995年，到时他们自动就散了。"（block_12）（此条已收于「夏仲奇断婚姻」§五.9。）

### 第六步 查反断他人（从己方八字断对方）

1. 从女命断丈夫／儿子的死因——核心是**十二生肖类化**：以六亲星所坐之地支类化为同类动物。【邢解】"其女对象八字中正官是丑，驴牛同类皆是畜也，无需细分。"（block_18）⚠ 此条是**记录在案的断错**（把"驴踢死"断成"牛抵死"），**粒度只到"畜类"，不得承诺具体物种／死法**；此条已被「断官非灾祸」「断六亲」「断婚姻」收录，本册只作引用。
2. 从女命断其**桃花对象的特征与结局**（年龄大、是骗子、昙花一现、某夏散）——直接从己方八字断"对方会怎样"。⚠ 本案另配了男方本人的八字，属**两盘合参**，不是纯单盘反断，引用时须说明。【原文】"她会遇上个年龄大的。""这个男的，可能是个骗子。"（block_02）
3. 从母命断诸子的残疾／病症——先断子女数与总评（"三儿二女""不是残疾就是有病"），再**借诸子各自的八字逐子细断**（拐子←年月之禄被冲；瘫痪←禄逢墓绝）。即母命给"有灾"，子命给"是哪一种"。【段解】"二儿子命：壬子，丙午，丁丑，甲辰，子水冲坏月上之禄，年月为腿脚，故是个拐子。"（block_06）（"父命看子"另见「夏仲奇断六亲」。）
4. 从男命断**妻子**的行为（何时有外遇、持续几年）——夫妻双方各自的桃花都从"被问者本人的八字"上读。【原文】"你两口子不会离婚，到二00一（辛巳）年你对象也有外遇，从你五十一岁那年，你妻子遇上的一个男朋友，时间十年。"（block_21）
5. 从女命断**"情人"的具体身份**（＝其继子／晚辈、很近），并同一盘再断亲生女儿之病与寿限。【原文】"我算你这个情人是你的晚辈。""这个情人，不是别人，就是你的儿子！"（block_22）

### 第七步 查穿／刑的动态力量对比（得生会不会反克）

1. 判"受克方经不经得起克"，**先看它有没有得生**。以"辰本虚土、经不起卯穿"为起点，再看旁支（巳火）是不是**不断生它**。【段解】"辰本虚土，是经不起卯穿的，但因为巳火不断地生它，它越来越强，到一定时候，辰就不再〔受〕卯的欺负，变成不可调和的力量对抗，反去穿卯木。"（block_07）
2. 认清这一环：**"生"不是化解，而是蓄势**——"卯生巳"这一环**不减**卯辰穿之力，**反而加强**该穿。【段解】"卯儿巳火不谨不能减卯辰穿之力，且能加强这种空。"（"不谨"应作"不仅"，照原文录）（block_07）
3. 记住本派立场：**"八字隔不作用"是歪理**——本派主张"八字中字字相关、引而应彼"，故不能因隔位就不论。【段解】"有一种命理歪理讲什么八字隔不作用，实际根本不合易之理，易讲万物都有相关性……八字中字字相关，怎么可能隔不作用呢？"（block_07）
4. 同型变体：两力原本**"形不成明显对抗"时不发凶**；一旦弱势一方在运中**得到生扶、又"有生无制"**，力量对比成对抗，即出凶。【段解】"原局中金旺火弱，两者形不成明显的对抗，故而一般情况是无牢狱之忧的。但到丁运，甲乙俱生丁，丁有生无制，便要出凶。"（block_03）
5. 反例（同一"刑冲"，因木之死活而结局相反）：**死木不怕斩根**，金冲为"劈木"、更利生火，故**不能**据"寅巳申三刑"断寿短。【段解】"见木要看死活，此造之甲木局中无明水生，又被冲刑，当以死木看。死木就如同木料，是不怕斩根的，金冲为劈木，更利生火。"（block_05）（此条已收于「夏仲奇取象直断」§八.2，本册只引用。）
6. 与"穿倒"分清：**"穿倒"＝一次性的破坏**（母宫／父星被穿倒 → 早丧）；**"穿而反强"＝力量对比翻转**。两型并列，**勿混**。【段解】"原局酉戌穿倒母宫，故应在戌运之戌年。"（block_02）（"穿倒母宫／父星"已收于「夏仲奇断六亲」。）

### 第八步 查"不入公门"

1. 正面与反面**必须成对看**：同一日生，**有丙寅时柱（阳火＋阳木）制去局中丑土（阴）** → 入公门（公安刑警）；**无此柱、反是更阴湿的亥水** → 不入公门。
2. 反面逐条对号。【段解】"此造没有能制去丑土的丙寅时柱，而是丑时 反而是更加阴湿的亥水，这就大坏其格了。乙木杀克身，不入公门；印坏，无学历；全局一无所用，此人也是一无是处；行入壬子运，克绝丙火，犯有神经质，与亲朋作对，恶名满贯。"（block_16）
   - 拆开记：无"阳制阴"的时柱（缺丙寅这类柱）反是阴湿亥水 → 大坏其格；**乙木杀克身 → 不入公门**；**印坏 → 无学历**；全局一无所用 → 一无是处；行壬子运克绝丙火 → 神经质、与亲朋作对、恶名满贯。
3. 正面对照：**有丙寅时柱制去局中丑土** → 入公门（"专门对付犯罪的公安刑警"）。【段解】"此造是以丙火与寅木，制局中丑土，故她是专们对付犯罪的公安刑警。"（block_16）
4. 与第一步第 4 条、第二步第 3 条互为对照（同一日生男命 vs 女公安）——**正反两条须成对用**，缺反面则判据不成对（「夏仲奇断财禄事业」§四只收了正面）。

### 第九步 查结论级断法

1. **定婚≠结婚，两档分开给**："定婚"与"结婚"是两个不同的年份，不可只给一个"某年结婚"。链条：定婚年 → 结婚年 → 婚变年 → 再婚年。【原文】"你的婚姻动的早，十六、七岁（丙午、丁未）该定婚……你应该在二十岁（庚戌）结婚。"（block_21）
2. 直断"某六亲现在已经不在人世"（结论级，而非"有灾"）：**定星 → 判其受克无生 → 取"运合克＋流年到字"之年**，即可直断已亡。【段解】"申金当她生的女儿看，戌土不生金反燥金，到已巳运巳火合克申，申难存，壬申年申到为应期。"（block_24）此层另见「夏仲奇断六亲」§三／§五。
3. 父命／本人命皆可断"子已亡"（煤气中毒一例），判据同「夏仲奇断六亲」§五"父命看子"（父命有克子配置＋子命复核）；本册只补"直断已不在人世"这一层结论口径。【原文】"可惜啊，你这个孩子，现在已经不在人世了。"（block_11）

## 判断标准

**做对了会看到**

- 同一组干支，你能指认它在哪一处分岔：是丙还是丁（心性方向）、有印还是无印（公门还是黑道）、得生还是没得生（反不反克）、活木还是死木（刑冲是凶是利）——并把这处分岔落到具体结论上。
- 断出的每一项，都能落到"哪几个字、哪个运、哪个流年（必要时哪个月）"，且与现场事实对得上（如"四岁随娘改嫁""2001 年妻子有外遇、十年"）。
- 引用附录那八条时，你**明确标了【附录】**并说明口径不同；引用【邢解】的月级记录时，也**标了层**。

**做错了会看到**

- 把"判据层原文未见"的条目（刺绣、地下工作、过继、掏兜／酒店夜总会／服装小买卖）**编出判据**——那是凭想象补的，不是书里的。
- 用【邢解】的旺衰／忌神口径（如"寅冲申忌神故而结婚"）当本派法则去复算——层已经串了，结论会与夏派相反。
- 把附录的"父星入墓 → 母星逢合 → 先冲后合"当夏仲奇原法直接宣讲，不标口径、不说不同源。

## 什么时候不该用它

1. **【邢解】当主口径会错。** 邢铭芬解释应期时夹用"旺衰／忌神"口径（如"29岁甲寅年结婚，甲申日元流年寅冲申忌神故而结婚"），而【段解】在同案自设质问"**用旺衰理论是讲不通的**"、总纲亦明言夏不用用神神煞。凡把【邢解】这部分当本派法则复算者，**会得出与夏派相反的结论且无法解释**；它只能作为邢铭芬一层的表述保留。第四步第 6 条（辛未年甲午月）同理，是【邢解】层的月级记录。
2. **附录八条是外来口径，不得当夏派原法用、不得与正文混写。** 该文照用用神／神煞／三奇／阳刃，"万不可拘泥"式表述与夏派直断相反；「夏仲奇断法边界」§七已明标该文未并入主口径。
3. **"判据层原文未见"的条目不得编判据。** 稿中明确标了——刺绣（block_16）、地下工作／煤矿下井（block_16／20／23／24）、过继（block_21）、掏兜／酒店夜总会／服装小买卖（block_09／13／25）：**只存行业方向或事件方向，判据层原文未见，一个字都不许补编。**
4. **"结论型心性评断"与"观人经验"不得当判据。** "生性风流""不是什么好人""命生得贱"（block_08／25／22）先有结论、后补旁证，无可复算判据链；"直性子、认死理""性情豪爽"（block_09／05）是现场观人／叙事，不是八字推出的。
5. **带性别歧视色彩、已被隔离的口径不得作为可迁移判据输出。** 如"火弱有水，这种人淫"（block_02），「夏仲奇断法边界」§四已明确点名隔离；本册只作缺口录存。
6. **死法／物种的粒度只到"畜类"**（牛驴同类不细分，曾被当事人当场指出断错——"驴踢死"误为"牛抵死"，block_18）；具体物种、器物、死法一律不承诺。
7. **"断某六亲已亡"这类结论级断法，一旦失手后果不可逆，且本书无法证明准确率**；此类结论必须按第九步第 2、3 条的取法给出，且不得在时辰未校正、无背景信息时下（见骨架「盲点与边界」）。
8. **退出条件（承骨架「盲点与边界」）**：① **时辰未校正不用**——报时辰不准是常态，须先用兄弟姊妹数、婚期、六亲经历倒推校正（L2），时辰无从校正时整套取法失效；② **只有八字、没有任何背景信息不用**——本书大量结论依赖求测者现场反馈修正（补记自述"在求测者的反馈中，不断修正调整"），"铁口直断"的独立性与"冷读＋反馈"难以区分；③ **数字型结论（子女数、妻数、兄弟数）受 1980–90 年代社会条件限制**（作者自述"由于计划生育的推行……推命中的孩子数没有了实际的意义"），今天照搬会直接出错；④ **交节时刻必须说清**（block_11 因未交代交节而误了避灾窗口），月级应期尤其如此；⑤ 同盘异命的判别本书未回答（"你须自辩而通"），遇此类追问不给死结论。
9. **凡按主流子平法（取用神、论旺衰、看神煞）或年柱纳音提问的，本册口径不同、不可互证。** 要子平法用「渊海子平」「子平真诠评注」，要纳音用「五行精纪注释」。
