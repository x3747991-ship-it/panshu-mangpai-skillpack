# ps-duan-shizhan · 段建业盲派断事实战

> 语料：段建业盲派讲义断事五章（第一章 应期 / 第五章 婚姻专辑 / 第七章 六亲 / 第九章 疾病专辑 / 第十章 车祸专辑），有效字数 23,555。

## 一、入口判定

### 1.1 何时使用（五域识别）

| 用户问的事 | 归属领域 | 主判据 |
|---|---|---|
| 婚姻好不好 / 会不会离婚 / 几次婚姻 / 何时结婚 / 为什么独身 | **婚姻** | 配偶宫 + 配偶星（男财女官）+ 宫被坏程度 |
| 得什么病 / 哪个器官 / 何时发病 | **疾病** | 干支体象 + 穿刑破 + 阴阳平衡 |
| 出车祸 / 何时出车祸 / 伤哪里 | **车祸** | 车象 + 速度象 + 引动 |
| 哪一年发生 / 何时应验 | **应期** | 大限→大运→流年 三层 + 出现/引动 |
| 父母情况 / 谁早逝 / 父母离异 / 过继给谁 | **六亲** | 父星（财官）母星（禄食伤）+ 年月宫 |

### 1.2 何时不使用

- 用户要**子平月令取格、格局成败、身强身弱喜忌** → 不属于本体系（详见 §五 失效场景）。
- 用户要**排盘、五行十神基础概念讲解** → 本包不含（语料未覆盖）。
- 用户要做**合参（多流派圆桌）** → 那是 `mingli-yuanzhuo` 的职责；本包只出段派一家之言。
- 用户要做**八字人格测试/MBTI** → 不属本包。

### 1.3 语料边界（必须向用户声明）

1. 本包是**断事专题**，不含干支基础、排盘法、旺衰理论。
2. 全部置信度按三级人工判定（高/中/低），**本语料无应验率数据**，不得虚构数字。
3. 属传统命理文本推演，**不构成医疗、安全、法律、投资决策依据**；不对在世具体个人下死亡/重疾断言。

## 二、断法步骤（通用五步，五域共用）

```
第 1 步 定星：这件事归哪个字管？
        婚姻→配偶星（男财/女官杀）｜父母→父=财官、母=禄食伤
        子女→男官杀、女食伤｜疾病→看干支体象（哪字代表哪个器官）
        车祸→看车象（辰丑酉申子、驿马）

第 2 步 看宫：该星落在哪个宫位？是否得位？
        年=祖上/早年/1–17｜月=父母兄弟/18–34｜日=自己配偶/35–54｜时=子女晚年/55后
        原则：宫为位、星为辅；宫被坏 > 星被坏

第 3 步 辨关系：宫与星之间、星与星之间发生什么？
        生 克 刑 冲 穿(害) 破 墓 三合 六合/五合/暗合
        穿/破/刑 = 致病致灾主路径；冲 = 动/开库；合 = 关联（未必吉）

第 4 步 判做功与凶结构：命局层次、有无先天大凶
        做功大 = 命贵；反局 = 大凶；凶神夹日/包局/死墓绝并现 = 夭命结构

第 5 步 落应期：大限 → 大运 → 流年
        大限定年龄段 → 大运定十年吉凶 → 流年只定"哪一年"（不断吉凶）
        应期两形态：①出现（原局之字现身）②引动（冲合/合局/墓气到位）
```

**输出要求**：每条断语必须带「出处（章）+ 模型路径 + 置信度」，格式见 §六。

## 五、失效场景与禁用（完整 41 条见 references/术语与误区.md）

### 5.1 体系层失效（口径边界）

| 场景 | 说明 |
|---|---|
| 用户以子平格局/旺衰提问 | 本体系**不谈月令取格、不看身强身弱喜克泄耗**。须显式声明口径，不得混用 |
| 要求量化应验率 | 语料无此数据，**禁止虚构**"应验率 XX%" |
| 涉及基础概念 | 排盘、五行定义、十神定义不在包内，不臆造 |
| 多流派合参 | 应交给 `mingli-yuanzhuo`（命理圆桌）做议题级合参，本包只出段派一家 |

### 5.2 使用层失效（易误判，11 条要点）

1. **同字多义**：酉＝肺/耳/车/金库；戌＝心/胃/神经/车/火库；子＝血/肾/轮子/夫星。取象必须绑定「宫位＋与谁发生关系＋当前议题」。
2. **见穿即断灾**：穿分性质——房事穿（丑午→心）、速度穿（酉戌）、水湿穿（寅巳→肝）、反局穿（卯辰）。
3. **见合即断吉**：合有合到（得）、合走（失）、合绊（困）、合墓之分。
4. **见破损即断伤**：子卯破/卯午破**须带禄身**才有手术刀伤。
5. **用流年断吉凶**：违反铁律（应-3）。
6. **禄虚透与墓虚透同判**：结论相反（应-7）。
7. **忽略条件限定**：丑午穿断心疾须"午被伤"；辛酉被火克"主骨不主肺"除非金水相连。
8. **对在世个人断死亡/重疾**：禁止；疾病/车祸章原文含大量死亡应期，仅作历史案例与研究方法。
9. **现代语境套用**：部分断语带时代背景（"下放五七干校""做小姐"），需转译。
10. **原文缺陷引用**：4 处四柱错行、3 处缺字、2 处段落重复（含 1 处语义相反）须按 references/术语与误区.md 的 D 系列处置。
11. **超越语料外推**：语料未覆盖的领域（如财运细节、六亲之外的十神事象）不强行出结论。

### 5.3 特例优先（3 条）

- 土财逢刑冲＝一次婚姻（覆盖通用多婚规则）
- 一星两宫若日时伏吟＝不表二婚
- 丑午穿若午旺有生＝不断心脏病
