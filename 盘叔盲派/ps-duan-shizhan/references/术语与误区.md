# 术语与误区 · 段建业盲派断事词典

> 任务A3 / 池A·段建业派 / 本书专属术语与断事口径词典
> 说明：仅收本语料（五章）中实际使用、且承载断法判断的术语；不收通用常识（五行、十神定义等，语料未讲）。
> 每条：术语 → 释义 → 出处 → 关联规则

## 一、系统骨架类（盲派底层概念）

| 术语 | 释义 | 出处 | 关联规则 |
|---|---|---|---|
| **做功** | 主位与用神之间有效的制/化/合关系；做功大则命贵、做功被坏则命差。「功的层次大」是最高等级评语 | 婚姻章、应期章 | R-B1-16、R-B1-11 |
| **主位 / 宾位** | 日柱与时柱为主位（体），年柱与月柱为宾位；主位制宾位＝我得，宾位制主位＝我失 | 贯穿五章（骨架 L4） | R-B3-13、R-B5-05 |
| **体 / 用** | 行天干运以天干为体、地支为用；行地支运反之。亦用于「主位之体不可坏」 | 应期章 | R-B1-03 |
| **反局** | 大运或流年使原局有效的做功关系反转，为大凶 | 应期章、疾病章 | R-B1-11、R-B4-17 |
| **宫位** | 年＝祖上/早年/1–17 岁；月＝父母兄弟/18–34；日＝自己配偶/35–54；时＝子女晚年/55 后 | 应期章、六亲章 | R-B1-01、R-B3-03 |
| **宫为位、星为辅** | 断父母/婚姻先看宫位是否被坏，再看星与宫的关系 | 六亲章、婚姻章 | R-B3-03、R-B2-01 |

## 二、字与字的关系类

| 术语 | 释义 | 出处 | 关联规则 |
|---|---|---|---|
| **穿倒** | 穿的力量强到把对方的象彻底破坏（如丑午穿使午火之象倒掉、夫星被穿倒） | 婚姻章、疾病章 | R-B2-21、R-B4-10 |
| **合走** | 合的力量把某字从原位置带走（配偶被合走） | 婚姻章 | R-B2-11 |
| **合到** | 合使某字与主位建立关系（合到夫妻宫＝进我家） | 婚姻章 | R-B2-03 |
| **合绊** | 合住使某字不能发挥作用（如甲木被己合绊＝财被夺） | 应期章、六亲章 | R-B1-11、R-B3-10 |
| **入墓 / 开库** | 入墓＝收藏闭气；冲刑墓库＝开库取用，是暴发与暴败共用的开关 | 婚姻章、应期章 | R-B1-16、R-B2-15 |
| **伏吟** | 同一柱或多柱完全相同（祖上/父母星伏吟主重婚、改嫁） | 六亲章、婚姻章 | R-B3-09、R-B2-19 |
| **暗合** | 干支之间不显于外的相合（寅丑暗合、午亥暗合等），常主暗中关系 | 婚姻章 | R-B2-03/22/28 |
| **相拱** | 两支之间拱出第三支之力（拱合、两辰拱财局、申辰相拱） | 婚姻章、车祸章 | R-B2-03、R-B5-07 |
| **会局** | 三支会成强局（巳酉丑三合、申子辰三合、亥卯会枭神局） | 婚姻章、疾病章 | R-B2-17、R-B4-20 |

## 二、易误用点（提取过程中识别的机械套用风险）

| 编号 | 风险 | 说明与正确做法 |
|---|---|---|
| Y-01 | **同一字多义，机械套用必错** | 酉＝肺/耳/车/金库；戌＝心脏/胃/神经/车/火库；子＝血/肾/轮子/夫星/食神。取象必须绑定「宫位 + 与谁发生关系 + 当前议题」，否则错误（骨架 §六-4） |
| Y-02 | **见穿即断灾** | 穿的性质要分：房事穿（丑午穿→心）、速度穿（酉戌穿）、水湿穿（寅巳穿→肝）、反局穿（卯辰穿）。同一穿法在不同字上断出完全不同的病/灾 |
| Y-03 | **见合即断吉** | 合有"合到""合走""合绊""合墓"之别：合吉为得、合走为失、合绊为困（M1-22 寅入未墓＋丑未冲，好局被破坏） |
| Y-04 | **把婚姻章"宫为主星为辅"误用到所有领域** | 宫星主次是**婚姻/六亲**的判法；疾病章、车祸章以**象法**为主，应期章以**引动**为主，不可一概而论 |
| Y-05 | **用流年断吉凶** | 原文硬性规定（R-B1-04）：流年只管应期、不管吉凶。常见误用是"某年凶神到位所以凶"——须先由原局＋大运定吉凶 |
| Y-06 | **忽略"出现"与"引动"的区分** | 出现＝原局之字在大运流年现身；引动＝冲合触发。二者应期机制不同（R-B1-05/06） |
| Y-07 | **把禄神虚透与墓神虚透同判** | 禄神虚透主**弱化**；墓神/余气虚透主**到位**（R-B1-09）。同是"虚透"结论相反 |
| Y-08 | **超越语料边界去补基础概念** | 本语料无排盘法、无五行定义、无十神定义（骨架 §六-1），不应在技能包中虚构 |
| Y-09 | **忽略现代语境** | 部分断语带时代语境（"做小姐""下放五七干校""补农用车"），直接套用今日场景易失真（骨架 §六-6） |
| Y-10 | **对在世具体个人断言死亡/重疾** | 疾病章、车祸章含大量死亡应期断语。技能包须明示边界：不作医疗/安全/法律决策依据，不对在世个人下死亡断言（骨架 §六-7） |
| Y-11 | **臆造应验率** | 本语料无量化验证数据，不得虚构"应验率 85%"之类数字（骨架 §六-3） |
