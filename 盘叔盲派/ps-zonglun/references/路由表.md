## 三、禁止路由组合（防串味）

| 组合 | 禁止理由 |
| --- | --- |
| ps-duan-zhongji ↔ ps-zhenbao 的三刑分组互用 | 同词异实（裁决 5） |
| ps-tiwei-* ↔ ps-zhenbao 的旺衰互用 | 段派弃衰旺、C1 只论身弱身旺（裁决 6） |

| ps-duan-yichi 含旺衰分支条目 → 未做旺衰判定前 | 条件不可满足，不可执行（仲裁 #21） |
| ps-duan-guibao 病神/病药 → 对外主断 | 限包内，对外降级（仲裁 #15） |
| ps-zhenjue-duanju 病药取用 → 对外主断 | 段氏早期口径，对外降级（仲裁 #3） |

## 四、路由执行顺序（每次必走）

1. 第 0 层：补四柱 →（必要时）校时 → 走 ps-minglizhenbao 五张前置卡 → 套通用前置。
2. 第 1 层：ps-tiwei-zuogong＋ps-tiwei-geju 定层次；ps-duan-zhongji 定正局/反局方向。
3. 第 2 层：按上表「主题 → 主断包」路由；主断包出结论，互证/佐证包补细节。
4. 第 3 层：口诀互证（E5 两说并出）＋神煞佐证（查法归 shensha、断义归段派）＋命例佐证（U-####）。
5. 第 4 层：ps-duan-xiangfa 象法定实物（职业/器官/场所/事件）。
6. 第 5 层：查 `仲裁摘要.md`；命中两说并列项 → 输出「主断＋另说＋存疑声明」。
