# 盘叔盲派·总控（ps-zonglun）

> 唯一入口。四派（段派/夏派/苏派/高派）**28 个子技能**统一由本总控调度：**先定层次，再按领域路由，多派互证，统一报告**。冲突裁决依据 `_融合工作区/跨包冲突仲裁表.md`（融合版 v2 升级中，未覆盖项按仲裁总原则兜底）。

## 什么时候用它

用户报出**四柱八字＋性别**（或可定四柱的出生信息），且问以下任何一类：

- 「这命怎么样/整体看命/贵贱祸福」→ 全流程
- 「事业/财运/官运/职业方向」
- 「婚姻/感情/会不会离婚/几次婚姻」
- 「健康/疾病/灾祸/牢狱/寿元/死亡信息」
- 「父母/兄弟/子女/六亲」（含父母早逝/多婚/养子）
- 「学历/性格」
- 「哪一年会怎样/应期」
- 「这字/这口诀什么意思」→ 走口诀与术语层

**不让位/不触发**：排盘教学（让位专项）、紫微/手相/六爻（拒绝）、子平扶抑取用（让位 panshu-ziping 系列）、蒸馏命理书（让位蒸馏技能）、只问单一术语含义（拒绝）。

**进入前置**：四柱不全 → 先补全四柱；时辰存疑 → 第 0 层走 ps-xiazhongqi-tiekou 校时；无性别 → 仅断与性别无关维度。

## 调度流程（七层）

### 第 0 层 · 定盘与前置

1. 排四柱；时辰不准 → `ps-xiazhongqi-tiekou`（兄弟数倒推校时），校不出 → 声明只能断原局不能断流年。
2. 走 `ps-minglizhenbao` 五张前置卡：宾主卡 → 岁运卡 → 冲合刑害优先级 → 忌神处理卡 → 虚实卡。
3. 套用通用前置（写入本技能）：不论旺衰用神；凶象须多作用重复方可定重，孤证作倾向；带空亡一律减等判假；神煞只作佐证。

### 第 1 层 · 定层次（主断，必做）

- 主链：`ps-tiwei-zuogong`（宾主→体用→做功→功量）＋ `ps-tiwei-geju`（格局名/阴阳包局/层数锚）→ 定富贵层级。
- 进阶：`ps-duan-zhongji`（E1 已就位）正局/反局判吉凶朝向——正局按做功论层次，反局（日支做功对抗、冲合反局）另立朝向，与 ps-tiwei-zuogong 结论互校后并表。
- 兜底查表：`ps-tiwei-jichu`（藏干/纳音/交运/类象/十神场所）。
- 补差：`ps-minglizhenbao-gangban`（E4）调候/从格/病神三态仅作段派口内校正，不引入扶抑取用。

### 第 3 层 · 互证与佐证

- 口诀速断互证：`ps-zhenjue-duanju` / `ps-jinkoujue` / `ps-gdc-jinkoujue` / `ps-duan-yichi`
- 神煞佐证：`ps-shensha`（一律佐证，不作独立断命）
- 命例支撑：`ps-anli-ku`（段派 263 例）/ `ps-zhenbao`（230 例）/ `ps-duan-guibao`（239 例）/ `ps-xiazhongqi-tiekou`（断例）
- 教材佐证：`ps-duan-hanshou` 条文精确引用（块号可查）

### 第 4 层 · 象法定实物

`ps-duan-xiangfa`：将功神/关键字干支取象→翻译为具体事物（职业/器官/场所/事件）。`ps-duan-guibao`（干支意向/十神多层意向）与 `ps-duan-mianshou`（象法七原则：共象/合象/化象/墓象/制象/带象/借象）可并做取象深挖。过河拆桥（主位财重生宾位官杀被制住）断发财升官属此层特型。此层决定断语的「实感」。

### 第 5 层 · 边界与仲裁

1. 冲突裁决：查 `跨包冲突仲裁表.md`。已定裁决 12 项（#1 墓开吉墓闭凶 / #2 空库遇冲两说并列 / #3 B1 早期降级 / #4 天乙贵人甲戊庚牛羊 / #5 流年只管应期 / #8 应期三链互证 / #10 神煞佐证 / #11 空亡减等 / #12 库墓按派别口径 等）。**E1/E2 已就位，仲裁表第四节 A-D 项进入回填流程**：A 正局反局已并入第 1 层进阶主断（见第 1 层）；B 面授口传（2010）为段派最新口径，冲突时标注「面授（2010）＞真诀导读期」；C 女命夫星/男命子女星以段派为主断、夏派作另说；D 流年吉凶维持 A2「只管应期」口径，E1 应期四法为细化补充。
2. 不确定 → `ps-xiazhongqi-bianjie` / 各包「什么时候不该用它」。
3. 高风险断语（死期/牢狱/重病）→ 概率化措辞＋免责边界；OCR 形近字（巳/己、戌/戍、午/牛、未/末、酉/西、卯/印）先按仲裁表第六节校正再引用。

## 什么时候不该用它

- 用户要排盘教学、紫微/手相/六爻/奇门等其他术数。
- 用户用子平法问话（「取什么用神」「身强身弱」）→ 让位子平技能（panshu-ziping 系列），本体系按不用神口径不回应扶抑。
- 用户要蒸馏命理书/做读书笔记 → 让位蒸馏技能。
- 用户未给四柱且拒绝补全 → 无法起手。
- 用户只问单一术语含义（「什么是空亡」）→ 概念查询，非断命。
