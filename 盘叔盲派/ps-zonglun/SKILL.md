## 一、什么时候用它（入口判定）

> **★ 交互流程层另有专包：`ps-zonglun-guide`（使用指引）。**
> 涉及「怎么向用户拿四柱、怎么拿背景、怎么出初校书、怎么用实证校准、怎么交付、怎么引导细推后运」——
> **一律先加载 `ps-zonglun-guide` 定流程，本包只负责断法本身。**
> 本包「怎么断」；`ps-zonglun-guide`「怎么问、什么时候断、断完怎么校」。

用户报出**四柱八字＋性别**（或可定四柱的出生信息），且问以下任何一类：

| 问法 | 走法 |
| --- | --- |
| 「这命怎么样／整体看命／贵贱祸福」 | 全流程七层 |
| 「事业／财运／官运／职业方向」 | 第 1 层 → 第 2 层（财命／官命／职业） |
| 「婚姻／感情／会不会离婚／几次婚姻」 | 第 1 层 → 第 2 层（婚姻） |
| 「健康／疾病／灾祸／牢狱／寿元／死亡信息」 | 第 1 层 → 第 2 层（疾病／灾祸／寿元） |
| 「父母／兄弟／子女／六亲」 | 第 1 层 → 第 2 层（六亲） |
| 「学历／性格」 | 第 1 层 → 第 2 层（学历／性格） |
| 「哪一年会怎样／应期」 | 第 1 层 → 第 2 层（应期） |
| 「这字／这口诀什么意思」 | 第 2 层（口诀与术语）＋第 4 层（象法） |

**进入前置**：四柱不全 → 先补全四柱；**时辰存疑 → 第 0 层走 ps-xiazhongqi-tiekou 校时**（仲裁 #13）；
无性别 → 仅断与性别无关维度。

> **★ 四柱的取得方式（硬规矩，见 `ps-zonglun-guide` 第 1 步）**：
> **优先向用户索取「四柱八字」，不要先要「公历生日」。**
> 生日还要过**节气换月**与**真太阳时**两道关，多一道环节就多一处出错点；
> 四柱是「一次性、可验证、用户手上有现成答案（万年历/排盘 App）」的既成事实，**直接要四柱可规避排盘出错**。
> 拿到四柱后仍须自检五项：**形近字校正 → 干支合法性 → 时辰边界（真太阳时）→ 起运数 → 旬空（年柱、日柱两查）**。

## 三、断法步骤（七层调度）

### 第 0 层 · 定盘与前置

1. 排四柱；**时辰不准 → `ps-xiazhongqi-tiekou`（兄弟数倒推校时）**，校不出 → 声明只能断原局不能断流年（仲裁 #13）。
2. 走 `ps-minglizhenbao` 五张前置卡：宾主卡 → 岁运卡 → 冲合刑害优先级 → 忌神处理卡 → 虚实卡。
3. 套用**通用前置**（见第四节），含「不混用清单」。

### 第 1 层 · 定层次（主断，必做）

- 主链：`ps-tiwei-zuogong`（宾主→体用→做功→功量）＋ `ps-tiwei-geju`（格局名/阴阳包局/层数锚）→ 定富贵层级。
- **正局/反局（方向闸门）**：`ps-duan-zhongji`（E1）正局/反局先定吉凶朝向，再以做功层数定功量刻度；
  二者维度不同、串联使用（仲裁表第四节 A）。**反局则凶，不再以层数论吉**（「反局优先于层数」为**融合推定**，原书无一处同时直述二者优先级，Pass 2 已标注）。
- 兜底查表：`ps-tiwei-jichu`（藏干/纳音/交运/类象/十神场所）。
- 包内校正：`ps-minglizhenbao-gangban`（E4）调候/从格/病神三态仅作段派包内校正；**从格判法限 E4／ps-zhenjue-duanju 包内，对外降级**（仲裁 #14）。
- **不认从格、不取扶抑用神、不看旺衰**（段派主流口径；苏派另说见仲裁 #21）。

### 第 5 层 · 边界与仲裁

1. **冲突裁决**：查 `references/仲裁摘要.md`。已定裁决 **21 项**（#1–#12 原定 ＋ #13–#21 新增），

2. **E1/E2 核定结论（v2 定稿 ＋ Pass 2 原文复核）**：A 正局反局并入第 1 层（「反局优先于层数」为**融合推定**，原书无直述）；
   B「面授（2010）＞真诀导读期」经原文复核**降为推定口径**（原书无直据：E2 学历章与 E1 逐字同源，「真诀／导读／病药」两书全文 0 命中）；

   D 流年维持「只管应期」（补 E1 直接等价句「大运讲吉凶，流年看应期」）。
3. **不确定** → `ps-xiazhongqi-bianjie` / 各包「什么时候不该用它」。
4. **高风险断语**（死期/牢狱/重病）→ 概率化措辞＋免责边界（不作医疗/法律/投资依据）。
