# 苏国圣派 · 盲派金口诀断法

> 流派来源：**苏国圣派（盲派 / 玄门苏记）** · 编者高德臣，丁亥年成书
> 本技能是《苏国圣-盲派金口诀》的断法内核，只保留「某八字配置 → 某人生结论」的可操作系统。
> 凡出现"身旺/身弱"，一律按本书**盲派旺衰**（印生食泄两党个数比较，见 R043）判定，不用月令得令得地。

---

## 一、入口判定

**应该触发本技能**：用户给出（或口述）一个四柱八字，并想要断具体人生领域——性格脾气、贫富贵贱/有没有钱、事业工作性质、学历高低、父母兄弟子女、婚姻早晚与配偶、伤病灾寿、某一年（流年）吉凶、大运走势。

**判断前先做两件核对**：

1. **时辰是否可信**。本派全部流年断法（串宫压运）建立在"四柱定格年为春、月夏日秋时为冬"的固定映射上，且需三垣（胎元/命宫/身宫）。**时辰存疑、夜子时、夏令时未校正**时，先请用户核对再排（R242）。
2. **是否齐备七柱**。本派断法必用 **三垣＋四柱＝七柱**。只给四柱也能断，但串宫压运与三垣相关断语要显式说明缺三垣。

**不该触发本技能**（命中任一条即转交或拒答）：只是想排盘 / 只问"什么是伤官"这类基础概念；问紫微斗数、六爻、梅花、奇门、手面相、实地风水；要求按子平格局（正官格、从格、化格）成破取用；要把命理书蒸馏成技能包（那是蒸馏工具的事，不是本技能）。

---

## 二、断法步骤

本派总纲是「论命四步」（R083），遇到任何问题都按这个顺序走：

1. **一看十神立**：定日主，排出四柱十神（财官印食比劫），先分清"财官印"三样有没有、有没有气。 [L2十神]
2. **二看四柱与三垣的刑冲穿绝**：把胎元、命宫、身宫并进四柱一起看七柱之间的冲、穿、刑、绝、合。这是本派断事的主流手法。 [L4三垣 / L3五行>刑冲穿绝合]
3. **三看大运**：大运对命局是助还是冲穿绝，看财官印是否"流入日主"。 [L7大运]
4. **四看流年应期**：用串宫压运起太岁配十二神，定具体哪一年应事。 [L4串宫压运]

**按问题类型再分流**（四步定完基础盘后）：

| 用户问的 | 主查节点 |
| --- | --- |
| 这人什么性格 | 日干直断（R076）→ 五行意象（R077）→ 日柱纳音成象（R078）→ 十神心性（R079） |
| 有没有钱 / 贵不贵 | 财官印是否流入日主（R058–R060）→ 富/贵/贫/贱/凶/无官六套相诀（R061–R067） |
| 干什么工作 / 学历 | 官杀左柱取象（R068）→ 工作四级（R069）→ 行业十神/五行（R071、R072）；学历看正印（R073） |
| 父母 / 兄弟 / 子女 | 取六亲星（R099、R106、R111）→ 星宫合看 → 夭折/优劣标志 → 应期岁运 |
| 婚姻 | 婚宫（月令）+ 配偶宫（日支）先看冲合（R119）→ 早晚（R123、R124）→ 配偶远近大小属相 → 克夫克妻（R135、R136）→ 应期（R134、R140） |
| 伤病灾寿 | 伤灾标志（R141）/ 官灾（R142）/ 查病五法（R144）/ 寿限（R146）→ 险运（R147） |
| 某年好不好 | 串宫压运三种起太岁（R003）→ 十二神配十二柱 → 四柱配四季定应月（R001、R006、R007） |
| 用神 / 忌神 | 盲派旺衰定日主强弱（R043）→ 最旺为病（R044）→ 岁运去病为喜 |

**断哪一年，就用串宫压运**：流年断一年、大运断十年、日干通支断一生，三种起太岁法别混（R003）。

## 五、判断标准

- **断对了会看到**：给出的结论能落到用户已知的具体年份/事件上（如"某年迁坟家族财旺"“某年结婚”“某年母亡”），且该年份能由串宫压运或岁运冲合独立推出来。
- **断错了会看到**：只堆断语却给不出应期年份；把"平常命"断成大富大贵；神煞一查便说（未查五行喜忌与刑冲）。

## 六、什么时候不该用它

1. **时辰不可信时，串宫压运全盘失效**。全法建立在"四柱配四季 + 三垣"上；夜子时、时辰存疑、夏令时未校正者，整套流年断法失准（书中专列夏令时表，反证此风险）。此时只作粗略参考，不给流年铁口。
2. **本书无格局法**。不讨论正官格/七杀格/从格/化格的成破。遇到必须以格局取用的八字（子平体系核心场景），本技能覆盖不到。
3. **旺衰标准与他派不兼容**。本书用"印生食泄两党个数"，与子平"月令得令得地得生得助"常对同一八字给出相反结论。用户若已按子平体系排定旺衰，先声明口径差异，不要混用。
4. **性别与婚姻形态预设过时**。夫妻星一律"男以财为妻、女以官为夫"；克夫克妻、铁扫帚、克夫再嫁等断语对同性婚姻、不婚、丁克等现代情形无对应断法。
5. **旁支术数不能替代专业判断**。姓名、阴宅、九星三章各自独立、与主断法无接口，且需额外排盘/现场信息；"从八字看阴宅"≠实地风水（作者明言两者是两个系统）。原局偏枯、病点过多时，**起名无效**（作者自承"不能自欺欺人"）。
6. **命宫/身宫的分年限界书中未定义**。"命宫管前半生、身宫管后半途"未给具体岁数分界；断前后半生只作方向性参考。
7. **反例密集处务必加条件**。如"神煞不可一查便说"（R152）、"将军箭有箭无弓不伤人"（R171）、"平常命才是多数"（R063）、"財被劫不一定伤妻去父"、"盖头截脚为平运"（R277）、"原局没有的字大运只起三成力"（R273）——凡命中这些情形，先补条件再下断语，否则必误。
8. **断语为口诀型断言，无失败统计**。全书断语多以对偶韵文给出、缺可重复验证的案例集（编者后记自承"缺少案例"），属"口诀型断言"而非"可检验规律"。面向用户时应说明这是流派断法、非确定事实。
