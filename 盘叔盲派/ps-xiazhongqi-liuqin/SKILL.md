# 夏仲奇断六亲

> **缺口补充册见「夏仲奇断事补法」**：父母宫的**再婚与继亲**取象（随娘改嫁／一母二父／继父／进门当后娘／过继）本册未收，见该册第三步。六亲的**疾病与死期**另见「夏仲奇断健康疾病」。

## 什么时候用它

用户报一个八字，问下面这类问题：

- "我父母怎么样？父母还在吗？哪一年走的？"
- "我几个兄弟姐妹？我排行第几？有没有早走的？"
- "我能生几个孩子？是男是女？头胎是什么？孩子有没有出息？"
- 反向用法：拿父亲的八字直断"某个儿子会死于非命"。

**通用前置见「夏仲奇看命总纲」**——本技能只写六亲专有的那一层，看命总则（L1 不取用神）、定盘与时辰校正（L2）、宫位体系（L3）、十神六亲星定位（L4）、干支作用关系六件套（L5）、应期机制（L7）都在总纲里，不在这里重写。

问配偶次数、婚期、克夫克妻、桃花第三者的，那半边见「夏仲奇断婚姻」。

## 核心判断

盲派断六亲不看旺衰，看的是**六亲星＋宫位**双轨——**星定是谁，宫定在哪**。星被穿／冲／刑／入墓即该六亲有灾，宫被穿倒即该宫位的人事破损（L3＋L4＋L5）。**先配星、后论刑冲**：星定错，后面所有刑冲结论全部作废。

**分歧点（C01）必须分层读，不得揉成一条：**

- 【总纲·弃衰旺】说：断六亲同样不取用神、不论衰旺，只看星宫与合冲刑穿墓空——"我跟夏老师这么多年，既没见他取过什么用神，也没有听他讲过什么神煞，但能断得如此之准……所以说，当前流行的命理学所讲的东西，基本上是无用的。"（三十一、求财当有道／块25）
- 【邢解】说：邢铭芬本人在解释六亲应期时夹用旺衰忌神口径，如"29岁甲寅年结婚，甲申日元流年寅冲申忌神故而结婚"；段解则自设质问"为什么此人行壬寅大运财官两旺，行癸卯大运不顺，**用旺衰理论是讲不通的**"。
- **采信**：以【总纲·弃衰旺】为主口径；【邢解】的旺衰表述只作"邢铭芬本人的解释习惯"，标注**非夏仲奇原法**。

## 怎么做

### 〇 前置：先定盘、再配星

1. **校时辰**（L2）。报时辰不准是常态，须先用兄弟姊妹数、婚期、六亲经历倒推校正；时辰无从校正时，后面全部结论不可靠。

2. **配星**（L4）。把该造主要六亲与八字里的具体字一一对应起来，配定之后才谈刑冲存亡：
   - 母＝印、父＝财、兄弟＝比劫；
   - **女命食神＝女儿、伤官＝儿子**；男命官星为子女；
   - 女命**年上伤官为男孩**。
   - 【原文】"你看她的食神是姑娘，巳中丙与寅中丙都是姑娘……她伤官为儿子，她儿子都很不错。"
   - 【段解】"首先应当将此造主要的六亲与八字中字一一对应起来。"
   - 【邢解】"婚后生男孩是因为年上戊土伤官为男孩。"

3. 配星依据：与宫位的合、坐、墓关系，以及星自身的生克处境。

### 一、父母

1. **母看印星**（月干为母宫、月令为母位）；**父看财星**。

2. **母星弃养主早丧母**——印星自身太弱不能生日主，古称"弃养"，即早辞世之意。
   - 【段解】"命中早丧母，必定在原局有显示。乙木母星在月干，母宫在月令。乙木母因自身太弱不能生丙，古人叫'弃养'，就是早辞世之意。"

3. **母宫被穿，凶应于穿宫之运年**——先看原局有无穿倒母宫之字，丧母应期落在"穿"该宫的运年，**不落在火最旺之年**。
   - 【段解】"这与母亲宫位相关，因母位在月令，原局酉戌穿倒母宫，故应在戌运之戌年，不应在巳年与午年。"

4. **财星被穿倒主早死父**。
   - 【段解】"看父则以酉金财看，原局中酉被戌穿倒，是早死父的信息。"

5. **父母应期同走 L7**：星入墓于支则逢墓（库到）之年为应期；克星藏支而透干为应期。
   - 【段解】"即酉金入墓于丑，而戌年正好刑开丑库，故戌年是不会死父的。到癸丑年正好库到，是谓之应期。"
   - 【段解】"她局中克父之能量是戌，戌中含丁，丁现于大运，又不受制于它神，表示克父的东西出现了，实际是应期的原理。八字有理五行与象五行，从象上讲，丁能克酉。"

### 二、兄弟姊妹

1. **兄弟看比劫，月令为兄弟宫。**

2. **月令伤官损兄弟**——伤官泄比肩。
   - 【段解】"月令伤官，有损兄弟，因月令为兄弟宫，临伤官必泄比肩。"
   - 旁证：【段解】"如：辛亥、壬辰、辛巳、壬辰造 月令伤官，比肩又坐伤官，兄早夭。"

3. **比肩被官杀克又被穿刑主死兄弟（含应期）。**
   - 【邢解】"己土是兄弟，大运甲，流年己，甲木官杀克己比肩，大运午与丑相穿，局中丑戌相刑，故而死弟。"

4. **定数与排行**：本书用兄弟姊妹数来校时辰（L2），实例有"一个哥哥，一个妹妹""兄弟三个，排行老大""午时生人，是兄弟自己（独生子）"。**但数目的推法本书未给**，只能事后解释——见"什么时候不该用它"。
   - 【原文】"按戌时推，你有一个哥哥，一个妹妹。"／【原文】"午时生人，是兄弟自己(独生子)。"

5. **注意应期记录的层间误差**：第九篇一例，原断为"19岁结婚、18岁那年死兄弟"，邢解却写成"十九岁死兄弟、十八岁结婚"，两件事的岁数颠倒。引用时**以原文断语为准**，邢解那段应期推导不作范例。

### 三、子女

**（1）定星**

- 女命伤官为子、食神为女；男命官星为子女。
  - 【原文】"丁火就是伤官，就是她儿子。"
  - 【原文】"你看她的食神是姑娘，巳中丙与寅中丙都是姑娘……她伤官为儿子，她儿子都很不错，有一个当大官的，也有一个存大钱的，但是姑娘不成器。"
- 女命年上伤官为男孩（见前置〇配星）。

**（2）克子**

- **食伤犯三刑克子女**（子多带残疾或不成器）。
  - 【原文】"你命中官星坏了，子星伤官、食神犯三刑，注定克大伤子"；"依我看，你的儿子都没有出息，就是残疾就是有病。"
  - 【邢解】"食伤为子女星，犯三刑，故克子女，子带残疾。"
- **伤官为子女＋丑未戌三刑主子女先天疾病且不孝无德。**
  - 【邢解】"孩子为伤官，八字中丑未戌三刑，所以她孩子有先天性疾病，而且不孝无德。"
- **三刑坏六亲星宫——刑落何宫即应何亲。**
  - 【原文】"她命中丁丑日主，丑未戌三刑坏了子女星"
  - 【段解】"凡遇带三刑者，在六亲上就可能出问题，如一例：坤：丁 丁 戊 庚 / 丑 未 戌 申 此造是父母宫的父母星犯三刑，还连带夫宫，结果父母都很早就离开了人世，夫也于丑运去世。"
- **伤官为子、受印克断子凶死。**
  - 【邢解】"乙木伤官为大儿子，原局中受时上辛金之克，故死于壬子大运辛未流年。"
  - 【段解】"乙木伤官为第一个儿子，先天弱而受辛金克，故死于辛运。"
- **食神遭刑主克闺女。**
  - 【原文】"你看她的食神是姑娘，巳中丙与寅中丙都是姑娘，寅巳相刑所以死闺女……她最晚到2004年克死一个姑娘。"
- **子女星受克断存亡。**
  - 【段解】"申金当她生的女儿看，戌土不生金反燥金，到巳巳运巳火合克申，申难存，壬申年申到为应期。"
- **刑断克子女，应期定到年。**
  - 【原文】"她女儿会在戊寅年（1998）生一场大病，是子宫上的病，活不过2004年。"

**（3）生育与保子**

- **子孙宫落空亡主不育／立不住孩子。**
  - 【邢解】"婚后不生孩子，是因子孙宫落空亡"
- **生子应期：冲动／合动子孙宫**（L7）。
  - 【邢解】"23岁以未年生孩子，冲动子孙宫之故。"
  - 【邢解】"25岁辛年生二胎，合动子孙宫故而生子。"
- **官星流年逢子孙宫主当年结婚怀孕**（两条同时成立）。
  - 【邢解】"为何十九岁结婚？因此年癸丑是官星流年，丑又是子孙宫，所以当年结婚，当年怀孕。"
- **断子女属相：以第一步大运地支定；子孙宫提前动主未婚先得子。**
  - 【原文】"她的第一个大运走的是卯，所以她第一个孩子可能是属兔的，走这个运的时候她还没结婚，可子孙宫却提前动了，所以第一个孩子就该是属兔的，而第二个孩子是属马的，正是她的情人。"
- **抱养子兼闰月年生育可保子**（盲师化解法，本书无原理说明，须标为未公开的秘传）。
  - 【原文】"你先要个孩子，这样再等到有闰月的年份你生的孩子就保住了。"
  - 【邢解】"为什么说她抱养个孩子，自己再到闰月年，就能立住孩子，这是盲师的秘诀，暂做保留"

### 四、断六亲总链（一句话骨架）

**定星 → 察克刑 → 落宫 → 定应期**（L4 → L5 → L3 → L7）。先定该六亲对应之星，看其是否先天受克、被刑，再结合所落宫位受冲刑穿的程度，最后取引发之运与流年定应期。

- 【段解】"此造以月支丑为第一个丈夫，先天受不刑，故运死；乙木伤官为第一个儿子，先天弱而受辛金克，故死于辛运。"
- 【原文】"你老公猛灾伤亡，从二十八，九岁起，你就开始守寡。"

### 五、父命看子

从父亲的八字里存在克子之配置，可直断某子（如长子）死于非命；再从其子本命复核，两处互证。

- 【叙事引述夏语】"只是有一句话没当着他本人的面说，夏老师告诉我，他命克子，大儿子会死于非命。"
- 前提提醒：夏老师本人也要索取子女本命来"验证一些东西"，故"以父母命推子女病残"须有子女本命佐证，不可单凭父母一盘定论。

### 六、一星两用（夫与子同到）

一星可兼两用：当某个字同时代表夫与子时，两事同来（此例再嫁即得继子）。**婚姻那半边见「夏仲奇断婚姻」**，这里只写子女这半边。

- 【段解】"当夫宫出现正副两宫时……与此同时，酉金同时代表儿子，儿子与夫同到，故得继子。"

## 判断标准

**做对了会看到：**

- 断出的六亲存亡之年能落到具体运年，且与"穿该宫／刑该星"的运年对得上——"故应在戌运之戌年""死于壬子大运辛未流年""壬申年申到为应期"。
- 断出的子女性别、属相可与现场核对（"六个女儿""第一个孩子属兔"）；子女数须有"坐支财被劫暗合＋又与子女宫穿（为子女破大钱）"这类旁证托底才敢报数。
- 三刑所应之亲可指认到具体宫位的人（"父母宫的父母星犯三刑……父母都很早就离开了人世，夫也于丑运去世"）。

**做错了会看到：**

- 拿旺衰、用神、神煞去反推六亲应期，必然自相矛盾；段解的原话就是判断标尺——"用旺衰理论是讲不通的"。
- 只挂一句"犯三刑"就下"某一子必是哪一种残疾"——本书里具体到某个儿子，用的是禄、冲、墓绝等分项取象，不是"三刑"一条包打（反例1）。
- 对同一个"子女宫被穿"之象，本书自己也分不清何时应"多女破财"、何时应"女儿生病"（夏老师答"有些细微的区别，你慢慢悟吧"）；出现这种"分派不下"时，说明已超出可复算范围。

## 什么时候不该用它

1. **子女数与性别这类数字型结论，建立在 1980–90 年代生育不受限的社会条件上，今天照搬会直接出错。** 作者自己在第八篇明说："在大陆由于计划生育的推行，那些许多命中有几个孩子的人，也只能生育一个，这使得推命中的孩子数没有了实际的意义，只要能推出头胎生什么，就算可以了。"夏仲奇本人也只在看出"坐支财星被劫财暗合、又与子女宫穿"（为女儿破费花大钱）这个旁证后，才敢断"六个女儿"——"如果不是凭这个看出他为女儿破费花大钱，现在计划生育，我断然不敢断他有六个女儿的"。

2. **时辰未校正时不可用。** 报时辰不准是常态，须先用兄弟姊妹数、六亲经历倒推校正（L2）；而"推兄弟姊妹数"的算法本书并未给出（属淘汰项，只能事后解释）。时辰无从校正时，本技能结论不可靠。

3. **无任何背景信息、只给八字时不可用。** 本书的断语是在现场对话中用反馈逐步收窄得出的（补记自述"在求测者的反馈中，不断修正调整"）；须先断过去之事以校时辰，再断未来。单凭一盘八字冷断，本书没有这样的能力证明。

4. **本书对"同八字为何六亲不同"未作答。** 记录者自承："这些都是命理的常识，但实际应用起来还是十分不易……（夏老师）在推断六亲方面尤其高超，至今我们无法窥其堂奥。"附录也承认："屡见命主已经有克无生，何以不死？……你须自辩而通。"六亲推断未形成可复制的完整方法。

5. **凡按主流子平法（取用神、论旺衰、看神煞）提问的，本技能口径不同、不可互证。** 要看子平法那套请用「渊海子平」「子平真诠评注」，要看年柱纳音那套请用「五行精纪注释」。C01 已明：本派以【总纲·弃衰旺】为主口径，邢解夹带的旺衰忌神说法只作个人解释习惯，两套口径不得混说。

6. **"抱养子兼闰月年生育可保子"是邢解明言的盲师秘诀**（"暂做保留"），本书无原理交代，不可当通用规则推给他人。

7. **十二生肖类化断死因的粒度只到"畜类"**（牛驴同类不细分，曾把"驴踢死"断成"牛抵死"），具体物种、器物、死法一律不列入可承诺范围。
