## 核心判断

**原象定层次，大运定吉凶，流年定应期；不取扶抑用神。**

- 先看原局的**干支配置 + 宾主位置 + 十神意向 + 虚实贼捕 + 八字之势**，判吉凶与层次；
  日主衰旺在本派没有实际意义，不参与定吉凶。
- **病神三态**定"有与没有"：病神旺现入主且有生 → 该事物不好；弱现入宾或被去 → 反得此神；不出现 → 无吉凶。
- **有势 + 有病**才成贵：得势的八字，病神是什么就可以得到什么。
- **大运只管吉凶，流年只管应期**；流年本身不主喜忌——用神流年受制反凶，忌神流年受克反吉。

3. 找**势**：会局、归禄、成党成势者为"得势"。有势 → 再看病神在哪。

### 调候正解 `[L4五]`（第14章）
- 调候取之于季节寒暖燥湿，**以节令为主**；冬夏生用寒暖，未戌月见火、丑辰月见水用燥湿，春秋生不用。
- 适用天干：甲乙最敏感 > 庚辛 > 戊己不敏感，丙丁壬癸有木才看。
- **调候不怕刑冲破害及合化变质**（无形之季节时间）；但**忌调候**存在（如忌木而木生寒地，行热地为忌）→ 可致灾。

### 有与没有 `[L4七]`（第18章）
- 病神**旺现、入主、有生** → 该神代表的事物就不好（财旺现入主有生 → 穷，乞丐造）。
- 病神**弱现、入宾、被去** → 反得此神、为此神劳神而大有收获。
- 病神 / 忌神在八字**不出现** → 此神在局中无吉凶；再看大运能否出现被去，能去则吉，不去则凶。
- 喜神 / 用神被坏 → 该事物凶；压根不出现 → 无吉凶；大运出现被去 → 运中见凶。

### 从格判别 `[L4九]`（第22章）
四条从格判据（身弱）：
1. 日主**无根无生扶**者从；
2. 日主**有根无生扶但根被坏**者从；
3. 日主**无根但有印、印也无根**者从；
4. 日主**无根、印有根但印根被坏**者从。

- "根被坏" = 被强有力的邻支冲掉，或通过合会局转化失去原性。
- **根远根近**：年支最远、月支略近、日支最近、时支次近；根远者难依托，往往从。
- 两种错误认识：**从弱格（越弱越好）**、**从格容易还原**——皆为歪理。
- 从格先辨"从了什么"再定喜忌；从财格最怕官运（泄财）。

### 财的四路 `[L4九]`（第23–26章）
- **以禄当财**：禄配印意向为权（官禄格）；禄不配印或印失力、单纯用禄时，禄当财看。禄作用神最怕见劫财（分禄）。
- **伤官当财**：为我苦心追求者（谋为之财、野心投机风险之财），故财大；**宜身旺，忌财星明现**（泄伤官损格）。
- **比劫去财**：财作忌神（无原神入宾 / 虚透无生 / 官杀多时财为忌 / 财弱被比劫制）→ 主富。
- **特殊财命**：**十年统看 vs 上下五年分看**——流年与大运不发生刑冲合并则分看，一旦发生则十年统看。

### 官的三路 `[L4九]`（第27–29章）
- **伤官去官格**：官为忌，伤官去官 → 反得当官最大（和珅）。伤官制官不见财 → 清廉之官；有伤官不见官 → 有才无官；财明透不合 → 贪而挥霍；配置不好 → 官不大。**此格不论日主衰旺。**
- **官杀制法**：弱的官杀要**旺制**；略偏旺要**平衡制**（或化敌为友，用印化杀）；旺的官杀要**弱制**（唬弄）。
- **官命七型**：官杀配印 / 配财 / 配伤官 / 配劫刃；印配财 / 配伤食 / 配比禄。**官杀及印无论作用神忌神都必须有根**（虚透只主名人或演员）。

### 看势（先天垂象）`[L4一 L4八]`（第20–21章）
- 伟人出色之人八字都有势；**有势 + 有病**才成贵（有势无病反贱）。
- 得势的八字，病神是什么就可以得到什么。
- 例：蒋介石 / 袁世凯（己土 / 丁火得势 + 金水之病）、梁启超（丙火得势 + 金水之病）、克林顿（伤官得势 + 官杀之病）、格林斯潘（火得势 + 金水之病）。
- 富命结构 = **旺用神去忌神**（李嘉诚午亥合去亥水；香港证监会主席 申财忌神实而有制）。

### 伏吟九义 `[L4十二]`（第42章）
伏吟**非吉非凶，只表意思**，参合喜忌断。九义：
**外出**（伏吟门户）/ **内调工作**（伏吟印星）/ **借出去钱**（伏吟财星）/ **结婚**（一个人变两个人）/

### 下岗与辞职 `[L4十四]`（第48章）
- 以**月令之官印**看工作；下岗 / 辞职者都是月令官印出了问题。
- 月令官印为**忌神** → 单位与工作不适合自己，离开为好；为**用神** → 好单位，不辞为好。
- 用神被坏 → **被迫离职下岗**；忌神被坏 → **主动离职**；忌神旺克日主 → 与领导不合或工作出差错而辞职。
- 以**年月官印看原工作，时上官印看后找的工作**；时上无官印 → 多自谋 / 自由职业；时上见用神 → 离职后转好。

### 寿元与死亡 `[L4十三]`（第54章）
- **寿元星四取**：①食神（无食神则伤官亦可）②印绶 ③日主（及禄神）④财星。一个命中一般只现一种。
- 寿元星三特征：命中小而精者 / 靠近日主或秉令者 / 一般通根得气（特殊能拯救命局之天干虽无根亦可）。
- **五行偏废**：金木怕过弱，弱极无补则死；火怕过旺，旺极无制则死；**水怕衰极，土怕旺极**。
- **空亡忌煞**：寿元星怕空亡，怕"墓病死绝"四煞宫；神煞只起辅助作用。
- **应期四则**：**衰极怕墓 / 衰绝怕生 / 遭克怕出现 / 死墓绝怕逢生**。
- 关键立场：**用神只管行运好坏、不主生死**；只有年岁高者看寿才参看用神。

### 大运流年三层关系 `[L4五 L7]`（第12章）
- 八字看贵贱、大运看吉凶、流年看应期（车子 · 路 · 人的比喻）。
- **作用次序**：流年先与大运作用，再与八字作用。
- 刑冲合害次序：先论冲合与害，再论三刑 / 三合 / 半合；冲合害同时出现时**合力与冲害力都减弱**。
- 大运冲八字**不主动**，旺冲衰为破；冲墓一般主破，只有大运与八字有合有冲（冲力减弱）时才论冲开墓库。

## 判断标准

**断对了会看到**：能说清"为什么偏偏死在这个运 / 为什么这人没财反富 / 为什么他辞职后转好"，
而不是笼统说"运气不好"；同一八字里象、势、期三条链互相印证；调候与喜忌不混为一谈。

**断错了会看到**：拿日主衰旺去找用神；把"有"当吉、"没有"当凶；把调候被刑冲破害当成坏；
把"伤官见官"一律论凶；把女命婚姻实质问题套旧时代道德断语。

## 什么时候不该用它

**流派上不适用**：
- 本包属盲派（段建业 · 郝金阳），与**子平格局派、旺衰派、调候派、神煞派**结论大面积相反。
  **不能与这些流派的技能混用**：同一八字两边算会互相否定。
  尤其"伤官见官"（本派看是否去官，子平一律论凶）与"取用神"（本派根本不取扶抑用神）。
- 本包**不用传统吉凶神煞**：用户问天乙贵人、文昌、桃花星、驿马吉凶，本包答不了（禄 / 羊刃 / 空亡只当象与寿元用）。
- 本包是**全量成书版，可独立主断**；但凡属内地版元规则层主干（宾主 / 贼神 / 意向 / 虚实 / 应期）的问题，优先走 `ps-minglizhenbao` 以统一口径。

**方法上会失效的场景**：
- **一象多义时没有判据**。同一个"戌"可以是色情场所、庙、烘干炉、库；同类"乙庚合"有的应吉有的不应，
  作者自己也未给判据（第33章）。取象高度依赖经验与师承。
- **并非所有八字都能找到用神 / 忌神**。作者承认有些八字"怎么看都不好"，此时只能给"差命"而不能给层次刻度。
- **无系统疾病断法**。全书仅在个别命例中顺带提病，不能用于"问身体哪里有病"。
- **断官级用旧制官阶**（处级 / 厅级 / 一品），直接套现代职级会有偏差。
- **财富量级不可计量**。"富过千万 / 资产千万"是命例自带的已知数，不是从八字推出的模型。
- **女命断语已降级**。第33、40章旧语境（贞操 / 职业贵贱）按任务卡一律不采用，只答婚姻实质。
- 八字没给全、时辰不明、或只有生肖年份的，不要用。

**最需要警惕的**：本书命例多为"已知结果倒推象"。本包能自证的是"这套符号系统内部一致"，
不能自证"它预测得准"。给结论时应如实告诉用户，不要把断语说成定论。
