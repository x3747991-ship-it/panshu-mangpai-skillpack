## CF-01 · 地支六冲：五种冲法 vs 七种冲法 ★作者自陈（详略之别）

| 来源 | 表述 |
| --- | --- |
| 第1章 | 「地支六冲又有**五种**冲法，即：冲破、冲去、冲动、冲开、冲旺」 |
| 第7章 | 「详细讲有**七种**冲法及用途：冲凶、冲旺、冲动、冲开、冲出、冲去、冲破」 |

- **差异**：第7章比第1章多出「冲凶」「冲出」两类。
- **裁决**：非矛盾，是**总纲概述 vs 专章详述**。第7章为定稿口径，第1章为其简版。
- **采用**：以**七种冲法**为准；「命中逢冲只有两种情况主凶——冲凶、冲破，其余多主应事不主凶」这句是第7章的实操结论，优先采用。
- 见 `规则.md` 第1章「五种冲法」条、第7章「七种冲法」条。

## CF-02 · 关财门"必离" vs 实例"至今未离" ★真冲突（已给边界）

| 来源 | 表述 |
| --- | --- |
| 第37章 口诀 | 「女命财门一关，婚姻是必离的」 |
| 第37章 例1 | 「此造行癸卯运闹离婚……但此造夫宫为喜，故一直在闹，却至今尚未离」 |

- **冲突点**：口诀称"必离"，同章实例却"尚未离"。
- **裁决**：作者在第37章给出的边界是**关财门有轻重**——「原局伤官旺、财被穿倒为重（必离）；原局伤官轻、财受冲受伤为轻（可断闹离婚）」。
  例1 属"轻"（卯酉冲去财，非穿倒），且夫宫为喜，故只闹不离。
- **采用**：**必须同时满足"重"（伤官旺 + 财被穿倒）才可断必离**；只受冲受伤者只断闹离婚。夫宫喜忌为第二道校正。
- **注意**：任务卡要求女命旧语境降级，本条按中性语言表述。

## CF-03 · 旺忌神弱制（第51章）vs 弱官杀旺制（第28章）★非冲突（同一原则两面）

| 来源 | 表述 |
| --- | --- |
| 第28章 | 「弱的官杀要**旺制**；官杀略偏旺要**平衡制**；旺的官杀要**弱制**」 |
| 第28章 例 | 和珅造午火弱未彻底制死 → 只是平衡制 → 庚寅运翻船 |
| 第51章 | 「**旺的忌神弱制则吉，旺制反凶**」；阎锡山用一点食神制众杀 → 统治群僚 |

- **裁决**：二者同向（弱敌彻底制服 / 强敌弱制唬弄），第51章是第28章第三型（旺官弱制）的强调版。
- **采用**：合并表述为"**制忌神先量敌之强弱：敌弱则旺制，敌略强则平衡制（或化），敌强则弱制**"。
- 边界：旺用神同样怕弱制（旺火用神被弱制 → 小气、成不了大器）。

## CF-04 · 调候"不怕被坏" vs "忌调候致灾" ★非冲突（两个命题）

| 来源 | 表述 |
| --- | --- |
| 第14章 | 「调候用神不怕刑冲破害及合化变质……惟有调候是一种季节、一种时间，是无形的，所以不怕被破坏」 |
| 第14章 | 「调候未必都表示吉，还有**忌调候**的情况，比如八字忌木而木生寒地，即不喜行热地，则暖调候为忌」 |

- **裁决**：两个命题不同层次——(a)"调候**本身**不能被坏"；(b)"该局**该不该要**暖/寒调候"。
- **采用**：先判该局要暖还是忌暖（判"该不该用"），再判调候不会被刑冲破害打掉（判"会不会失效"）。
  庚戌/己丑/辛丑/辛卯 车祸致残造即"忌暖调候"型。

## CF-05 · 虚实喜忌"用神实/忌神虚" vs 两种例外 ★作者自陈边界

- 主则：宜用神实而忌神虚；忌神虚而受生主凶，忌神实而被制主吉。
- 例外（第11章）：①用神作**调候**者，虚用神也吉（火若实则泄禄反为忌）；②作**泄神**的用神宜虚（泄为秀气、为清气）。
- **采用**：主则 + 两条例外必须同时携带，否则会把"虚用神吉"的命断错。

## CF-06 · 伏吟"非吉非凶" vs 古书"反吟伏吟泣哭淋淋" ★作者否定古书

- 第42章：「伏吟本身并非吉也并非凶，它只表意思，参合喜忌来断」。
- **采用**：以作者口径为准。伏吟是**中性事件标记**（外出/内调/借钱/结婚/痛苦/高兴/复归/失去），吉凶由所伏之神的喜忌决定。

## CF-07 · 从格"越弱越好" / "容易还原" ★作者否定（列为误区）

- 第22章明确把"从弱格（越弱越好）"与"从格容易还原"判为**两种错误认识**。
- **采用**：看从格先辨"从了什么"，再定喜忌；多数从格不还原。从财格忌官运（泄财），日主受制或没了都不吉。

## CF-08 · 患妻患夫"重患必离" vs 从财格"虽重现婚后很好" ★作者自陈边界

| 来源 | 表述 |
| --- | --- |
| 第38章 总则 | 「配偶宫、星偏正杂出，为**重患，必离**」 |
| 第38章 例6 | 从财格「虽重现，也只是婚前有些波折，婚后很好」 |

- **裁决**：作者给的边界是「**一般为忌神者多数会离，为用神者多数不会离**」。
- **采用**：患 ≠ 必离；叠加"该星是喜是忌"与"重见伏吟（轻患）"两道校正。

## CF-09 · "伤官见官"吉凶 —— 跨流派冲突（非本派内部）

- 本派：伤官见官（去官得官）→ **吉**，行官运也能升官（第27章、和珅造）。
- 子平格局派：伤官见官 → **凶**（官非、女命婚灾）。
- **采用**：本技能包只承本派口径。**不得与子平技能混用**，否则同一八字结论相反。
