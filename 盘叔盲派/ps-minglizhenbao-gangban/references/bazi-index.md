## L2 · 十神体系 [不可变底层]

生成规则：同我比劫／我生食伤／我克财／克我官杀／生我印。

本书对十神的态度：**活论十神**（意向理论）🔥🔥🔥
- 财星：妻、父、亦作"欲望/才能"看
- 官星：夫、职、名誉、规范，亦作父看（官星为父）
- 食神/伤官：子女（男女通用，非只以七杀为子）、才学、名气
- 印星：母、学识、单位/工作、权柄、庇护
- 比劫：兄弟朋友、分夺、竞争

十神属性卡（各含 六亲 / 心性 / 事业义 / 财运义 / 婚姻义 / 喜忌 / 位置义 / 组合义）
→ 完整卡片见 `bazi-model.md`，本书使用时**必须标注命中的是哪个维度**。

## L3 · 五行体系 [不可变底层]

五行生克：木→火→土→金→水→木（生）；木→土→水→火→金→木（克）

旺衰判断维度（本书**整体不用** ✗ —— 作者明确反对以日主衰旺定吉凶，仅在"虚实"与"势"中替代性使用）
```
得令 / 得地 / 得生 / 得助 / 综合身强身弱 —— 本派 ✗
替代维度：虚实（干透有根否）🔥🔥🔥 ／ 成势（会局透干成党）🔥🔥🔥
```

冲合刑害表 🔥🔥🔥（本书核心工具层）
```
天干五合：甲己土 乙庚金 丙辛水 丁壬木 戊癸火
  本书五种合法：合去 / 合伤 / 合留 / 合动 / 合变
天干四冲：甲庚 乙辛 丙壬 丁癸
地支六合：子丑土 寅亥木 卯戌火 辰酉金 巳申水 午未火土
  本书位阶：六合 > 三合局 > 三会局
地支三合：申子辰水 亥卯未木 寅午戌火 巳酉丑金（+半合）
地支三会：寅卯辰木 巳午未火 申酉戌金 亥子丑水
地支六冲：子午 丑未 寅申 卯酉 辰戌 巳亥
  本书五种冲法：冲破 / 冲去 / 冲动 / 冲开 / 冲旺
地支六害（穿）：子未 丑午 寅巳 卯辰 申亥 酉戌
地支相刑：子卯（无礼）寅巳申（恃势）丑戌未（无恩）辰午酉亥（自刑）
```

干支相互作用：盖头 / 截脚 / 通根 / 透干 🔥🔥

调候维度 🔥🔥🔥
```
冬生喜火暖 / 夏生喜水润 / 未戌月见火 → 燥湿调候 / 丑辰月见水 → 燥湿调候
本书修正：调候仅限冬夏与未戌丑辰月；只对部分天干适用；且调候不怕刑冲破害
```
