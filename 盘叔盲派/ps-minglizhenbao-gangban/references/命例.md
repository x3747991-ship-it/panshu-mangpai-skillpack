## 命例 · 某作者论「天干五合化与不化」的反例
- 八字：丁亥 / 壬寅 / 己未 / 丁卯 · 乾造
- 出处：命理珍宝（香港版）· 第1章
- 大运：书中仅提「行戊戌运」
- 涉及规则：天干五合（合而不化）；三合局不成与透干无关；忌神受合绊去忌得喜
- 推理链：
  1. 某作者称丁壬本合化木、无甲乙透干则「化火」，故亥卯未三合木局不成、日主转旺、取财为用，癸亥年进财。
  2. 作者批：丁壬无化火之理；亥卯未木局成否与透不透木无关。
  3. 作者断此造日主弱、身弱用劫印，财官为忌。
  4. 丁壬合、寅亥合皆忌神合绊；亥绊住三合木局不成，但卯未半合可成。
  5. 行戊戌运卯戌六合，解卯未半合，为吉；癸亥年忌神财星出现遭大运戊土合绊——去忌神得忌神喜，此为得财应期；寅亥再合，两忌神合绊论吉。
- 结论：身弱用劫印，癸亥年得财应期在「忌神受合绊被去」，非五合化气。
- 验证状态：有争议（作者明确反驳原断）
- 模型路径：L4 > 二、干支作用关系 > 天干五合（合绊/合去）；L5 > 忌神受制即得喜；L4 > 一、破衰旺取用法

## 命例 · 徐先生（郝金阳断合伙养车）
- 八字：戊戌 / 己未 / 乙巳 / 丁亥 · 乾造（1958 农历六月十一亥时，四岁起运）
- 出处：命理珍宝（香港版）· 第2章

- 涉及规则：活论六亲（患父）；原神看生死；患病之神到位应期；岁运相并；食神为子女非七杀；印为车、克印为司机；先流年与大运后与八字作用
- 推理链：
  1. 以月令偏财己土为父；己旺不等于好，看有无原神。
  2. 巳为己之原神，落日支被亥冲坏 → 父在命主中青年（日支）去世。
  3. 正偏财混杂（己、戊、戌、未）→ 本门「患父患母」诀，主继父母或父母有灾；所患之神不关联母星 → 只表死父。
  4. 行壬戌运患星戌到位、父之原神巳入墓 → 此运死父；流年壬戌岁运相并，患力倍增 → 应死父。
  5. 以丁火食神为子女（非七杀）；丁卯年丁火逢合、妻星戌逢合 → 妻怀胎；合丁之壬水太衰，戊辰年戊克壬 → 流产。
  6. 戊辰年再怀孕 = 辰戌冲开妻星之墓。
  7. 戊辰年破财：八字水木喜、土忌，流年大运旺土 → 破财。
  8. 官司：一辰冲两戌，戌含七杀主官司；七杀不明透克身 → 民事非刑事。流年先与大运作用（壬戌之戌为司机）→ 第一场为司机的官司；印星入岁墓 = 扣车。
- 结论：其父早丧、子女先女后男、戊辰年破财打两场民事官司且车被扣。
