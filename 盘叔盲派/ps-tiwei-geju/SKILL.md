# 段氏理象学格局实战

> 本册是「段氏理象学」主册的**实战判法补充册**，从《段氏理象学》（段建业 著）第六至八章及附录（OCR 块 06–22）补录。
> 读它的正确方式：**先按主册把宾主、体用、功、净度走完**，再回本册补格名、补阴阳包局、补取象细目、补层数实证锚，以及处理主册与原文相斥的那一条。
> 主册已讲的内容（四步主断法、六式做功、制局通辨、制法、功量加层、四门取象）**本册不重写**，只写主册没写全的补充与修正。

## 什么时候用它

用户拿着一个四柱，已经（或正准备）按主册走了一遍，接着问下面这类细判时用它：

- 「这命做功几层／能到多大官／能有多少资产」——要拿**实证锚**对档次（不是只问通用映射）。
- 「这局是阳包阴还是阴包阳／是假阳还是真阳／该走公门还是走偏门」。
- 「什么算内食神格／什么是伤官配印／官禄格怎么认／金水伤官喜见官是什么意思」。
- 「所制的那个字入了墓运，到底是大吉还是失色」——主册与原文在这里打架，本册专治。
- 「辛为什么是调料／午为什么是门户／戌为什么是火灾／甲为什么是头」——取象落到细目。
- 「火金为何主声音／食神入墓为何断寿／什么叫天地合为合绊／行运劫财为什么要忌投资」——附录命例里新出的判法。

## 核心判断

**主册管「这命在做什么功、功有多大」，本册管「这个功属于哪一个格、这个局是阴是阳、这个字落到哪一行哪一件物、这个层数对应到现实里的哪一档」。** 两条最容易出错：一是**阴阳包局的胜负只看天干那一层**——地支阳气不足不等于败，天干阳盖阴照样是胜；二是**「所制之神入墓」的吉凶取决于墓在运上是开是闭**——墓被原局旺字冲开则反成大功（原文·李世民），墓闭无冲才是事业失色（现有技能／李昌镐）。这两条不弄清，前一条会把卧底断成正牌公门，后一条会把一生最关键的一步运断反。

## 怎么做

按这个顺序查，前面不通不要跳到后面。

### ① 定格局（先看有没有主册没成的这几个格）

主册讲「基本不讲八正格」，但原书自造了几个「格」名目，主册未成系统，这里补全：

- **内食神成格**：日主**自生食伤**，且**食神里藏财星、又能转化为财**——「将自己的想法变成财富」→ 判词「内食神一般都是做企业的企业家」。落**主位食神**时主企业（如寅为内食神）；若此食神又**入官墓**（如寅墓于未），＝才华被官方所用＝**企业经理人**。
  命例：壬寅癸卯壬子壬寅（内食神成格，丙午运任大型国企董事长）；己未癸酉壬寅庚子（寅为内食神，企业经理人）。
- **伤官配印**：伤官**成势透干为凶神**（如两乙透干）＋**有印星制服伤官**（午印）＝伤官配印；**印主权力** → 判词「气势恢弘，能成一代明君」。附判：两伤官＝造反两次；官杀可代表儿子。
  ⚠ 主册已用「伤官诀」（土金／水木伤官成局＋配印→得重权）收了配印思路，本册补的是**格名与判词**。同盘换到子平「伤官配印格、用神是木」会翻案（作者自陈旧解解不了希特勒的成败），**不可混用**。
- **金水伤官喜见官**：金水成势的伤官局＋见官星，判分两支——① **喜见官**＝官被合理取用；② **伤官制官**（如子午冲）＝职务是「**制服别的官员**」，官星带财＝**制服贪官**（纪检委书记）。附判：金水伤官局主**学历高、工作不错**。
  ⚠ 主册「伤官诀」只收土金／水木两支，金水这支未收。
- **官禄格「以印当权，怕见食神」**：**杀星入墓、又无杀印组合**时，看权**不走官杀、改走印**＝**以印当权**；其忌神是**食神**（食神克印、泄印之权）。成立要三条叠加：① 月令见印（强印主权力）；② **杀库被冲开并被三合局制死**（制去杀与杀之原神＝**双层功**）；③ **禄星＋禄库把全命包围**（影响力可覆盖任何地方＝再加一层）。四条功叠加 → **四层功 → 主权力就是帝王**。
  命例：乙未丁亥乙丑己卯（慈禧）。⚠ 此格与传统「官杀为权」正相反，是本派自有格。

### ② 判阴阳包局

**总纲**：**木火为阳，金水为阴**（土随火燥则阳、随水湿则阴）。成局两式——一方在外把另一方包住：**阳包阴**（外阳内阴）／**阴包阳**（外阴内阳）。成局之后再判胜负，**胜负看天干那一层**：天干阳盖阴＝**阳胜阴**；天干阳气不能胜阴、反受阴制＝**阳不足／假阳**。

**断法总规则**：**阳胜阴 → 得正位（公门、正职）；阳不足／假阳 → 走偏门、暗行、凶终。**

| 分式 | 成立条件 | 结论与取象 |
|------|----------|-----------|
| 阳包阴·阳胜阴 | 阳包阴局，地支阳气虽欠足，**但天干阳盖阴** | 判「**阳胜阴局**」；寅作公门 → **在警局为官**（正牌公门） |
| **假阳** | 阳包阴局成立，**但阳不足以胜阴**（天干阳气不能胜阴、反有被阴所制之虞） | 「有点公门的意思，**但不全**」→ 不是正牌公门；先断「保安大队长」，再补「阳不足、又不像黑社会」→ 断「**卧底公安**」；结局阳终被阴制 → 入狱 |
| 阳能胜阴 | 阳包阴局（卯酉冲＝食神制杀，有执法意） | **有寅 → 入公门；无寅 → 不能入公门 → 私人保镖／保安公司主管**（同类多解皆可）；原局阳能胜阴 → **牢灾不长** |
| 阳包得很紧 | 阳强、包裹严实 | 主做事精确（「能把账管得一分不差」） |
| 阴包阳／体阴用阳 | 阴包局（群阴包住）＋**时上见伤官** | 「**群阴而用阳**」：**体阴**（所操之业＝黑道暗杀、黑暗面）→ **用阳**（行事之志＝正义、理想崇高、不为财利）。取象：丑＝阴中之阴、辛酉之库＝黑社会 |
| 阳制阴（取格） | 火土成一党集于坐支（如未巳戌集于巳火） | 「集权之意」，**取格为「阳制阴」**；被制的年上食神为功 |
| 阴制阳 | **阴多阳少，阴来制阳** | 「**摧毁文明之象**」；「阳中之阴／**表阳而实阴**」＝用表面光彩掩盖阴险本质；行运见阴之亥水合制阳长生 → 摧毁之应；行运「阴虚而阳实」则制阳之局被阳反制 |

⚠ 假阳与阳胜阴的分野**只在“天干那一层”**：同为阳包阴，天干阳盖阴＝胜（正官），天干阳不胜阴＝败（假阳／暗行）。不要一见阴多就断凶。

### ⑤ 看大运是否踩到「所制之神入墓」，再判这个墓是开是闭

**这一节是本册最重要的一节——主册与原文在这里结论相反，必须两说并列、按条件取用。**

**【原文】说**：贼神（被制方）入墓之运，**似凶实吉**。
> 块 14·李世民 戊午乙丑戊午壬戌：「观其行运，**当崛起于戊辰之辰运，丑入辰墓，贼神入墓似不吉，有反局之嫌，然戊辰运戊盖头，辰也在自己的控制之下，且有旺戌冲之甚烈，辰戌冲，强烈做功。毕其功于一运！**」大事记：「**戊辰运之辰运，丙戌年，弑兄弟建成、元吉。登基。(辰戌冲之应)**」

**【现有技能】说**：所制之神（被制方）入墓之运，**事业失色**。
> 主册 SKILL.md「L7 大运流年」表逐字条文：「所制之神入墓之运｜原局以某字被制为功，行运该字入墓｜**该运无法做功、事业失色**｜附录」

**两说方向确实相反**——同一事件（被制方入墓运），一个判吉、一个判凶。

**★ 判别原则（决定用哪一说）：先判这个墓在运上是「开」还是「闭」。**

| | 【原文·似凶实吉】（块 14 李世民） | 【现有技能·事业失色】 |
|---|---|---|
| 入墓者 | 丑（贼神／被制方）入辰墓 | 所制之神（被制方）入墓 |
| **墓运是否被冲开** | **原局有旺字（戌）与墓库（辰）相冲** → 「辰戌冲，强烈做功」，墓门被**冲开** | **墓闭、无冲** —— 被制之神困在墓中出不来，制方无从施制 |
| **墓运天干（盖头）** | **戊辰运，戊盖头**，且「辰也在自己的控制之下」 | （未设天干条件） |
| 结论 | **吉**：强烈做功、「毕其功于一运」，事业崛起 | **凶**：无法做功、事业失色 |

**一句话原则**：**墓开则转吉（原书·李世民），墓闭则失色（现有技能／李昌镐）。** 主册那条只写了「闭」这一支、漏了「开」这一支，所以与原文表面相斥；**补上「墓运被冲开」这个条件后，两说并不矛盾**。

- **用【原文·似凶实吉】的条件**：① **墓运有盖头干且该干受命主控制**；② **原局有旺字来冲该墓库**（辰戌冲、丑未冲等开库之冲）→ 判「似凶实吉、强烈做功、事业崛起」。
- **用【现有技能·事业失色】的条件**：**墓运闭库、无冲** → 被制之神困死墓中、制方无从施制 → 判「事业失色」。
- **正向佐证（闭支）**：块 16·李昌镐 己未辛未丙子戊子——「行入庚辰运的辰运，**这个运是子水入墓，戊土无法制水的运**，所以近两年开始莫明其妙的输棋」。这正是「墓闭而制方无法施制 ＝ 事业失色」的正面例证。
- **本派自洽依据**：主册「墓逢冲则开」条——「墓冲变库，库中之物可随便取用（喜冲）」。三处合看即可自洽。
- **建议的合并写法**（供回修主册时用）：「所制之神入墓之运：① 墓闭无冲 → 无法做功、事业失色；② 墓运被原局旺字冲开（或有受控盖头干）→ 墓开反成，似凶实吉、强烈做功、事业崛起。」

## 判断标准

**做对了会看到**：能叫出主册没写的格名（内食神格／伤官配印／官禄格以印当权／金水伤官喜见官）并说清成立条件；能判出这局是**阳包阴还是阴包阳**，并**落定在天干那一层**说清是胜还是假阳；层数能对上**实证锚**（两层≈厅级、行运好副省级；三层≈数十亿／省部级；四层千亿），且**注明用的是正文版还是附录版口径**；取象能落到细目（辛水调料／午为门户／戌为火灾·戊戌楼房／甲头戌刀），不停在五行类别；碰到「所制之神入墓」**先判墓的开闭、再定吉凶**；附录特殊断法能按「判法」用，而不是背命例。

**做错了会看到**：把主册的四步主断法又重讲一遍（本册只补不重写）；一见阳包阴就不分天干那一层，把**假阳断成正牌公门**（或反之把胜局断成暗行）；不问功量就把「两个老婆并联」「伤官配印」当必然；碰到「所制之神入墓」**直接判事业失色**、不知墓被冲开可反成大功（或反之，一律判崛起）；拿附录名人命例的**事后解释**当预测保证；给 4-24 编出一条原文没有的口诀；把本册取象细目当唯一门路（只走干支象一门）。

## 什么时候不该用它

1. **本册是实战补充册，不能单独断命。** 必须先做完主册四步（定宾主→分体用→找功→判结构净度），再回本册补格、补象、补层。跳过主册直接翻本册，会把补充条当主断法用。
2. **阴阳包局有适用条件，不许简化。** 只有**先确认成局**（一方在外把另一方包住）才判阴阳与胜负；阳包阴的胜负**必须看天干那一层**——**地支阳气不足不等于败**，天干阳盖阴照样是胜；「假阳」只在天干阳不胜阴时用。**不能简化为「见阴多就凶」。**
3. **「贼神入墓」两说必须按条件取用。** 先判这个墓在运上是**开**还是**闭**——原局有旺字冲开该墓库（或有受控盖头干）→ 用【原文】的似凶实吉；墓闭无冲 → 用【现有技能】的事业失色。
   **照哪一说会错在哪**：只照【现有技能】（事业失色）→ 会把李世民式的「墓开强烈做功、事业崛起」**误断成失色**，把一生最关键一步运判反；只照【原文】（似凶实吉）→ 会把李昌镐式的「墓闭、制方无从施制」**误断成崛起**，把败运看成好运。两说都不设条件地单用，一定有一半会错。
4. **附录命例多为「事后解释」，不作预测保证。** 名人命例是在已知结果之后去复盘（李世民、希特勒、乔布斯都是），且**名人的时辰多为推定**（乔布斯寅时、玻尔午时、王亚樵辰时、汉武帝戌时、辛普森戌时）——**不可当铁证**，只能作判法参考。
5. **主册的边界全部照旧适用**：连体连根之字不可制（做功整体让位于生死边界）；无功之命要转象解、不硬凑功；时辰不准则全盘不可用；婚姻、六亲、疾病、牢狱、应期的系统推断未展开，本册收的只是碎片，**不得宣称体系化断事能力**；数目/数量类断语（兄弟数、金额数）易失准，只能给区间。
6. **层数实证锚是经验标定，无统计支撑。** 只能作档位参照；且要注意正文版与附录版数字有出入（见③），**不要把两版混引**。
7. **取象只保证到五行类别，别强求精确商品名。** 同一组象在相近行业间天然多解。
8. **与子平各派会打架。** 同一八字上，本册与格局派／旺衰派／调候派判断路径可能相反（作者自陈旧解「伤官配印格、用神是木」解不了希特勒）——这是流派差异，不是错误，但**不要在同一盘里混着用**。
