## 凡例

1. **族别**：本书口诀分两大族——
   - **第一族·五言取用诀**：以五行（木火土金水）为纲，各分春/夏/四季/秋/冬五段，五字一句，共 **25 段 · 200 句**，是全书招牌。
   - **第二族·其余韵文口诀**：天干重字断、地支重字断、断运篇、十神专论、江湖铁口断命决（含盲师断命金口诀·宫星定位）、月柱×日柱十神组合断。
2. **用/忌列**取值：`喜X`（宜见/satisfying）、`忌X`（不宜见）、`喜A忌B`、`前提`（格局长势说明，不涉喜忌）、`重断`（应验形态）。
3. **断事维度**取值：六亲 / 婚姻 / 子女 / 财运 / 事业官贵 / 性格 / 健康灾病 / 寿夭凶死 / 官非牢狱 / 祖业 / 大运 / 格局。
4. **OCR 校字**：源文系 DOC 转换，存在形近字讹（巳/己/已、戌/戍、午/牛、未/末、酉/西、卯/印）。已结合上下文判正者径改；判不准者**照录原字并在其后加〔〕注明**，如 `未戍〔未戌〕`、`三亡〔疑「三癸」〕`。
5. **剔除项**：政治敏感内容、江湖卖艺话术、纯排盘工具（盲人快速查日法——块01–04 未出现，无需处理）。
6. **重复/异文**：「江湖铁口断命决」与「盲师断命金口诀·宫星定位」系同源传抄，正文只在 **第五章** 著录一次，金口诀之异文另立 **第六章** 对照；重复之组合断口诀（块04 与 块05／块12 重出）注明「另见…（重复）」。
