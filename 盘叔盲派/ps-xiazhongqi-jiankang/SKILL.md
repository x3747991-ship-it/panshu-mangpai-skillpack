# 夏仲奇断健康疾病

## 什么时候用它

用户报一个八字，问下面这类问题：

- "这八字身体哪里容易出毛病？会得什么病？"
- "他哪一年会生病？严不严重？病什么时候好？会不会反复？"
- "这命能有寿吗？能活多久？哪一年是关口？"
- "他是怎么死的？死于什么？是病死还是出凶？"

**通用前置见「夏仲奇看命总纲」**——本册只写两件事：一是"哪里有病"（致病之字→落何宫→配脏腑），二是"何时病、何时死、怎么死"（得病年、反复年、死期档、死因取象）。看命总则（L1 不取用神不衰旺）、定盘与时辰校正（L2）、宫位体系（L3）、十神六亲星定位（L4）、干支作用关系六件套（L5）、理五行与象五行取象法（L6）、应期机制（L7）、门类总纲与边界（L8）都在总纲里，本册不重写。

**健康层的"禄／火／羊刃"判据另见「夏仲奇断官非灾祸」**：禄主身体、子水冲月上之禄主腿残、禄逢墓绝主身不能动、火为伤官坏局主神经／精神病、羊刃被冲穿主血光——这些判法「夏仲奇断官非灾祸」§三已经写过，本册只把它们列进下面的对应表备查，不再复述。

## 核心判断

盲派断健康疾病，**不看日主旺衰**——日主强弱在本派既不表示能力强弱，也不表示身体好坏（L1）。它看的是三件事：

1. **有一个"致病之字"**——在克日干（如流年见水克丙）、在坏局（如伤官丁火坏局）、在坏禄（如子水冲坏月上之禄）；
2. **这个字落在哪一柱哪一宫**——年月为腿脚、时上为头脸（L3）；
3. **按"五行／器官→脏腑"落断**——但本派能配的明文只有四处：水→肾、火→神经（精神）／眼、血→血、子宫→子宫；肝／肺／脾本书未载，不许补。

断寿另立两条：一是**"关口＋顺延"两档死期法**——先给一个关口年（"51 岁不死，就是 60 岁死"），过不去即关口应死，过去了就顺延到下一档；二是**"凶支／泄而无生"**——原局某一凶支被运引到冲战即凶死；日元在原局本弱、行运流年皆泄而无生即死在此年。

应期不在"忌神到位"（那是邢解一层，非本派原法），而在"流年该字到／该字引动／泄而无生"把结论落到具体年份（L7）。**四层声音必须分层读**：【原文】＝夏仲奇本人断语（最高口径）、【邢解】＝邢铭芬（记录者）的解释、非原法、【段解】＝段建业、【附录】＝书末外来文章（口径与夏仲奇体系不完全一致）。

## 怎么做

### 一、断"哪里有病"：三步链（致病之字 → 落何宫 → 断何病）

1. **先定致病之字**——在盘上找出那个"出手"的字，三选一：
   - 克日干之字：【邢解】"壬申年得肾病是因其流年见水，克日干，故病。"（块02）注意这里虽用"克"，属**取象层面的生克，不是衰旺用忌**。
   - 坏局之字：【段解】"大儿子命：甲辰、丁丑、甲戌、丁卯，是伤官丁火坏了命局。"（块06）
   - 坏禄之字：【段解】"二儿子命：壬子，丙午，丁丑，甲辰，子水冲坏月上之禄。"（块06）

   同时按 L4 认这个字是何十神（伤官／官星／食神／禄／比肩）——十神定错，后面的病与应期一起作废。

2. **再看它落在哪一柱哪一宫**（L3）。宫位兼断身体部位：**年月＝腿脚，时上＝头脸**（【段解】"年月为腿脚，故是个拐子"／【邢解】"丁火在时上主头脸"）。

3. **按五行／器官配脏腑落断**（查下一节对应表）。链子走通才落病名——【段解】"是伤官丁火坏了命局，火主神经，故是神经病。"

4. **病名粒度可粗**：本派允许只按"质"报，不落到病种——【原文】"应该是血液方面的病。"（块19，实况为白血病。）

### 三、断应期：得病年、反复年、愈期

1. **得病年＝流年该字到、或该字克日干之年**。可直断年岁：【原文】"后年(1992)，你要患上肾病。"（块02）／【原文】"你十九岁（己酉）有一场大病灾。"（块21）。
2. **反复年**：断出病后，再报一个"病又犯了"的年——【原文】"她女儿会在戊寅年（1998）生一场大病，是子宫上的病"（块22），实况次年己卯复发。**反复年的判法原文未给（【碎片】）**，只能照录断语，不许自造规则。
3. **愈期须与死期交叉读**——"过某年就好了"多为**潜词**，字面吉、实指凶：【原文】"过了九七年，就好了。"（块19）实为 1997 年病逝。潜词机制本身见「夏仲奇断官非灾祸」§五，本册只补它在疾病上的用法：**凡"过某年就好了"型断语，一律拿去跟第四节死期档对表，不得按字面当愈期。**（块02 同型：【原文】"须过97年(丁丑)，到时一切都会好了"——实况 1997 腊月病逝。）
4. **伤灾应期给区间，不给单点**：住院时长用"下限＋上限"——【原文】"这次伤灾最少也要住院十个月，多则一年。"（块11/20/23/25）这是**断语记录，不是本派能算出的月数**，不得据以承诺。
5. **病、婚、情、死可并行于同一命、各取不同流年**：块02 一造 1992 得肾病、1994 甲戌离婚、1996 丙子遇桃花、1997 丁丑死——一个流年管一件事，不是一个流年管全部（L7）。

### 四、断寿与断死期

1. **两档死期法（关口语）：先给关口年，再说顺延档**——【原文】"这个人如果到了51岁不死，那就是60岁死。"（块04）读法：早那个年是关口，过不去就在关口应；过去了顺延到下一档（此造实况 51 岁险过、60 岁应死）。**断死期不是单点，是"关口＋顺延"。**
2. **死年判据（两路，均有明文）**：
   - **凶支被引到冲战**：【段解】"戊辰运亥水得强根与戌土相冲战，是忌神反局，故凶。""上造的原局中的戌土，是他遭凶死的原因。"（块04，对照造局中无戌则无凶害）——凶死之根在原局某一凶支。
   - **泄而无生**：【邢解】"丙火在原局中本弱，又行大运己丑，流年丁丑皆泄而无生，故死在此年。"（块02）
3. **短寿可按三档粒度一次给全**（年岁＋死法＋月）——【原文】"这个孩子短命，活不过13岁.""他会死于车祸，头会受创，一只眼睛没了。""要看是1998年阴历十月最凶"（块11）。
4. **死的委婉断语**："性命大灾""性命攸关的凶杀大灾"＝死——【原文】"你看是什么灾？""性命大灾。""我算她现在已经不在人世了。"（块24）**"性命大灾"可覆盖自杀，不专指他杀。**
5. **中间档：「大病灾」＝有性命之危而未死**：【原文】"你十九岁（己酉）有一场大病灾。"（块21，实况演习被炮震昏、险死未死）——与"活不过13岁"的必死档、"过了九七年就好了"的潜词死档作三档对照。
6. **断寿可细到月**：【序·邢铭芬自述】"夏先生明确告诉家里人，她活不过当年的二月，让叔叔准备后事吧。"（实况婶母死 1970 农历二月）此处属书前序文，**非四层声音之一**，引用须标"序·邢铭芬自述"。
7. **自断死期一例**：【原文】"八十岁，也就是1999年，我怕活不过那个年坎的。"（块17，夏仲奇本人，**未存四柱**；实况逝于 1998 年腊月）——本人无四柱，只作应验记录，不可当判据复用。

### 五、断死因取象

1. **先分大类：病死，还是出凶**。【原文】"我算他的死因不是病，是出了凶，像是也沾水也沾火死的，具体看不清。"（块11）——**"看不清"是本派本来就有的状态**，断不出具体死法不算断错，也不许事后类象强行补圆。
2. **死法二选一并列，不细分**：【原文】"不是刀杀，就是枪毙！"（块04）——同类死法（官府行刑／见血）并列给出。
3. **具体死因取象（有判据的）**：
   - **煤气中毒＝水火相加**：【原文】／【邢解】"水指洗澡，火是煤气"，象落在"丁丑"一柱（丁为火、丑为湿土含水）。
   - **枪毙＝枪库**：【邢解】"土官星在局中坐绝地大运流年入墓，弱绝怕入墓为枪库"（块20）。
   - **刀杀／刀伤＝辛金主刀、羊刃被冲**：【邢解】"辛金又主刀"（块13）。
   - **畜类死法＝十二生肖类化**：官星（丑土）类化为"畜"，牛驴同类不细分（块18）。
   - 以上几条的完整判法见「夏仲奇断官非灾祸」§三、§四，本册只作死因取象的索引。
4. **只有断语、没有判据的死法（【碎片】，照录不补）**：
   - **车祸**：块11 明断"他会死于车祸，头会受创，一只眼睛没了"，但全书**未给"车祸"的取象判据**（何字主车、何字主撞），只存断语。
   - **上吊自杀**：块24 全书仅此一例，断语只到"已不在人世""性命大灾"，**上吊这一死法无任何命理判据**，由案情补出。
   - **服安眠药自杀**：块22 媳妇，无判据。
   - **水淹、火烧**：块11 只在追述中被并列提及（"有刀杀，有车祸，有水淹的，也有火烧的"），**全书无对应命例、无取象判据**；不得据此编造"某字主水淹／火烧"的规则。
   - **溺水**：**原文未见**——全书无"溺死／淹死"的具体命例，仅块11"水淹"二字泛提。
5. **断病死的脏器线**：本派唯一能给出脏器／病质的一条线（肾／心／血／子宫），判据见第一、二节；**除"水→肾""血→血""子宫→子宫"外，多数病名原文未给取象**（块08、块17 的心肌梗塞／尿毒症：断语只到"出灾""寿不长／都得死"，病名由当事人补出）。

## 判断标准

**做对了会看到：**

- 能指出一个**被点名的"致病之字"**（克日干的那个字、坏局的那个字、坏禄的那个字），并说清它落在哪一柱哪一宫。
- 病名是从"五行／器官→脏腑"表上查下来的，且**出处层标得对**；遇到表上标【碎片】的，只报病名、不编判法。
- 断寿给的是**"关口＋顺延"两档**（"某岁不死就是某岁死"），或一个**上限语**（"活不过某年"），不是一个凭空精确的死期点。
- 死因取象能落到对应表里已有的象（水火相加＝煤气、墓＝枪库、辛金＝刀、丑土＝畜）；表上没有的（车祸、上吊、水淹、火烧），**如实说"原文没给判据"**。
- 见到"过某年就好了"型断语，会**反向**读成"过不去该年"。

**做错了会看到：**

- 开头先算日主旺衰、先取用神——本派断病不靠这个（L1），一旦走这条路，病位与应期都落不下来。
- 把【邢解】的"流年见水克日干""皆泄而无生"当本派主口径去复算——那是邢铭芬本人的解释习惯，非夏仲奇原法（见下节）。
- 把"心肌梗塞""尿毒症""肺癌"这类**当事人自报或实况补出的病名**当成"某五行配某脏"的判据倒推——原文没有。
- 遇到一个没判据的死法（上吊、车祸）就自己造一条象把话补圆。
- 拿"住院十个月""活不过13岁""51 不死则 60 死"这类**断语记录**当成可对活人承诺的输出。

## 什么时候不该用它

1. **把【邢解】当主口径会错。** 本册四层声音分开读：【原文】＝夏仲奇本人断语（最高口径）、【邢解】＝邢铭芬（记录者）解读、非原法、【段解】＝段建业、【附录】＝书末外来文章（口径与夏仲奇体系不完全一致）。凡把【邢解】当主口径用，即刻出错——例如邢解以"流年见水克日干""皆泄而无生"解释病与死，走的是旺衰忌神一路；本书段解在同案自设质问，明说"用旺衰理论是讲不通的"。引【邢解】一律标层，不得当法则。
2. **断死期类结论一旦失手后果不可逆，且本书全部证据是事后叙述的应验轶事：无对照、无失败记录，取样本身经过筛选。** "活不过1997"恰好应验属幸存者记录。**不得对活人下寿元、死期的断言。**
3. **不能替代医疗诊断。** 本册只是命理口径的取象；用户若带着"我是不是得了病""该不该做检查"来问，须先说明这一点，不得以断病替代就医。
4. **时辰未校正不可用。** 报时辰常不准，夏仲奇本人的做法是先推兄弟姊妹数校正时辰（L2）；时辰无从校正时，整套取法失效。
5. **只有八字、无任何背景信息时可靠性大幅下降。** 本书大量断语依赖现场反馈逐步收窄（L8），"铁口直断"的独立性与"冷读＋反馈"难以区分。
6. **表外一律留空，不许补编。**

7. **碎片级的条目只能照录结论，不能当判法用。** 明标【碎片】的有：块06 妇人之"肾上的病"（断语在、取象依据缺）、块22"不是肾脏不好就是心脏不好"（二选一、无判据）、块17 心肌梗塞／尿毒症（无判据）、块08"只定年不定病"（只断"乙亥年会出灾"，病名当事人补）、块22"反复年"判据、块15 流产次数（只到"好几次"）、块24 上吊死法。**这些一律只报结论、不报算法。**
8. **与主流子平法、纳音法不通约。** "官星（土官）在局中坐绝地入墓为枪库"这类取象须在夏派口径内读；要看主流子平法请用「渊海子平」「子平真诠评注」，要看年柱纳音那套请用「五行精纪注释」。
